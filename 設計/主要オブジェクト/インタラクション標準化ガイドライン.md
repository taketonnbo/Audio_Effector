# インタラクション標準化ガイドライン (Audio Effector)

## 1. 概要
本ドキュメントは、Audio EffectorのOOUI（オブジェクト指向UI）設計におけるユーザーインタラクション（操作トリガーと振る舞い）の統一ルールを定めた設計仕様書です。
各オブジェクト固有の属性（プロパティ）およびアクション一覧については、各主要オブジェクト仕様書（単一の情報源: Single Source of Truth）を参照するものとし、本ドキュメントではUI全体で一貫して適用される操作ルール、トリガー種別の標準化、および共通インタラクションパターンを定義します。

---

## 2. 主要オブジェクト仕様書（参照先）
各オブジェクトの詳細な属性定義テーブルおよび実行可能アクション一覧は、以下の仕様書を参照してください：

- [楽曲仕様書 (`Track`)](01_楽曲_Track.md): メタデータ属性、再生・キュー追加・タグ編集・一括操作
- [アルバム仕様書 (`Album`)](02_アルバム_Album.md): 作品集約属性、詳細情報確認・一括再生・ドリルダウン
- [プレイリスト仕様書 (`UserPlaylist`)](03_プレイリスト_UserPlaylist.md): 動的/静的プレイリスト属性、M3U入出力・編集・Undo
- [再生キュー仕様書 (`PlayQueue`)](04_再生キュー_PlayQueue.md): リアルタイム再生順序、ギャップレス事前プリロード・並び替え
- [エフェクトプリセット仕様書 (`EqualizerPreset`)](05_エフェクトプリセット_EqualizerPreset.md): 10バンドEQゲイン値、プリセット管理
- [接続機器仕様書 (`Device`)](06_接続機器_Device.md): ストレージ容量予測・警告、フォルダ探索・直接転送

## 3. トリガー種別の標準化ガイドライン (Interaction Standards)

UI全体で直感的かつ一貫性のある操作感を提供するため、入力方式ごとの役割と標準挙動を以下のように統一します。

### 3.1 シングルクリック (Left Click)
- **対象選択 (Selection)**: リスト行、カード、ツリーノードのフォーカスおよび選択状態の切り替え。
- **トグル操作**: チェックボックス（転送選択など）、お気に入り（星アイコン）の反転。
- **ナビゲーション**: 左サイドバーのメニュー項目選択、タブ切り替え、閉じるボタンの実行。

### 3.2 ダブルクリック (Double Click)
- **プライマリアクション実行（最重要ルール）**:
  - 楽曲 (`Track`) → 該当曲の即時再生開始 (`PlayTrackCommand`)
  - アルバム (`Album`) → アルバム全曲をキューに読み込み、1曲目から一括再生開始 (`PlayAlbumCommand`)
  - プレイリスト (`UserPlaylist`) → プレイリスト詳細画面（収録曲一覧）の表示 (`ShowPlaylistCommand`)
  - フォルダ / アーティスト → 下位階層へのドリルダウン展開
- **インライン編集**: プレイリスト名などのテキスト要素のインプレース編集モードへの移行。

### 3.3 右クリック (Context Click)
- **セカンダリアクション（コンテキストメニュー表示）**:
  - 選択されたオブジェクトに対して実行可能な二次的操作（「次に再生」「最後に再生」「プレイリストに追加...」「詳細情報/プロパティ」「ライブラリから削除」など）を網羅したメニューを表示。
  - 複数行選択時は、選択中の全アイテムに対する一括操作メニューを表示。

### 3.4 ドラッグ＆ドロップ (Drag & Drop)
- **直接操作（ダイレクトマニピュレーション）の標準ルール**:
  画面遷移を挟まずに、オブジェクトを目的の場所へ直感的に移動・投入できる操作体系を提供します。

| ドラッグ元 (Source) | ドロップ先 (Target) | 実行されるアクション |
| :--- | :--- | :--- |
| **楽曲 / アルバム** | 再生キューパネル (`PlayQueueSidePanel`) | キューのドロップ位置へ割り込み挿入、または末尾追加 |
| **楽曲 / アルバム** | サイドバーのプレイリスト項目 | 対象プレイリストへ楽曲を一括追加 |
| **楽曲 / アルバム** | サイドバーの接続機器 (`Device`) | 対象機器の現在フォルダへ転送開始 |
| **再生キュー行** | 再生キューパネル内（他行の上下） | 再生キュー内の順序並び替え |
| **外部エクスプローラー** | メインウィンドウ全体 | 音声ファイル/フォルダの取り込み、またはM3Uプレイリストのインポート |

### 3.5 キーボードショートカット (Keyboard Shortcuts)
- **グローバル操作（常時有効）**:
  - `Space`: 再生 / 一時停止のトグル切り替え
  - `Ctrl + Z`: 直前の破壊的・変更操作の取り消し (Undo)
  - `Ctrl + Y` / `Ctrl + Shift + Z`: 取り消した操作のやり直し (Redo)
- **リスト / グリッド操作（フォーカス時有効）**:
  - `Enter`: 選択中アイテムの再生開始（ダブルクリックと同等）
  - `Delete`: 選択中アイテムの除外/削除（プレイリストからの除外、キューからの削除、ライブラリ削除）
  - `Ctrl + A`: 現在のビュー内の全アイテム選択
  - `Alt + Enter`: 選択中アイテムのプロパティ（タグ情報）ダイアログ表示
  - `↑` / `↓` / `←` / `→`: カーソル移動による選択項目の変更

### 3.6 ホバー操作 (Hover / Mouse Over)
- **クイックアクションの表出**:
  - アルバムカードホバー時: 再生オーバーレイボタン、トラック一覧展開トグル、詳細情報ボタンの表示
  - 再生キュー行ホバー時: 削除「✕」ボタンの表示、ドラッグハンドルの視認性向上

## 4. 共通操作パターンとフィードバック

### 4.1 複数選択（マルチセレクト）の統一
- `Ctrl + Click`: 個別アイテムの選択追加 / 選択解除。
- `Shift + Click`: 起点からクリック位置までの範囲連続選択。
- 複数選択状態において実行された操作（D&D、右クリックメニュー、Deleteキー）は、選択されたすべてのアイテムに対して一括適用されます。

### 4.2 操作の取り消し (Undo / Redo) の標準化
- ユーザーが安心して直接操作（D&D、削除、並び替え等）を行えるよう、以下の破壊的・変更操作を対象に `Ctrl + Z` による安全な復元機能（`HistoryManager`）を提供します：
  1. プレイリストからの楽曲除外、およびプレイリストの誤削除
  2. 再生キューの全クリア（Clear）、および意図しない順序並び替え
  3. 楽曲・アルバムのライブラリからの除外
  4. 楽曲タグ・メタデータの一括編集
