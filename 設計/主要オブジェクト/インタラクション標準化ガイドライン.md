# インタラクション標準化ガイドライン (Audio Effector)

## 1. 概要
本ドキュメントは、Audio EffectorのOOUI（オブジェクト指向UI）設計におけるユーザーインタラクション（操作トリガーと振る舞い）の統一ルールを定めた設計仕様書です。
各オブジェクト固有の属性（プロパティ）およびアクション一覧については、各主要オブジェクト仕様書（Single Source of Truth）を参照するものとし、本ドキュメントではUI全体で一貫して適用される操作ルールを**「実装済み標準インタラクション」**と**「拡張インタラクション設計方針（構想）」**に分けて定義します。

## 3. 実装済み標準インタラクション (Implemented Standards)

### 3.1 シングルクリック (Left Click)
- **対象選択 (Selection)**: リスト行、アーティスト項目（`ArtistsView` 左ペイン）のフォーカスおよび選択状態の切り替え。
- **即時再生（ボタン型リスト）**: アルバム展開トレイ内トラック、右側パネル収録曲、再生キュー（`PlayQueueSidePanel` / `MiniPlayerWindow` 下部連結キュー）、プレイリスト内楽曲（`PlaylistTracksView`）の行クリックによる再生開始（右側パネルでは再生中トラックの再クリックで一時停止/再開トグル）。
- **トグル操作**: チェックボックス（機器転送選択）、お気に入り（ハート/星アイコン）、アルバム展開（Expander / ソケットトレイ）、右側パネル開閉・サイズ切替、スペクトラム開閉。
- **ナビゲーション**: 左サイドバー（`SidebarControl`）のメニュー項目選択、プレイリストカード（`PlaylistSelectorView`）クリックによる詳細画面への遷移、再生キューの「再生リスト / 履歴」タブ切り替え。

### 3.2 ダブルクリック (Double Click)
- **リスト行のプライマリ再生（`AllSongsView`, `ArtistsView`, `RecentView`）**:
  - 楽曲行のダブルクリックで該当曲から即時再生を開始します。
  - **誤動作防止ルール**: `MouseDoubleClick` ハンドラ内で必ず `e.OriginalSource` からビジュアルツリーを遡り、子 `Button`（お気に入り等）や `ScrollBar`、アイテム外の余白でのダブルクリックでは再生を発火させません。
- **フォルダ階層移動（`DeviceSyncView`）**:
  - デバイス内ディレクトリ一覧のフォルダ（`📁`）ダブルクリックで下位階層へ移動します。

### 3.3 右クリック (Context Click)
- **コンテキストメニュー表示**:
  - 楽曲 (`Track` / `RecentTrackEntry` / `AllSongsTrackItem`): 「再生」「次に再生」「最後に再生」「お気に入りに追加/解除」「プレイリストに追加...」「プロパティ」「ファイルの場所を開く」「削除（または履歴から削除 / キューから削除）」。
  - アルバム (`Album`): 「再生」「次に再生」「最後に再生」「お気に入りに追加/解除」「プレイリストに追加...」「削除」。
  - プレイリスト (`UserPlaylist`): 「開く」「再生」「シャッフル再生」「名前の変更」「削除」。

### 3.4 キーボードショートカット (Keyboard Shortcuts)
- **カスタマイズ可能な再生・音量ショートカット（`AppSettings` / `SettingsDialog`）**:
  - 「再生 / 一時停止」「次の曲」「前の曲」「停止」「音量を上げる（+5%）」「音量を下げる（-5%）」「ミュート切替」の7操作に対して任意のキー（修飾キー＋キー）を割り当て可能。
  - `ShortcutInputBox` にてアプリ内重複チェックおよび Win32 `RegisterHotKey` による他アプリ競合警告を行う。
- **ミニプレイヤーのウィンドウ操作**:
  - ミニプレイヤー表示中に最大化ショートカット（`Win + ↑` 等の Aero Snap 最大化）が入力された場合は、ミニプレイヤーの拡大を抑止してメインウィンドウへの復帰を実行する（Issue #72）。

### 3.5 ホバー操作 (Hover / Mouse Over)
- **クイックアクション・ハイライトの表出**:
  - アルバムカードホバー時: 再生オーバーレイボタン、トラック展開トグルボタンの表示。
  - リスト行・ボタンホバー時: `ControlBackgroundHighlightBrush` 等による背景ハイライト。
- **見切れテキストの自動シームレスループ (`MarqueeTextBlock`)**:
  - 曲名・アルバム名・アーティスト名が表示幅を超過している場合のみ、対象テキストまたは親カード/行へのマウスホバーで約0.5秒後にシームレスな無限ループスクロールを開始し、マウス離脱で即座に初期省略表示へ復帰する。

## 4. 拡張インタラクション設計方針（将来構想 / To-Be）

以下のインタラクションは、OOUI移行プロジェクト（Issue #216, #233 等）における拡張設計指針として定義されています。

### 4.1 ドラッグ＆ドロップ (Drag & Drop) による直接操作
| ドラッグ元 (Source) | ドロップ先 (Target) | 構想アクション | 関連Issue |
| :--- | :--- | :--- | :---: |
| **再生キュー行** | 再生キューパネル内（他行の上下） | 再生キュー内の順序並び替え | #216 |
| **プレイリスト内楽曲行** | プレイリスト詳細画面内（他行の上下） | プレイリスト内の曲順並び替え（Domain/App層は実装済み） | #233 |
| **楽曲 / アルバム** | 再生キューパネル / サイドバーのプレイリスト項目 | ドロップ先への楽曲割り込み挿入・追加 | #71, #233 |

### 4.2 複数選択（マルチセレクト）と操作の取り消し（Undo / Redo）
- **複数選択一括操作**: `Ctrl + Click` / `Shift + Click` / `Ctrl + A` による複数楽曲の選択と、一括キュー追加・プレイリスト追加・削除。
- **Undo / Redo (`Ctrl + Z` / `Ctrl + Y`)**: プレイリストからの除外、キューの全クリア、ライブラリからの削除等の破壊的操作を直前の状態へ復元する履歴管理機構（`HistoryManager`）の導入。
