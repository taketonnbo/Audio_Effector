# プロパティ・アクション定義辞書 (Audio Effector)

## 1. 概要
本ドキュメントは、Audio EffectorのOOUI（オブジェクト指向UI）設計における全主要オブジェクトの「プロパティ（静的情報）」および「アクション（動的操作）」を網羅的に定義した辞書（操作マトリクス）です。
ユーザーがUI上で直接知覚する情報と、各オブジェクトに対して実行可能な操作の対応関係を標準化し、一貫性のあるユーザーインターフェース設計の基盤とすることを目的とします。

---

## 4. トリガー種別の標準化ガイドライン (Interaction Standards)

UI全体で一貫した操作感を提供するため、操作トリガー（入力方式）の役割を以下のように統一します。

1. **シングルクリック (Left Click)**:
   - オブジェクトの選択（Selection）
   - トグルボタン・チェックボックスの切り替え
   - ナビゲーション（画面・タブ・フォルダの切り替え）
2. **ダブルクリック (Double Click)**:
   - オブジェクトのプライマリアクション実行（**楽曲・アルバム・プレイリストの「再生開始」**）
   - フォルダ項目の「下位階層へのドリルダウン」
   - テキストの「インライン編集モードへの移行」
3. **右クリック (Context Click)**:
   - オブジェクトに対するコンテキストメニューの表示（「次に再生」「プレイリストに追加」「プロパティ」「削除」等のセカンダリアクション）
4. **ドラッグ＆ドロップ (Drag & Drop)**:
   - オブジェクトの移動・追加（楽曲を再生キューやプレイリスト、接続機器へ直接投入）
   - リスト内での順序並び替え（キュー行の入れ替え）
   - 外部ファイルの取り込み（エクスプローラーからの音声ファイル/M3Uファイル投入）
5. **キーボードショートカット**:
   - `Space`: 再生 / 一時停止のトグル（グローバル）
   - `Ctrl + Z` / `Ctrl + Y`: 直前操作の取り消し（Undo） / やり直し（Redo）
   - `Ctrl + A`: リスト内全楽曲の全選択
   - `Delete`: 選択中楽曲のプレイリスト除外 / キュー除外
   - `Enter`: 選択中アイテムの再生開始
