# 共通コントロールスタイル仕様書 (Common Control Styles Specification)

## 1. 概要

本仕様書は、Audio Effectorの各画面・ビューにおいて使用するWPFコントロールに対するカスタムStyleおよびControlTemplateの設計を定めたものです。
[デザイントークン仕様書](01_デザイントークン仕様書.md) で定義されたトークンおよび [パフォーマンス最適化方針](../詳細設計/パフォーマンス最適化.md) に準拠し、**「アプリケーション全体でグローバル登録されている共通スタイル」**と**「各画面で統一適用するデザインガイドライン」**の2層で定義します。

---

## 2. グローバル定義済み共通スタイル (`App.xaml` / `ScrollBarResources.xaml`)

以下のスタイルは [`App.xaml`](../../AudioEffector/App.xaml) および [`ScrollBarResources.xaml`](../../AudioEffector/Presentation/Themes/ScrollBarResources.xaml) でアプリケーション全体へ公開されています。

### 2.1 スクロールバー (`ScrollBarResources.xaml` - 暗黙グローバルスタイル)
Windows 11 Fluent Designのミニマルな外観を採用し、`TargetType="{x:Type ScrollBar}"` の暗黙スタイルとして全画面の `ScrollBar` に自動適用されます。

- **非ホバー時 (Idle)**:
  - トラック背景: `ScrollBarTrackBrush`（完全透明 `#00000000`）。
  - サム（Thumb）: 縦スクロールバーは **幅 6px**（`MinHeight="24"`）、横スクロールバーは **高さ 6px**（`MinWidth="24"`）、**角丸 3px**、色 `ScrollBarThumbBrush`（Dark: `#424C5E` / Light: `#CBD5E1`）。
- **マウスホバー時 (Hover)**:
  - サムの太さが **8px** へ拡張、色 `ScrollBarThumbHoverBrush`（Dark: `#607088` / Light: `#94A3B8`）。
- **ドラッグ時 (Dragging)**:
  - サム色が `ScrollBarThumbDraggingBrush`（Dark: `#00FFFF` / Light: `#0078D7`）へ変化。

### 2.2 コンボボックス (`NeonComboBoxStyle` - `App.xaml`)
ソート順選択や設定画面のドロップダウンで使用する共通コンボボックススタイルです。
- **本体**: 背景 `ControlBackgroundBrush`、文字色 `TextForegroundBrush`、枠線 `BorderBrush` (1px)、角丸 `4px`。
- **ホバー / ドロップダウン開状態**: 枠線が `NeonCyanBrush` へ強調され、右端矢印パスも `NeonCyanBrush` に変化。
- **ポップアップ (`PART_Popup`)**: 背景 `PanelBackgroundBrush`、枠線 `BorderBrush` (1px)、角丸 `4px`、選択・ホバー項目は `ControlBackgroundHighlightBrush`＋`NeonCyanBrush` 文字。

### 2.3 縦型スライダー (`NeonVerticalSliderStyle` - `App.xaml`)
イコライザーバンド等で利用する縦型スライダーのグローバルスタイルです。
- **トラック**: 幅 `4px`、角丸 `2px`、上部 `ControlBackgroundHighlightBrush`、下部（充填側）`NeonCyanBrush`。
- **Thumb**: `16×16px` の円形、`NeonCyanBrush` 塗り。

## 3. 画面ローカル・コントロールスタイルと標準ガイドライン

以下のコントロールは各View（`MainWindow.xaml`, `AllSongsView.xaml`, `ArtistsView.xaml`, `RecentView.xaml`, `EqualizerView.xaml` 等）の `Resources` 内で同一のデザイン原則に従って定義します。

### 3.1 ボタン (Button & ToggleButton)

各画面のツールバー等では、`ToolbarPrimaryButtonStyle` / `ToolbarSecondaryButtonStyle`（または `RecentPrimaryButtonStyle` 等）として以下のバリアントを定義します。

| バリアント | 用途 | 通常時 (Normal) | ホバー時 (Hover) | 無効時 (Disabled) |
| :--- | :--- | :--- | :--- | :--- |
| **PrimaryButton** | 最重要アクション（すべて再生、履歴から再生、保存） | 背景: `NeonCyanBrush`<br>文字: `InverseTextForegroundBrush`<br>角丸: `4px` | `Opacity="0.88"` または `DarkNeonCyanBrush` | `Opacity="0.4"` |
| **SecondaryButton** | 補助的アクション（シャッフル、履歴をクリア、キャンセル） | 背景: `ControlBackgroundBrush`<br>文字: `TextForegroundBrush`<br>枠線: `BorderBrush` (1px)、角丸: `4px` | 背景: `ControlBackgroundHighlightBrush` | `Opacity="0.4"` |
| **SubtleButton (Ghost)** | インラインアイコンボタン、検索クリア `✕`、パネル閉じる | 背景: 透明<br>文字: `MutedTextForegroundBrush` | 背景: `ControlBackgroundHighlightBrush`<br>文字: `TextForegroundBrush` | `Opacity="0.4"` |
| **IconCircleButton** | プレイヤー再生/一時停止ボタン | 背景: `NeonCyanBrush`（または枠線シアン）<br>形状: 円形 | 背景ハイライトまたは色反転 | `Opacity="0.4"` |

### 3.2 テキスト入力・検索ボックス (TextBox & SearchBox)
- **外観**: 外枠 `Border` に背景 `ControlBackgroundBrush`、枠線 `BorderBrush` (1px)、角丸 `4px`。内部 `TextBox` は背景透明、`CaretBrush="{DynamicResource NeonCyanBrush}"`。
- **プレースホルダー**: 空文字（`Text == ""`）時のみ `DataTrigger` で `MutedTextForegroundBrush` のウォーターマーク `TextBlock`（`IsHitTestVisible="False"`）を表示。
- **クリアボタン (`✕`)**: 検索文字列が入力されている場合のみ右端に表示し、`ClearSearchCommand` で即時クリア。

### 3.3 再生シークバー・音量スライダー (`MainWindow.xaml` / `EqualizerView.xaml`)
- **プログレスシークバー (`NeonSliderStyle`)**:
  - 左側（再生済みトラック）: `NeonCyanBrush`（高さ 4px）。
  - 右側（未再生トラック）: `ControlBackgroundHighlightBrush`（高さ 4px）。
  - Thumb: 円形、`IsMoveToPointEnabled="True"` によりクリック位置への即時シークおよびドラッグシークに対応。
- **音量スライダー (`NeonVolumeSliderStyle`)**:
  - `EqualizerView.xaml` では縦型スライダー（充填色 `NeonVolumeBrush #008B8B`）、`SettingsDialog.xaml` では横型スライダー＋パーセント数値表示（`P0`）として配置。

## 4. コレクション表示 (ListBox / ListView)

楽曲一覧、アーティスト一覧、最近再生した曲、再生キュー履歴など、多数のオブジェクトを表示するリストの標準仕様です。

### 4.1 パフォーマンス必須ルール（UI仮想化）
[パフォーマンス最適化方針](../詳細設計/パフォーマンス最適化.md) に基づき、親 `ScrollViewer` の内包を禁止し、以下の4属性指定を必須とします：

```xml
VirtualizingPanel.IsVirtualizing="True"
VirtualizingPanel.VirtualizationMode="Recycling"
VirtualizingPanel.ScrollUnit="Pixel"
ScrollViewer.CanContentScroll="True"
```

### 4.2 行インタラクションと状態スタイル
- **行ホバー (MouseOver)**: 背景 `ControlBackgroundHighlightBrush`。
- **行選択 (Selected) および 現在再生中 (IsPlaying)**:
  - **行の左端に幅 3px のネオンシアンアクセント縦バー (`NeonCyanBrush`)** を表示。
  - 現在再生中の楽曲（`Track.IsPlaying == True`）は、アルバムアート上に暗幕＋ `AlwaysNeonCyanBrush` の再生インジケーターを重ね、タイトル文字色を `NeonCyanBrush` で強調。
- **ゼブラストライプ**: 奇数行に `ZebraOddBackgroundBrush`（Dark: `#12FFFFFF` / Light: `#0C000000`）を適用し、多列リストの視認性を高める。

## 5. コンテキストメニュー (ContextMenu & MenuItem)

オブジェクト（楽曲、アルバム、プレイリスト、履歴エントリ等）の右クリックメニュー仕様です。
- **構成**: 再生アクション（再生、次に再生、最後に再生）→ 区切り線（`Separator`）→ コレクション操作（お気に入り追加/解除、プレイリストに追加...）→ 区切り線 → ファイル・管理操作（プロパティ、ファイルの場所を開く、削除/除外）の順で論理グループ化する。
- **`PlacementTarget.Tag` 経由のバインディング**: WPFの `ContextMenu` はメインビジュアルツリーから独立するため、親要素の `Tag` に親ViewModel（または `DataContext`）を保持させ、`PlacementTarget.Tag.<Command>` で確実にコマンド解決を行う。
