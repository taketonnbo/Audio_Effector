# デザイントークン仕様書 (Design Tokens Specification)

## 1. 概要

本仕様書は、Audio Effectorにおける視覚デザインの最小単位である「デザイントークン（Design Tokens）」を標準化・体系化した設計書です。
カラー、タイポグラフィ、スペーシング、角丸、エレベーション、モーションを名前付きのセマンティックトークンとして定義することで、コードおよびXAMLリソース間でのハードコードを排し、ダークテーマ・ライトテーマの双方で破綻のないビジュアル調和と高い保守性を保証します。
カラートークンの正本リソースは [`DarkTheme.xaml`](../../AudioEffector/Presentation/Themes/DarkTheme.xaml) および [`LightTheme.xaml`](../../AudioEffector/Presentation/Themes/LightTheme.xaml) です。

| `Spacing.XS` | 4px | インラインアイコンとラベルの間隔、タイトなパディング |
| `Spacing.S` | 8px | ボタン内横パディング、リスト行の上下余白、コントロール間隔 |

| `Spacing.XXL` | 32px | ウィンドウ境界からの大マージン、ヒーローセクション周囲 |

## 6. エレベーションと陰影トークン (Elevation Tokens)

パフォーマンス最適化方針に基づき、高負荷な動的ぼかしエフェクトの乱用を禁止し、**「ボーダー線（Border）による境界分離」を基本としつつ、テーマ定義された静的シャドウリソースのみを厳選適用**します。

| リソースキー / レベル | Dark Theme 定義 | Light Theme 定義 | 適用要素 |
| :--- | :--- | :--- | :--- |
| **Level 0 (Flat)** | 境界線なし | 境界線なし | メインワークスペース背景、プレイヤーバー |
| **Level 1 (Surface)** | `BorderThickness="1"` + `BorderBrush` (`#343E4E`) | `BorderThickness="1"` + `BorderBrush` (`#CCCCCC`) | アルバムカード、リストコンテナ、サイドバー区切り |
| **`CardDropShadowEffect`** | `Color="#000000" BlurRadius="22" ShadowDepth="5" Direction="270" Opacity="0.75"` | `Color="#000000" BlurRadius="16" ShadowDepth="3" Direction="270" Opacity="0.30"` | 右側Player Podカード等の主要カードコンテナ |
| **`AlbumArtDropShadowEffect`** | `Color="#000000" BlurRadius="30" ShadowDepth="8" Direction="270" Opacity="0.85"` | `Color="#000000" BlurRadius="20" ShadowDepth="5" Direction="270" Opacity="0.35"` | 右側メインアルバムアートのメタリックベゼル外周 |

> [!IMPORTANT]
> **パフォーマンス制約**: スペクトラムアナライザのバーやシークバー、常時スクロールするリスト行など、高頻度で描画更新される動的要素には `DropShadowEffect` を指定してはなりません。

## 7. モーション・トランジショントークン (Motion Tokens)

### 7.1 時間軸 (Duration)
| トークン名 | 時間 (ms) | 用途 |
| :--- | :---: | :--- |
| `Motion.Instant` | 0ms | 即時切り替え（チェック状態、フォーカス枠） |
| `Motion.Fast` | 100ms | マイクロインタラクション（ボタンホバー、押下時の色変化） |
| `Motion.Normal` | 200ms | フェードイン/アウト、タブ切り替え、ツールチップ |
| `Motion.Slide` | 250ms | 右スライドパネル開閉、ドロワー展開、アコーディオン開閉 |
| `Motion.Slow` | 400ms | 大規模な画面ビュー遷移、モーダルダイアログのポップアップ |

### 7.2 イージングカーブ (Easing Function)
- **標準イージング (`Easing.Standard`)**: `CubicEase EasingMode="EaseInOut"`
- **進入イージング (`Easing.Enter`)**: `CubicEase EasingMode="EaseOut"`
- **退出イージング (`Easing.Exit`)**: `CubicEase EasingMode="EaseIn"`
