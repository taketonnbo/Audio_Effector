# 機能仕様書: スペクトラムアナライザ

## 1. 機能概要
スペクトラムアナライザ機能は、再生中の音声信号の周波数成分をリアルタイムに解析し、音楽のビートやトーンの変化を視覚的なグラフィックアニメーションとして楽しむための機能です。
音質の確認や、楽曲の世界観に浸るビジュアル演出を提供します。

## 2. ユーザー向け提供機能

### 2.1 リアルタイム周波数可視化
- **32バンド周波数表示**: 重低音（40Hz付近）から超高音（20kHz）までを32分割し、音量・強弱に応じて各バーが滑らかに上下します。
- **ピークホールド表示**: 音の瞬時最大レベルを把握できるよう、最高到達点にマーカーが一定時間滞空した後にゆっくり降下します。
- **流れるようなスムージング**: 音の立ち上がり（アタック）には素早く反応し、減衰（ディケイ）時は自然に滑らかに下降することで、視覚的な心地よさを実現します。

### 2.2 自由な表示切り替え（スライドアニメーション）
- **トグル開閉**: 画面最下部の「SPECTRUM ANALYZER」ボタンをクリックするだけで、いつでもアナライザ領域の展開・格納が可能です。
- **スライドトランジション**: 開閉時は下部から滑らかにせり上がり・引き下がるアニメーションが行われます。

### 2.3 アルバムアートとの自動カラー連動
- **ドミナントカラー連動**: 再生中のアルバムのアートワークからメインカラーを自動解析し、バーの発光色やグラデーションが曲ごとに自動で調和します。

## 3. 利用手順（想定ワークフロー）
1. 任意の楽曲を再生します。
2. ウィンドウ最下部にある「SPECTRUM ANALYZER」のハンドルバー（▲/▼マーク）をクリックします。
3. スペクトラムアナライザが下部からスライド展開し、音楽に合わせてリアルタイムにネオングローのバーが躍動します。
4. 画面を広く使いたい場合は、再度ハンドルバーをクリックすることで、いつでもアナライザをコンパクトに格納できます。
