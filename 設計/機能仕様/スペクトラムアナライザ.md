# 機能仕様書: スペクトラムアナライザ

## 1. 機能概要
スペクトラムアナライザ機能は、再生中の音声信号の周波数成分をリアルタイムに解析し、音楽のビートやトーンの変化を視覚的なグラフィックアニメーションとして楽しむための機能です。
音質の確認や、楽曲の世界観に浸るビジュアル演出を提供します。

## 2. ユーザー向け提供機能

### 2.1 リアルタイム高解像度周波数可視化
- **64バンド周波数表示**: 重低音（20Hz付近）から超高音（20kHz）までを64分割し、音量・強弱に応じて細身のスレンダーバーが滑らかに上下します。
- **アスペクト比・寸法の固定表示**: 画面サイズやウィンドウの伸縮にかかわらず、中央に配置された一定のアスペクト比・バー太さ（約6px）・間隔を常に維持します。
- **6分割帯域インジケーター**: `60Hz`, `250Hz`, `500Hz`, `1kHz`, `4kHz`, `16kHz` の周波数ラベルにより、現在鳴っている音域を直感的に把握できます。
- **水面ミラーリフレクション**: バーの下部に水面に映り込むような反転リフレクション光を描画し、立体的な奥行きを演出します。
- **流れるようなスムージング**: 音の立ち上がり（アタック）には素早く反応し、減衰（ディケイ）時は自然に滑らかに下降することで、視覚的な心地よさを実現します。
- **マスター音量・イコライザーからの独立性**: アプリの音量を下げたりミュートにしても、楽曲本来の音量・周波数変化に応じてスペクトラムバーが美しく変動します。

### 2.2 自由な表示切り替え（スライドアニメーション）
- **トグル開閉**: 画面最下部の「SPECTRUM ANALYZER」ボタンをクリックするだけで、いつでもアナライザ領域の展開・格納が可能です。
- **スライドトランジション**: 開閉時は下部から滑らかにせり上がり（高さ140px）・引き下がるアニメーションが行われます。

### 2.3 アルバムアートとの自動カラー連動
- **ドミナントカラー連動**: 再生中のアルバムのアートワークからメインカラーを自動解析し、バーの発光色やグラデーションが曲ごとに自動で調和します。

## 3. 利用手順（想定ワークフロー）
1. 任意の楽曲を再生します。
2. ウィンドウ最下部にある「SPECTRUM ANALYZER」のハンドルバー（▲/▼マーク）をクリックします。
3. スペクトラムアナライザが下部からスライド展開（高さ140px）し、音楽に合わせてリアルタイムにネオングローのバーと水面反射が躍動します。
4. 画面を広く使いたい場合は、再度ハンドルバーをクリックすることで、いつでもアナライザをコンパクトに格納できます。
