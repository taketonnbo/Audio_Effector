# 機能仕様書: スペクトラムアナライザ

## 1. 機能概要
スペクトラムアナライザ機能は、再生中の音声信号の周波数成分をリアルタイムに解析し、音楽のビートやトーンの変化を視覚的なグラフィックアニメーションとして楽しむための機能です。
音質の確認や、楽曲の世界観に浸るビジュアル演出を提供します。

## 2. ユーザー向け提供機能

### 2.1 リアルタイム高解像度周波数可視化
- **64バンド対数周波数表示**: 重低音（20Hz）から超高音（20kHz、またはサンプリング周波数のナイキスト周波数）までを対数スケールで64分割し、音量・強弱に応じて細身のバーが滑らかに上下します。
- **全周波数バランス最適化（低音抑制・高音躍動感強化）**:
  - 低音から高音までが均整の取れたダイナミックな動きとなるよう、周波数帯域ごとの調整係数および高音チルト補正を適用しています。
  - 低音が過剰に天井に張り付くのを防ぎつつ、シンバルやハイハットなどの高音域も力強く跳ねるよう最適化しています。
- **アスペクト比・寸法の固定表示**: 画面サイズやウィンドウの伸縮にかかわらず、中央に配置された一定のアスペクト比の64本バーを常に維持します。
- **6分割帯域インジケーター**: バー上部に `60Hz`, `250Hz`, `500Hz`, `1kHz`, `4kHz`, `16kHz` の周波数ラベルを配置し、現在鳴っている音域を直感的に把握できます。
- **流れるようなスムージング**: 音の立ち上がり（アタック）には素早く反応し、減衰（ディケイ）時は自然に滑らかに下降することで、視覚的な心地よさを実現します。
- **マスター音量からの独立性とイコライザー連動**:
  - 解析はイコライザー処理の直後・マスター音量処理の前段で行われるため、イコライザーによる周波数ブースト／カットはスペクトラム波形にリアルタイム反映される一方、アプリのマスター音量を下げたりミュートにしてもスペクトラムバーは楽曲の信号に応じて変動します。

### 2.2 自由な表示切り替え（スライドアニメーション）
- **トグル開閉**: 画面最下部の「SPECTRUM ANALYZER」ボタンをクリックするだけで、いつでもアナライザ領域の展開・格納が可能です。
- **自動格納連携**: 機器転送（Device Sync）画面へ切り替えた際は、作業領域を確保するためスペクトラムアナライザは自動的に格納されます。

### 2.3 アルバムアートとの自動カラー・背景連動
- **ドミナントカラー連動**: 再生中のアルバムのアートワークからメインカラーを自動解析し、バーのグラデーション色が曲ごとに自動で調和します。
- **背景アートワーク演出**: アナライザの背景には現在再生中のアルバムアートをぼかし＆減光した状態で透過配置し、没入感を高めます。

## 3. 利用手順（想定ワークフロー）
1. 任意の楽曲を再生します。
2. ウィンドウ最下部にある「SPECTRUM ANALYZER」のハンドルバーをクリックします。
3. スペクトラムアナライザが下部からスライド展開し、64本のバーが音楽に合わせてリアルタイムに躍動します。
4. 画面を広く使いたい場合は、再度ハンドルバーをクリックすることで、いつでもアナライザをコンパクトに格納できます。
