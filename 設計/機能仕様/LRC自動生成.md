# LRC 自動生成機能 仕様書

## 1. 機能概要
「LRC 自動生成機能」は、Audio Effector に登録された楽曲の音声データをローカル AI モデルで解析し、楽曲の進行に同期したタイムタグ付き歌詞ファイル（`.lrc`）を自動生成・確認・保存する機能です。

ユーザーは手作業で 1 行ずつタイムスタンプを打ち込む負担なく、次の **2 つの独立した生成方法** を用途に応じて別々のボタンから選択できます。

1. **テキストファイル（`.txt`）から LRC を生成する（強制アライメント）**: 手元にある正確な歌詞テキストファイルと楽曲音声を突き合わせ、各歌詞行へ自動的にタイムタグを付与します。
2. **音声から直接文字起こしして LRC を生成する（自動文字起こし）**: 歌詞テキストが手元にない楽曲でも、楽曲の音声そのものをローカルモデルで文字起こしし、タイムタグ付き LRC ファイルを生成します。

本機能はメイン画面右側タブの下部拡張領域に表示され、再生中の同期歌詞表示を担当する [歌詞表示機能](歌詞表示機能.md)（関連 Epic #401）と役割分担しながらシームレスに連携します。生成・保存した `.lrc` ファイルは、保存完了と同時に歌詞表示パネルへ即時反映されます。

---

## 2. ユーザー向け提供機能

### 2.1. 起動導線と歌詞表示機能との役割分担
- **役割分担（歌詞表示機能との責務分離）**:
  - **歌詞表示機能（#401）**: 外部 `.lrc` ファイルや埋め込み歌詞の探索・読み込み、再生位置に連動した同期ハイライト・自動スクロール・行クリックシークを担当します。
  - **LRC 自動生成機能（本機能）**: テキストファイルまたは音声からの `.lrc` 生成、生成結果のプレビュー確認・簡易微調整、`.lrc` ファイルの保存、および保存後の歌詞表示パネルへの即時リロード連携を担当します。
- **起動導線**:
  - 右側タブの歌詞表示パネル（歌詞未検出時の「LRC を自動生成する」ボタン、およびヘッダーの「LRC 自動生成／再生成」ボタン）から、再生中の楽曲を対象として即座に LRC 自動生成画面へ切り替えられます。
  - 楽曲一覧等のコンテキストメニューからも、任意の選択楽曲を対象に LRC 自動生成画面を開けます。
  - 起動時に右側タブが折りたたまれている場合は自動で展開し、右側タブが最大化モードになっている場合は自動でコンパクトモードへ切り替えたうえで、下部拡張領域に LRC 自動生成パネルを表示します。
- **下部拡張領域の排他切替と戻る操作**:
  - 右側タブ下部拡張領域では、同期歌詞表示パネルと LRC 自動生成パネルを排他的に切り替えます。
  - 「歌詞表示へ戻る（閉じる）」操作により、いつでも右側タブ下部を同期歌詞表示パネルへ戻せます。

---

### 2.2. 2 つの生成モード（別ボタンによる明示的な選択）
テキストからの同期生成と音声からの直接文字起こしは性質・精度特性が異なるため、ユーザーを混乱させないよう **別々の操作ボタン** として明確に分離して提供します。

#### (1) テキストファイル（`.txt`）から LRC を生成する
- ユーザーが用意した歌詞テキストファイル（`.txt`）を指定し、対象楽曲の音声解析結果と強制アライメント（自動位置合わせ）を行うことで、歌詞本文の表記を保ったまま各行へタイムタグを付与します。
- 歌詞の正確な漢字・仮名遣い・改行単位を維持したまま同期させたい場合に適しています。
- 入力テキストファイルはファイル選択ダイアログ、または画面内の所定エリアへのドラッグ＆ドロップで指定できます。

#### (2) 音声から直接文字起こしして LRC を生成する
- 歌詞テキストファイルを用意せずに、対象楽曲の音声データからローカルモデルによる音声認識（文字起こし）を直接実行し、認識されたフレーズとタイムスタンプから `.lrc` ファイルを生成します。
- 手元に歌詞テキストがない楽曲の仮同期歌詞を素早く作成したい場合や、ポッドキャスト・語学音源・弾き語り音源などの文字起こし用途に適しています。
- テキストファイル未選択の状態でも、専用の「音声から文字起こしして LRC を生成」ボタンから単独で実行できます。

### 2.3. 入力仕様・文字コード変換フロー（テキスト生成時）
- **標準入力形式（UTF-8）**:
  - テキストからの生成における標準入力は、**UTF-8 エンコードのプレーンテキストファイル（`.txt`）** とします（BOM 有無の両方に対応）。
  - UTF-8 として正常に読み込めるファイルが選択された場合は、変換確認を挟まずそのまま生成可能な準備完了状態へ遷移します。
- **非 UTF-8 文字コード（Shift-JIS 等）検出時の警告・承諾変換フロー**:
  - Shift-JIS（CP932）、EUC-JP、UTF-16 など **UTF-8 以外の文字コード** が検出された場合、自動変換を無断で行わず、検出された文字コード名と「UTF-8 へ変換して処理する」旨を明示した警告および承諾確認 UI を表示します。
  - **ユーザーが変換を承諾した場合**: 入力内容を UTF-8 へ変換して処理を続行します。
  - **ユーザーが承諾しなかった（キャンセルした）場合**: 変換および生成処理を実行せず、安全に中断（選択解除または待機状態へ復帰）します。
  - **元ファイルの保護**: UTF-8 変換はアプリ内部の処理用データ（メモリ上または一時データ）に対して行い、ユーザーが指定した元の `.txt` ファイル自体は破壊的に上書きしません。
- **対象楽曲フォーマットと入力バリデーション**:
  - 対象楽曲は Audio Effector が再生に対応している音声フォーマット（MP3 / WAV / FLAC / M4A / AAC / Ogg / WMA 等）すべてをサポートします。
  - 以下の不正・境界ケースでは、それぞれ適切なタイミングで分かりやすい案内メッセージを表示し、アプリや音楽再生を異常終了させません。
    - **開始前バリデーション**:
      - 対象楽曲が未選択、または音声ファイルがディスク上に存在しない・読み取り権限がない場合
      - 選択された `.txt` ファイルが空（0 バイト）または空白・改行のみで歌詞行が 1 行も含まれない場合
      - テキストファイル以外の未対応拡張子（バイナリファイル等）がドロップされた場合
    - **解析結果バリデーション**:
      - 無音楽曲や純粋なインストゥルメンタル楽曲など、音声解析の結果として発話・歌唱区間が 1 件も検出されなかった場合（エラーまたは未検出の案内を表示し、空の不正 `.lrc` を無断保存しない）

### 2.4. ローカルモデル処理方式・モデル管理・将来拡張方針
- **完全ローカル・無料オフライン処理（初期実装）**:
  - 初期実装ではオープンソース（MIT ライセンス）のローカル音声認識モデル（Whisper ローカル実行）を採用します。
  - 音声データを外部サーバーへ送信せず、API キーの取得や従量課金も一切発生しません。モデルファイル配置後は完全オフラインで動作します。
- **モデルファイルの取得・管理**:
  - 初回利用時にローカルモデルが未配置の場合は、画面上のガイドから無料の標準モデル（速度と精度のバランスに優れた `base` 相当を既定とし、より軽量な `tiny` や高精度な `small` 等の選択も想定）をワンクリックでダウンロードし、ユーザーデータ領域へ保存できます。
  - すでに手元へダウンロード済みのモデルファイル（`.bin`）をローカル参照先として手動指定することも可能です。
- **処理時間の目安・非同期進捗表示・キャンセル**:
  - CPU 実行の場合、3〜5 分程度の楽曲 1 曲あたり数十秒〜1〜2 分程度が処理時間の目安です（PC 性能やモデルサイズにより変動します）。
  - 解析・生成処理はバックグラウンドで非同期実行し、UI 操作や楽曲再生を一切ブロックしません。
  - 処理中は進捗バー（0〜100%）および現在の処理フェーズ（例:「音声デコード中」「モデル読み込み中」「音声解析・文字起こし中」「歌詞タイミング合わせ中」「LRC 整形中」）をリアルタイムに表示します。
  - 処理中いつでも「キャンセル」ボタンから安全に中断でき、中断時に一時リソースを解放して待機状態へ戻ります。
- **エラーハンドリング**:
  - モデル未配置、モデルダウンロードのネットワーク失敗、ディスク容量不足、メモリ不足、音声ファイル破損などの異常が発生した場合は、音楽再生を継続したままパネル内に原因と対処方法（モデル取得・ファイル再確認・軽量モデルへの切替等）および再試行アクションを表示します。
- **将来的な外部 API 移譲への拡張方針**:
  - 将来的に「より高速・高精度な外部音声認識／強制アライメント API」へ処理を移譲・追加できるよう、利用する解析エンジンを切り替え可能な構成を見据えます。
  - ユーザー視点では、将来的に設定画面または生成パネルから「ローカルモデル（無料・オフライン）」と「外部 API（要 API キー）」を切り替えられる拡張点として機能仕様を位置付けます。

### 2.5. 生成結果のプレビュー確認・簡易微調整・保存と即時反映
- **LRC プレビュー確認**:
  - 生成完了後、タイムタグが付与された LRC テキストおよび各歌詞行のタイムスタンプ一覧をパネル内で即座に確認できます。
  - 対象楽曲を再生しながらプレビューのタイミングを確認できるため、保存前にズレの有無を把握できます。
- **タイミングの簡易微調整（精度補完）**:
  - 伴奏が大きい楽曲、ライブ音源、重複コーラス・ハモリが強い楽曲などでは、自動生成されたタイムタグに数百ミリ秒〜数秒程度のズレや文字起こしの誤変換が生じる場合があります。
  - そのため、保存前にユーザーが手軽に補正できる以下の簡易微調整機能を提供します。
    - **全体オフセット調整**: 全行のタイムスタンプを一括で前後（例: `-0.5秒` / `-0.1秒` / `+0.1秒` / `+0.5秒` 等）へシフト調整（0 秒未満になる場合は `00:00.00` へ下限補正）。
    - **個別行の微調整・編集**: 特定行のタイムスタンプ微調整および歌詞テキストの手動修正（特に音声直接文字起こし結果の誤字修正に有効）。
- **対応言語の前提**:
  - 日本語・英語を中心とした多言語楽曲に対応します（言語自動判定に加え、必要に応じて日本語／英語等の言語指定により認識精度を安定させる運用を想定します）。
- **`.lrc` ファイル出力・上書き確認**:
  - **既定の保存先**: 対象楽曲の音声ファイルと **同じフォルダ・同じファイル名（拡張子 `.lrc`）** とします（例: `01_Song.flac` に対し `01_Song.lrc`）。
  - **出力フォーマット**: 文字コードは **UTF-8（BOM なし）**、タイムタグは標準形式 `[mm:ss.xx]` とし、楽曲メタデータから取得可能な範囲で `[ti:]`（曲名）・`[ar:]`（アーティスト名）・`[al:]`（アルバム名）ヘッダを付与します。
  - **既存 `.lrc` 上書き確認**: 保存先にすでに同名の `.lrc` ファイルが存在する場合は、無断上書きを行わず確認ダイアログ等でユーザーへ上書き可否を確認し、承諾された場合のみ上書き保存します。
  - **保存後の補助アクション**: 保存完了後に「保存先フォルダを開く」ボタンでエクスプローラーを開き、生成ファイルを確認できます。
- **同期歌詞表示パネル（#401）への即時反映**:
  - `.lrc` ファイルの保存が完了すると、Audio Effector 内の歌詞表示機能へ自動的に更新が通知されます。
  - 保存対象が現在再生中の楽曲である場合は、保存完了後にパネルヘッダーの「← 歌詞へ戻る」ボタン等で同期歌詞表示パネルへ戻る（または切り替える）ことで、今保存したばかりの同期歌詞が即座に読み込まれ、楽曲再生に連動したハイライト表示を開始できます。
  - コンテキストメニュー等から現在再生中ではない別楽曲を対象に `.lrc` を保存した場合は、対象楽曲の歌詞キャッシュを最新化し、次回その楽曲を再生した際に新しい同期歌詞が自動適用されます。

## 3. 利用手順（想定ワークフロー）

### 3.1. 歌詞テキストファイル（`.txt`）から LRC を自動生成する
1. 同期歌詞を作成したい楽曲を再生し、右側タブの歌詞パネルにある「LRC を自動生成する」（またはヘッダーの「LRC 自動生成／再生成」）ボタンをクリックします。
   - 右側タブが閉じている／最大化されている場合は、自動でコンパクト表示に切り替わり下部に LRC 自動生成パネルが開きます。
2. 初回利用でローカルモデルが未配置の場合は、画面の案内に従って無料モデルをダウンロード（または配置済みモデルファイルを指定）します。
3. 歌詞が書かれた `.txt` ファイルをファイル選択ボタンまたはドラッグ＆ドロップで指定します。
   - ファイルが **UTF-8** の場合はそのまま準備完了になります。
   - ファイルが **Shift-JIS 等の非 UTF-8** の場合は警告と変換確認が表示されるため、内容を確認して「UTF-8 に変換して続行」を承諾します（元の `.txt` ファイルは上書きされません）。
4. 「テキストから LRC を生成」ボタンをクリックします。
   - 処理中は進捗バーと現在のフェーズが表示され、必要に応じて「キャンセル」で中断できます。
5. 生成が完了したらプレビューでタイムタグを確認し、ズレがある場合は全体オフセット調整や個別行の修正を行います。
6. 「LRC を保存」ボタンをクリックします（同名の `.lrc` がすでにある場合は上書き確認で承諾します）。
7. 保存完了後、「歌詞表示へ戻る」をクリック（または自動連携で遷移）すると、右側タブの同期歌詞表示パネルへ生成した同期歌詞が即座に反映されます。

### 3.2. 歌詞テキストなしで音声から直接文字起こしして LRC を生成する
1. 歌詞テキストを用意していない楽曲を選択または再生し、LRC 自動生成パネルを開きます。
2. ローカルモデルが準備済みであることを確認し、テキストファイルを選択せずに **「音声から文字起こしして LRC を生成」ボタン** をクリックします。
3. 進捗バーとフェーズ表示を確認しながら文字起こし完了を待ちます（途中キャンセル可能）。
4. 生成された文字起こし結果とタイムタグをプレビューで確認し、誤変換やタイミングのズレがあれば個別行編集・全体オフセット調整で補正します。
5. 「LRC を保存」ボタンで楽曲と同フォルダへ `.lrc` ファイルを保存し、同期歌詞表示パネルへ即時反映して鑑賞します。
