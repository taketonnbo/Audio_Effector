# リスニング統計ダッシュボード 機能仕様書

## 1. 機能概要

「リスニング統計ダッシュボード」は、メイン画面右側パネル下部の 3 タブ構成（`歌詞` / `ダッシュボード` / `タグ`）の 1 つとして、対象楽曲の累計再生回数・累計再生時間・最終再生日時および**対象楽曲が所属するアルバム内の「アルバム内でよく聴く曲 TOP 5」**を素早く確認できる機能です。

左側メイン画面で管理するライブラリ全体のリスニング統計・ランキング（#453）と明確に役割分担し、右側タブでは現在再生中または選択中の楽曲・アルバムに紐づく統計のみを集約して表示します。

あわせて、従来の再生履歴ファイル（`RecentTracks.json`）を `ListeningStats.json` へ統合し、楽曲別の累計統計に加えて **日時毎の再生履歴イベント（`PlayEvents`）** を一元管理することで、後続のライブラリ全体統計・期間別ランキング（#453）および設定画面からの全リセット機能（#454）の共通永続化基盤を提供します。

## 2. ユーザー向け提供機能

### 2.1. 右側パネル 3 タブ統合とシンプル操作
- 右側パネル右上のボタンは **拡大／縮小ボタン（1 つ）** のみに整理します。
- **楽曲未再生時のガード**: 右側パネルの拡張領域は楽曲に紐づく情報を扱うため、楽曲未再生時は拡大／縮小ボタンからコンパクト拡張領域を開けません。
- 楽曲再生中に縮小ボタンをクリックするとコンパクト表示へ切り替わり、下部拡張領域の上部に 3 タブバー（`歌詞` / `ダッシュボード` / `タグ`）が表示されます（初期選択タブは `歌詞`）。

### 2.2. 右側プレイリストからのコンテキストメニュー導線
- 右側パネルの収録曲一覧（プレイリスト）の各楽曲行を右クリックすることで、再生中の曲に関係なく選択した曲を対象として該当タブへ直接遷移できます。
  - **ダッシュボードを表示**: 選択曲を対象として `ダッシュボード` タブを開き、その曲の統計情報を表示します。
  - **タグを表示**: 選択曲を対象として `タグ` タブを開きます（タグ管理本体は #124 で提供予定）。
  - **歌詞を編集（LRCエディタ）**: 選択曲を対象として LRC 自動生成・編集パネルを開きます。
- 再生中以外の曲を表示している間は「選択中の曲を表示中」バッジと「再生中の曲に戻す」ボタンが表示され、ワンクリックで現在再生中楽曲の表示へ戻せます。

### 2.3. 再生完了時の自動集計と永続化統合
- 楽曲の再生完了（`IAudioService.TrackPlaybackEnded`）時に、以下を自動更新して `%APPDATA%\AudioEffector\ListeningStats.json`（カスタムデータディレクトリ設定時は指定フォルダ配下）へ原子的に永続化します。
  - 対象楽曲の累計再生回数（`+1`）
  - 対象楽曲の累計再生時間（再生時間を加算）
  - 対象楽曲の最終再生日時（`LastPlayedAt`）
  - 日時毎の再生履歴イベント（`PlayedAt`, `FilePath`, `Title`, `Artist`, `Album`, `PlayedDuration`）
- 旧 `RecentTracks.json` が存在する環境では、初回読み込み時にデータ欠損なく `ListeningStats.json` へ自動マイグレーションされます。
- 左サイドバー「最近再生した曲（`RecentView`）」も統合後の `ListeningStats.json` を参照し、表示側のみ最新 100 件へ絞ることで全曲の統計および日時毎履歴を切り捨てずに既存互換性を維持します。また、「最近再生した曲」画面からの履歴 1 件削除・履歴クリアでは累計統計および日時毎履歴を保持します。統計全体の初期化は設定画面（「データ管理・その他」→「再生履歴・リスニング統計をすべてリセット」）から確認ダイアログ付きで実行でき、実行後は本ダッシュボード・「最近再生した曲」・左側「リスニング統計」の 3 画面へ即座に空状態が反映されます。

### 2.4. ダッシュボード表示項目
1. **対象楽曲ヘッダー**: タイトル・アーティスト・アルバム（再生中以外の曲を表示時はバッジ＋「再生中の曲に戻す」ボタン）。
2. **対象楽曲 KPI カード（3 項目）**:
   - 累計再生回数（例: `12 回`）
   - 累計再生時間（例: `48分 30秒` / `1時間 15分` / `0分`）
   - 最終再生日時（例: `2026/11/29 14:30` / 未再生時は `未再生`）
3. **アルバム内でよく聴く曲 TOP 5**:
   - 現在表示対象の楽曲（再生中曲または右側プレイリスト右クリック選択曲）が所属するアルバム内の楽曲のみを対象とし、累計再生回数降順で上位 5 曲（順位・曲名・アーティスト・再生回数・1 位比プログレスバー）を表示します。
   - 他アルバム（同名・別アーティストの別アルバムを含む）の楽曲は集計対象から除外されます。
   - 行クリックで同アルバム内の別楽曲を対象曲として KPI サマリをプレビュー確認でき、同アルバム内のランキング表示を維持します。
   - 別アルバムの楽曲へ切り替えた場合（再生曲変更・右クリック指定・再生中曲復帰）、ランキングも新しい対象アルバム内へ即座に追従します。
   - 対象アルバム内の統計未記録時および対象曲未設定時は適切なエンプティ案内を表示します。
