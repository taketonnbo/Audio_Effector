# 機能仕様書: 機器転送機能

## 1. 機能概要
機器転送機能は、PC上に登録されている楽曲ファイル（ライブラリ）を、USB接続されたポータブルオーディオプレーヤー（MTPデバイス）やUSBフラッシュメモリ等のリムーバブルドライブへ同期（コピー）するための機能です。
ユーザーは転送対象のアルバム・楽曲を直感的に選択し、接続されたデバイスの指定したフォルダ階層へ安全に楽曲データを書き込むことができます。

## 2. ユーザー向け提供機能

### 2.1 デバイスの検出と管理
- **画面切替時の自動デバイス検出と手動再検出**: 「機器転送（Device Sync）」画面へ切り替えた際に、PCに接続されているリムーバブルドライブおよびMTPポータブルデバイスを自動検出して接続先リストに表示します（あわせて画面下部のスペクトラムアナライザを自動格納し、作業領域を広く確保します）。また、画面上の「`↻ 機器を再検出`」ボタンから画面を切り替えずに接続機器を再検出できます。機器が未接続の場合は案内メッセージと再検出ボタンを表示します。
- **接続機器の詳細情報・空き容量表示**: 選択中の機器について、接続種別（`USB` / `MTP`）、総容量・空き容量、使用率プログレスバーを表示します（容量取得非対応のMTP機器では「容量情報取得不可」へ安全にフォールバックします）。
- **デバイス内エクスプローラー**: 接続したデバイスの内部フォルダ・ファイル構造をアプリ上で閲覧できます。フォルダをダブルクリックして下位階層へ移動したり、ナビゲーションバーの「`..`」ボタンで上の階層へ戻る、「`↻`」ボタンで現在のフォルダを再読み込みすることで、楽曲を転送したい目的のフォルダを指定できます。
- **機器ごとの既定転送先フォルダ記憶・自動選択**: ナビゲーションバーの「`☆ 既定` / `★ 既定`」ボタンから、現在表示中のフォルダをその機器固有の既定転送先フォルダとして登録・解除できます（`AppSettings.DeviceDefaultTransferFolders` に永続化）。次回同じ機器を接続・選択した際は自動的に登録済みフォルダへ遷移し、対象フォルダが削除・リネームされていた場合は安全にルートフォルダへフォールバックして通知を表示します。
- **デバイス内コンテンツ管理（「⚙ Manage」ダイアログ）**: 「⚙ Manage」ボタンからデバイス管理ダイアログを開き、デバイス上に転送済みのアルバムおよび収録トラックの一覧を確認し、不要になった楽曲やアルバム全体をデバイスから削除できます（アルバム内の最後の1曲を削除した場合は空になったアルバム・アーティストフォルダも自動的にクリーンアップされます）。

### 2.2 楽曲の選択（SELECT機能）
- **アルバム・楽曲の階層表示**: 転送候補となるPC内の楽曲は「アルバム単位」でグループ化して表示されます。アルバムを展開することで、収録されている「曲単位」のリストを確認できます。
- **選択サマリと空き容量予測**: 選択中のアルバム数・曲数・合計ファイルサイズおよび接続機器の空き容量との比較判定（`空き十分` / `容量不足`）をリアルタイムに表示します。
- **柔軟な選択方法**:
  - アルバムごと一括転送したい場合は、アルバム名の横にあるチェックボックスをONにします。アルバム内の一部の曲が既に転送済みの場合、未転送の曲のみが自動的に選択されます。
  - 特定の曲だけを転送したい場合は、アルバムを展開し、曲ごとのチェックボックスをONにします。
- **曲単位の高速重複判定と重複転送の防止**: ユーザーが選択中の転送先フォルダ（`CurrentDevicePath`）配下にある既存音声ファイルを非同期で一括インデックス化し（ルート直下では不要な全階層再帰走査を回避しつつ PC ライブラリ由来の既知の転送先候補フォルダのみ照合）、フォルダ名のファイル名禁止文字（`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|` および制御文字）を `_`（アンダースコア）へ置換し末尾ピリオド・空白を除去する保存時と同一規則で正規化した相対パス（`<Artist>\<Album>\<拡張子を除いたファイル名>`。`<Artist>` は PC ライブラリで解決したアルバムの代表アーティスト、互換のため旧配置の曲別アーティスト配下・旧禁止文字除去配置・旧末尾ピリオド保持配置・指定フォルダ直下配置ファイル名も認識、大文字・小文字非区別）ベースで高速かつ別アルバム間の誤衝突なく重複判定を行います。既に存在する曲（新配置・旧配置のいずれかに存在する場合を含む）は曲単位でチェックボックスが非活性・グレーアウトされ、同じアルバムの未転送曲のみを追加転送できます。アルバム内の全曲が転送済みの場合はアルバム全体のチェックボックスおよび表示も非活性・グレーアウトされます。デバイス未選択・切断時は既転送状態が自動リセットされ、転送完了時は再走査による状態反映完了後に完了通知および操作ロック解除を行います（デバイス管理ダイアログ終了時にも状態が自動更新されます）。転送実行時にも新配置・旧配置の既転送曲は自動的に除外されます。

### 2.3 転送実行とステータス管理
- **転送前確認・警告ダイアログ（空き容量不足・形式変換確認）**: 「TRANSFER SELECTED」押下時、転送開始前に以下の事前チェックを行い、該当する場合に確認・警告ダイアログを表示します。
  - **空き容量不足警告**: 選択した未転送楽曲の合計ファイルサイズ（形式変換 ON 時も元ファイルサイズ合計ベースの安全側概算）が接続機器の空き容量を超過している場合、選択曲数・必要容量・機器の空き容量・不足容量を警告アイコン付きで明示し、キャンセルまたは続行を選択できます（誤転送防止のため既定ボタンはキャンセル）。
  - **形式変換確認**: 設定で「MP4 → M4A 変換」または「FLAC → MP3 変換」が ON で、転送対象に変換対象曲が含まれる場合、変換形式別の曲数内訳（例: `FLAC → MP3: X 曲`、`MP4 → M4A: Y 曲`、`コピーのみ: Z 曲`）および処理に時間がかかる旨を表示して開始可否を確認します。
  - **1 ダイアログ統合と通常転送の即時開始**: 容量不足と形式変換の両方に該当する場合は 1 回のダイアログに両注意事項を統合表示して二重表示を防ぎます。空き容量が十分（または容量情報非対応）かつ形式変換対象がない通常転送では、確認ダイアログを表示せず即座に転送を開始します。
- **一括転送処理**: 選択したすべての楽曲を、「TRANSFER SELECTED」ボタン一つで指定したデバイスのフォルダ配下（`<Artist>\<Album>\` 階層、`<Artist>` は PC ライブラリで解決したアルバムの代表アーティスト。各曲の演奏者タグは保持）へ転送開始します。アルバム一括転送・1 曲ずつの追加転送・形式変換の有無にかかわらず、同一アルバムの楽曲は同じ代表アーティスト配下のアルバムフォルダに保存されます。
- **音声フォーマット自動変換転送（MP4 → M4A / FLAC → MP3）**: 設定画面の「データ管理・その他」カテゴリで「転送時に MP4 を M4A に変換する」または「転送時に FLAC を MP3 に変換してデータ量を削減する」を ON にしている場合、対象の `.mp4` を `.m4a`（AAC）へ、`.flac` を `.mp3`（320 kbps、ハイレゾ音源は自動リサンプル）へ Windows Media Foundation 経由で一時フォルダに変換し、メタデータ・カバーアートを引き継いだうえで転送します。変換用一時ファイルは転送完了・キャンセル・例外時に自動でクリーンアップされ、拡張子変換後の重複判定とも整合します。
- **同期歌詞ファイル（`.lrc`）の種別判別・同梱転送（Issue #442）**: 設定画面の「データ管理・その他」→「機器転送設定」にて、①自動生成以外（手動作成・外部取得等、`TransferManualLrcFiles`）、②テキストから自動生成（`TransferTextAlignedLrcFiles`）、③音声から自動文字起こし生成（`TransferTranscribedLrcFiles`）の 3 種別ごとに同梱有無を個別に ON/OFF できます（既定値はすべて OFF）。新規に音声ファイルを転送した際、同階層・同名の `.lrc` が存在すれば先頭メタデータ（LRC 標準 `[re:...]` タグ、未付与・他ツール値は自動生成以外へフォールバック）から生成元種別を判別し、該当種別が有効な場合のみ音声ファイルと同じ転送先フォルダへ変換後音声ファイルと同名ベース（`.lrc`）で同梱転送します（MTP・ファイルシステム両経路で統一）。なお、音声ファイルが重複スキップされた場合は `.lrc` も転送せず、`.lrc` は重複判定対象（音声拡張子）にも含めません。`.lrc` の読み込み・判定・転送で例外が発生した場合は警告ログのみ記録し、音声ファイル本体および後続トラックの転送を妨げません。
- **詳細進捗表示と転送の中止（キャンセル）**: 転送実行中は下部パネルにプログレスバー（0〜100%）、処理件数（`X / N 曲 (XX%)`）、現在処理中のファイル名、処理フェーズ（`変換中 (FLAC → MP3)...` / `変換中 (MP4 → M4A)...` / `コピー中...` / `スキップ中...`）、および「`✕ 転送を中止`」ボタン（キャンセル処理中は二重押下防止のため「`中止中...`」で非活性）を表示します。中止ボタン押下または転送中のアプリ終了確認で中断を選択した場合は、`CancellationTokenSource` を介して安全に中断し、変換用一時ファイルおよび書き込み途中の不完全ファイルを確実にクリーンアップします。
- **1 曲単位エラー個別ハンドリングと転送結果サマリ表示**: 各楽曲の変換・転送は 1 曲単位で個別に例外ハンドリングされ、特定の 1 曲でファイル不在・変換エラー・個別書き込みエラーが発生しても `NLog` へログ出力のうえ残りの楽曲の転送を継続します（ただしデバイス切断や転送先フォルダ消失など回復不能エラー発生時は安全に中断します）。転送完了・キャンセル・中断後は、成功件数・スキップ件数（重複済み）・失敗件数（失敗曲がある場合は曲名とエラー理由の一覧を含む）をまとめた結果サマリダイアログ（`TransferResultDialog`）を表示し、転送済み楽曲の `IsOnDevice` 状態・ディレクトリ表示・空き容量情報を最新化します。
- **安全保護機能**: データ破損を防ぐため、転送処理中はデバイス切替・フォルダ移動・選択操作がロックされ、転送ボタンも「`TRANSFERRING...`」に変化します。また、転送中にアプリのメインウィンドウを閉じようとした場合は、中断確認ダイアログを表示し、終了を選択した際は進行中の転送を安全にキャンセルしてから終了します。

## 3. 利用手順（想定ワークフロー）
1. PCに転送先のデバイス（USBメモリやMTPプレーヤー等）を接続します。
2. 左サイドバーから「機器転送（Device Sync）」を開きます。
3. 画面上部で、転送先のデバイスと保存したいフォルダ階層を選択します。
4. 画面下部で、PC側のライブラリから転送したいアルバムまたは曲にチェックを入れます。
5. 画面最下部の「TRANSFER SELECTED」ボタンをクリックし、転送を開始します。
6. 転送が完了し、既にデバイス上にあるアルバムがグレーアウト状態に更新されたら、必要に応じて「⚙ Manage」から転送済み楽曲を確認・整理できます。
