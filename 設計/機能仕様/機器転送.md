# 機能仕様書: 機器転送機能

## 1. 機能概要
機器転送機能は、PC上に登録されている楽曲ファイル（ライブラリ）を、USB接続されたポータブルオーディオプレーヤーやUSBフラッシュメモリ等の外部デバイスへ同期（コピー）するための機能です。
ユーザーは転送対象の楽曲を直感的に選択し、接続されたデバイスの指定したフォルダ階層へ安全に楽曲データを書き込むことができます。

## 2. ユーザー向け提供機能

### 2.1 デバイスの検出と管理
- **自動デバイス検出**: PCに新しい外部デバイス（USBメディアなど）が接続された際、または画面を切り替えた際に、自動的にデバイスを検出して接続先リストに表示します。
- **デバイス内エクスプローラー**: 接続したデバイスの内部フォルダ構造をアプリ上で閲覧できます。ユーザーはダブルクリックでフォルダの奥へ進んだり、ナビゲーションバーの「..」ボタンで上の階層へ戻ることで、楽曲を転送したい目的のフォルダを自由に指定できます。
- **デバイス管理**: 「⚙ Manage」ボタンから、接続したデバイスのフォーマットやストレージ使用量の確認など、デバイス自体の管理操作へアクセスできます。

### 2.2 楽曲の選択（SELECT機能）
- **アルバム・楽曲の階層表示**: 転送候補となるPC内の楽曲は「アルバム単位」でグループ化して表示されます。アルバムを展開することで、その中に含まれる「曲単位」のリストを確認できます。
- **柔軟な選択方法**:
  - アルバムごと一括転送したい場合は、アルバム名の横にあるチェックボックスをONにします。
  - 特定の曲だけを転送したい場合は、アルバムを展開し、曲ごとのチェックボックスをONにします。
- **重複転送の防止**: すでに接続先デバイス内に保存されている楽曲やアルバムについては、チェックボックスがグレーアウトし選択できない状態になるため、誤って同じ曲を二重に転送してしまうことを防ぎます。

### 2.3 転送実行とステータス管理
- **一括転送処理**: 選択したすべての楽曲を、「TRANSFER SELECTED」ボタン一つで指定したデバイスのフォルダへ転送開始します。
- **進捗フィードバック**: 転送が始まると、進行状況が「Transferring: XX%」のようにリアルタイムで画面上に表示されます。
- **安全保護機能**: データ破損を防ぐため、楽曲の転送処理中は別の楽曲を選択したり、別のフォルダへ移動するなどの操作が自動的にロックされます。転送ボタンも「TRANSFERRING...」に変化し、処理の完了をユーザーに伝えます。

## 3. 利用手順（想定ワークフロー）
1. PCに転送先のデバイス（USBメモリ等）を接続します。
2. アプリの「機器転送（Device Sync）」タブを開きます。
3. 画面上部で、転送先のデバイスと保存したいフォルダ階層を選択します。
4. 画面下部で、PC側のライブラリから転送したいアルバムまたは曲にチェックを入れます。
5. 画面最下部の「TRANSFER SELECTED」ボタンをクリックし、転送を開始します。
6. 進捗が100%になり完了表示が出たら、安全にデバイスを取り外すことができます。
