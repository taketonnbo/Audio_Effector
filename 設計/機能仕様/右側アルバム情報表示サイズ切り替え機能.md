# 右側アルバム情報表示サイズ切り替え機能 仕様書

## 1. 機能概要
「右側アルバム情報表示サイズ切り替え機能」は、メイン画面の右側パネルに表示されているアルバム情報・プレイヤー領域の表示サイズを、ユーザーの好みに応じてワンクリックで切り替える機能です。
ユーザーは「通常表示」「最大化表示（全画面）」「最小化表示（コンパクト）」の3段階を切り替えることで、収録曲リストをじっくり確認したい時や、下半分の拡張タブ（今後追加されるリスニング統計やタグ管理など）を広く使いたい時など、用途に応じた最適なレイアウトで快適に音楽鑑賞・管理を行えます。

---

## 2. ユーザー向け提供機能

### 2.1. 3段階の表示モード切り替え
右側パネル上部の操作ボタンをクリックすることで、以下の3つの表示モードを切り替えることができます。

- **通常表示（デフォルト）**
  - 右側パネルの上半分にアルバム情報（ジャケット画像、タイトル、アーティスト名、品質情報、収録曲リスト、プレイヤーコントロール）を表示し、下半分に拡張情報タブ領域を表示します。
  - 基本的なアルバム情報の閲覧と、下部の拡張機能の利用をバランスよく両立した標準レイアウトです。
- **最大化表示（全画面）**
  - 右側パネルの縦幅全体をアルバム情報・プレイヤー領域として使用します（下半分の拡張タブ領域は非表示・折りたたみ）。
  - パネル内は**左右2カラム構成**となり、左側に特大のアルバムアートと各種操作コントロール、右側に縦いっぱいのトラックリストを展開します。
- **最小化表示（コンパクト）**
  - 収録曲リストを非表示にし、アルバムアート、曲名・アーティスト名、音質情報（ハイレゾバッジ、ビットレート/サンプリング周波数等）、および基本的な再生コントロールのみを表示します。
  - プレイヤーとしての最小限の情報を維持したまま高さを極小化し、下半分の拡張タブ領域を最大化して広々と利用できるようにします。

---

### 2.2. 最大化表示時の構成要素とプレイヤー機能
最大化表示時は、画面の広さを活かして以下の要素を左右に効率よく配置します。

#### ① 左側領域（アートワーク・基本情報・楽曲操作コントロール）
- **特大アルバムアート**: 正方形アスペクト比を維持した大迫力のジャケット画像。
- **アルバム名称・アーティスト名称**: 視認性の高いタイポグラフィで表示。
- **音質・フォーマット詳細情報**: ビットレート、サンプリングレート、フォーマット（MP4, FLAC等）、Hi-Resバッジ等の詳細スペック。
- **シークバー＆再生時間**:
  - 現在の再生位置を示すシアンのプログレスバー。
  - 現在再生時間および総再生時間の表示（例: `00:59 / 04:34`）。
  - 現在再生中の曲名表示。
- **プレイヤー操作系（楽曲コントロール群）**:
  - **シャッフル再生 (`Shuffle`)**: アルバム収録曲の再生順をランダム化。
  - **前へ (`Previous`)**: 前の曲へスキップ、または曲の先頭へシーク。
  - **再生 / 一時停止 / 停止 (`Play / Pause / Stop`)**: 楽曲の再生と一時停止・停止。
  - **次へ (`Next`)**: 次の曲へスキップ。
  - **リピート再生 (`Repeat`)**: アルバムリピート / 1曲リピートの切り替え。
  - **再生リストキュー表示 (`Play Queue`)**: 現在の再生キュー一覧を展開・確認。
  - **プレイリスト追加 (`Add to Playlist` / `＋`)**: 現在再生中の曲を任意のプレイリストへ追加。
  - **お気に入り追加/解除 (`Favorite` / `♥`)**: 現在再生中の曲をお気に入り（Favorites）へワンクリックで登録/解除。

#### ② 右側領域（トラックリスト・ステータス）
- **アルバム総トラック数表示**: アルバム内に収録されている全曲数を明記（例: `Tracklist (9 tracks)`）。
- **フルハイトトラックリスト**: 縦スクロール対応で全曲を一望できる一覧。
  - **曲番号**: 2桁ゼロ埋め表記（例: `01.`）。
  - **曲名**: トラックのタイトル。
  - **再生時間**: 曲の長さ（例: `03:45`）。
  - **再生ステータス表示**:
    - **再生中**: 再生中を示すアイコン（`▶` / イコライザー波形）をアクセントカラー（シアン）で点灯表示。
    - **一時停止中**: 停止中を示すアイコン（`⏸`）を表示。

---

### 2.3. 直感的なサイズ切り替えコントロール
- 右側パネルのヘッダー部（またはコントローラー部）に、現在の状態に応じた切り替えボタン（最大化・最小化・元に戻すアイコン）が配置され、ワンクリックで目的のサイズへスムーズに切り替えることができます。
- 切り替え時はレイアウトがスムーズに伸縮し、視覚的に違和感のない遷移を実現します。

---

## 3. 利用手順（想定ワークフロー）

### 3.1. 収録曲リストを広く見たい場合（最大化）
1. 右側パネルが開いている状態で、アルバム情報エリアの「最大化」ボタンをクリックします。
2. 下半分の領域が折りたたまれ、右側パネル全体に左右2カラムの最大化レイアウトが広がります。
3. 左側の大きなアルバムアートを見ながら、右側のトラックリストで全曲数や各曲の再生時間を確認し、聴きたい曲を選曲します。
4. 下部の操作バーから、シャッフル再生やリピート再生、お気に入り登録（♥）、プレイリストへの追加（＋）、キューの確認（≡）をスムーズに行います。
5. 元のレイアウトに戻したい場合は、「元に戻す（通常表示）」ボタンをクリックします。

### 3.2. 下側の拡張情報（統計・タグなど）を広く使いたい場合（最小化）
1. 右側パネルが開いている状態で、アルバム情報エリアの「最小化」ボタンをクリックします。
2. トラックリストが非表示となり、アルバムアートと音質情報・再生コントロールのみのコンパクトな表示になります。
3. 下半分の拡張機能エリアが上に大きく広がり、広大なスペースで詳細情報（リスニング統計グラフやタグクラウドなど）を快適に操作・閲覧します。
4. 再びトラックリストを表示したい場合は、「通常表示」ボタンをクリックして元のサイズに戻します。
