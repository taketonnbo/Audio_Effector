# 右側アルバム情報表示サイズ切り替え機能 仕様書

## 1. 機能概要
「右側アルバム情報表示サイズ切り替え機能」は、メイン画面の右側パネルに表示されているアルバム情報・プレイヤー領域の表示サイズを、ユーザーの好みに応じてワンクリックで「最大化（全画面）」と「最小化（コンパクト）」の2段階に切り替える機能です。
ユーザーはアルバム鑑賞に没頭したい時（最大化）と、プレイヤー領域を上部にコンパクト化して下部領域を広く確保したい時（最小化）をシンプルなトグル操作で瞬時に切り替えられます。

さらに、スペクトラムアナライザの開閉状態と連動してアルバムアートの表示サイズを動的に切り替え、画面下部の余白を解消してスペースを有効活用します。

---

## 2. ユーザー向け提供機能

### 2.1. 2段階の表示モード切り替え（2値トグル）
右側パネル右上の切り替えボタンをクリックすることで、以下の2つの表示モードを交互に切り替えることができます（初期状態は最大化表示）。

- **最大化表示（全画面モード: `IsAlbumViewMaximized = true`）**
  - 右側パネルの縦幅全体をアルバム情報・プレイヤー領域として使用します。
  - パネル内は**左右2カラム構成**となり、左側にアルバムアートとPlayer Pod（再生操作カード）、右側に縦いっぱいの収録トラックリストを展開します。
- **最小化表示（コンパクトモード: `IsAlbumViewMaximized = false`）**
  - トラックリストを非表示にし、アルバムアートサムネイル、曲名・アーティスト名、音質情報（Hi-Res / Losslessバッジ、フォーマット詳細）、および楽曲操作コントロールを上部にコンパクトに集約します。
  - 下部には拡張用の予約領域（関連Issue #121, #123, #124, #130）が展開されます。

---

### 2.2. 各表示モードの構成要素

#### 🎵 最大化表示時の構成要素（左右2カラム）
- **① 左側領域（アートワーク・基本情報・Player Pod）**:
  - **動的アルバムアート（多層メタリックベゼル・深層ソフトシャドウ・アナライザ連動伸縮）**:
    - 最外周ハイライトエッジ、削り出しメタリックベゼル、および内周ハイライトエッジからなる多層額装構造と、テーマ連動の深層立体ソフトシャドウ（`AlbumArtDropShadowEffect`）により立体感を演出します。
    - スペクトラムアナライザの開閉動作と連動し、イージングアニメーションによってアートサイズが滑らかに伸縮します。
  - **アルバム基本情報**:
    - 選択中のアルバム/再生リスト名称（ホバー連動マーキー対応）、サブタイトル（アーティスト名、マーキー対応）、および音質バッジ（`Hi-Res` / `Lossless`）。
  - **メタリック調プレイヤーカード（Player Pod）**:
    - メタリックグラデーションとカードシャドウ（`CardDropShadowEffect`）を施した操作カード内に、現在再生中の曲名（マーキー対応）、クイックアクション（プレイリスト追加・お気に入り・再生キュー）、再生操作5ボタン、およびワイドシークバーと再生時間/総時間を集約します。
- **② 右側領域（フルハイト・トラックリスト）**:
  - **メタリック調カードコンテナ**:
    - トラックリスト全体をメタリックグラデーションコンテナで囲み、左側のPlayer Podと統一感を演出します。
  - **ヘッダー表示**:
    - `Playlist: <リスト名>` 形式のヘッダータイトルと、右端に `<N> Tracks` 形式の曲数を表示します（空の場合は「プレイリストは空です」を表示）。
  - **フルハイトトラックリスト**:
    - **テーマ連動ゼブラストライプ**: 奇数行に `ZebraOddBackgroundBrush`（Dark: 約7%白透過 `#12FFFFFF` / Light: 約5%黒透過 `#0C000000`）を適用し、テーマ切り替え時にも即時追従します。
    - **曲番号と再生/一時停止アイコンのインライン統合**:
      - 通常時は2桁ゼロ埋め曲番号（例: `01.`）、再生中はシアンの再生アイコン（`▶`）、一時停止中は一時停止アイコン（`⏸`）を同一カラム内で切り替えます。
    - **曲名・再生時間**: トラックタイトル（ホバー連動マーキー対応、再生中はシアン強調）と再生時間（`mm:ss`）。
  - **楽曲クリック・右クリック操作**:
    - 再生中の楽曲をクリックすると一時停止、一時停止中の楽曲をクリックすると再生再開、別楽曲をクリックすると新規再生を開始します。
    - 右クリックメニューから、再生・次に再生・最後に再生・お気に入り切替・プレイリスト追加・ダッシュボードを表示・タグを表示・歌詞を編集（LRCエディタ）・プロパティ・ファイルの場所を開く・削除を実行できます。

#### 📦 最小化表示時の構成要素（コンパクトプレイヤー）
- **上部コンパクトプレイヤー領域**:
  - 小型アルバムアート（50×50px）、曲名・アーティスト名（マーキー対応）、音質バッジ・フォーマット詳細、再生操作5ボタン、シークバー＆再生時間、プレイリスト追加・お気に入り・再生キューボタンを上部に集約表示します。
- **下部拡張領域（3タブ構成）**:
  - 下部拡張領域の上部に 3 タブバー（`歌詞` / `ダッシュボード` / `タグ`）を配置し、`LyricsView`（および LRC 自動生成・編集パネル `LrcGeneratorView`）、`ListeningStatsView`（リスニング統計ダッシュボード）、タグパネルを排他表示します。

---

### 2.3. トグル操作
- 右側パネルの右上端に「最大化/最小化切り替えボタン」の 1 つだけを常時固定配置します（楽曲未再生時はコンパクト表示へ開けないガード付き）。
  - 最大化時: 縮小アイコンをクリックで最小化（コンパクトモード＋3タブ拡張領域）へ切り替え。
  - 最小化時: 拡大アイコンをクリックで最大化（全画面モード）へ切り替え。

---

## 3. 利用手順（想定ワークフロー）

1. 右側パネルを開いた状態（初期状態は最大化モード）でアルバムを再生すると、左側に特大アルバムアートとPlayer Pod、右側に収録曲リストが表示されます。
2. スペクトラムアナライザを開閉すると、アルバムアートのサイズが滑らかに伸縮し、画面内に美しく収まります。
3. 右上の切り替えボタンをクリックすると、トラックリストが折りたたまれ、上部のコンパクトプレイヤーへと瞬時に切り替わります。
4. 再度右上の切り替えボタンをクリックすると、左右2カラムの最大化レイアウトへ戻ります。
