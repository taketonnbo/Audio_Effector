# 右側アルバム情報表示サイズ切り替え機能 仕様書

## 1. 機能概要
「右側アルバム情報表示サイズ切り替え機能」は、メイン画面の右側パネルに表示されているアルバム情報・プレイヤー領域の表示サイズを、ユーザーの好みに応じてワンクリックで切り替える機能です。
ユーザーは「通常表示」「最大化表示（全画面）」「最小化表示（コンパクト）」の3段階を切り替えることで、収録曲リストをじっくり確認したい時や、下半分の拡張タブ（今後追加されるリスニング統計やタグ管理など）を広く使いたい時など、用途に応じた最適なレイアウトで快適に音楽鑑賞・管理を行えます。

## 2. ユーザー向け提供機能

### 2.1. 3段階の表示モード切り替え
右側パネル上部の操作ボタンをクリックすることで、以下の3つの表示モードを切り替えることができます。

- **通常表示（デフォルト）**
  - 右側パネルの上半分にアルバム情報（ジャケット画像、タイトル、アーティスト名、品質情報、収録曲リスト、プレイヤーコントロール）を表示し、下半分に拡張情報タブ領域を表示します。
  - 基本的なアルバム情報の閲覧と、下部の拡張機能の利用をバランスよく両立した標準レイアウトです。
- **最大化表示（全画面）**
  - 右側パネルの縦幅全体をアルバム情報の表示に使用します。
  - 下半分の拡張タブ領域を非表示（折りたたみ）にし、収録曲リスト（トラックリスト）の表示領域を縦いっぱいに広げます。曲数の多いアルバムでも一覧性が大幅に向上し、スムーズに選曲・確認が可能です。
- **最小化表示（コンパクト）**
  - 収録曲リストを非表示にし、アルバムアート、曲名・アーティスト名、音質情報（ハイレゾバッジ、ビットレート/サンプリング周波数等）、および基本的な再生コントロールのみを表示します。
  - プレイヤーとしての最小限の情報を維持したまま高さを極小化し、下半分の拡張タブ領域を最大化して広々と利用できるようにします。

### 2.2. 直感的なサイズ切り替えコントロール
- 右側パネルのヘッダー部（またはコントローラー部）に、現在の状態に応じた切り替えボタン（最大化・最小化・元に戻すアイコン）が配置され、ワンクリックで目的のサイズへスムーズに切り替えることができます。
- 切り替え時はレイアウトがスムーズに伸縮し、視覚的に違和感のない遷移を実現します。

## 3. 利用手順（想定ワークフロー）

### 3.1. 収録曲リストを広く見たい場合（最大化）
1. 右側パネルが開いている状態で、アルバム情報エリアの「最大化」ボタンをクリックします。
2. 下半分の領域が折りたたまれ、右側パネル全体にアルバム情報とトラックリストが広がります。
3. 長いトラックリストを一目で確認し、聴きたい曲を素早く選曲・再生します。
4. 元のレイアウトに戻したい場合は、「元に戻す（通常表示）」ボタンをクリックします。

### 3.2. 下側の拡張情報（統計・タグなど）を広く使いたい場合（最小化）
1. 右側パネルが開いている状態で、アルバム情報エリアの「最小化」ボタンをクリックします。
2. トラックリストが非表示となり、アルバムアートと音質情報・再生コントロールのみのコンパクトな表示になります。
3. 下半分の拡張機能エリアが上に大きく広がり、広大なスペースで詳細情報（リスニング統計グラフやタグクラウドなど）を快適に操作・閲覧します。
4. 再びトラックリストを表示したい場合は、「通常表示」ボタンをクリックして元のサイズに戻します。
