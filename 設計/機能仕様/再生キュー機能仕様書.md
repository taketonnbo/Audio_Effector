# 再生キュー機能仕様書

## 1. 機能概要
本機能は、ユーザーが次に聴きたい楽曲を柔軟に整理・管理し、自分だけのリスニングフローを自由に組み立てるための「再生キュー（Play Queue）」機能です。

単曲やお気に入りのアルバム全体をキューに追加・挿入できるだけでなく、アルバムの途中の楽曲から聴き始めたり、シャッフル再生・リピート再生と視覚的かつ直感的に連動させることができます。さらに、再生が完了した楽曲を振り返ることができる「履歴」タブや、ドラッグ＆ドロップによる直感的な曲順変更を提供し、ストレスのない音楽鑑賞体験を実現します。

---

## 2. ユーザー向け提供機能

### 2.1 再生キュー一覧表示と「再生リスト／履歴」タブ切り替え
- **再生リスト（キュー）表示**:
  - 現在再生予定の楽曲リストが縦一列に整然と一覧表示されます。
  - 現在再生中の楽曲には、アルバムアート上に水色ネオンの再生アイコンが表示され、一目で再生状態を把握できます。
  - 各楽曲カードには、アルバムアートサムネイル、楽曲タイトル、アーティスト名、および再生時間が表示されます。
- **「再生リスト」と「履歴」のタブ切り替え**:
  - パネル上部のタブにより、「再生リスト」と「履歴」をワンクリックで切り替えることができます。
  - 各タブには現在の登録件数が `再生リスト (5)` `履歴 (12)` のように表示されます。
- **再生履歴の自動蓄積と活用**:
  - 楽曲の再生が終了した際、その楽曲は自動的に「履歴」リストへ格納・蓄積されます。
  - 履歴タブを開くことで、過去に聴いた楽曲を時系列で振り返ることができます。
  - 履歴内の楽曲を右クリックして「今すぐ再生」「次に再生」「再生リストに追加」を選択することで、過去に聴いた曲を簡単に再利用できます。
  - 履歴リスト右上の「履歴をクリア」ボタンにより、ワンクリックで全履歴を消去できます。

### 2.2 楽曲およびアルバムのキュー追加・再生
- **単曲の追加・挿入**:
  - 楽曲カードやリストの右クリックメニューから「次に再生」を選択すると、現在再生中の楽曲の直後に挿入され、最優先で次回再生されます。
  - 「キューに追加」を選択すると、再生キューの末尾に追加されます。
- **アルバム全体の再生**:
  - アルバムの「再生」ボタンをクリックすると、既存のキューを置き換えてアルバム全曲がキューにセットされます。
  - **通常時（シャッフルOFF）**: トラック1から順にキューに並び、1曲目から再生が開始されます。
  - **シャッフルON時**: **アルバム内から最初の1曲目がランダムに選定されて再生を開始**し、残りの曲もランダムにシャッフルされた順序でキューに展開されます（常にトラック1から始まらない自然なシャッフル再生）。
- **アルバム収録曲の途中トラックからの再生**:
  - アルバムトレイや詳細画面から特定のトラック（例: No.5）をクリックして再生を開始した場合、**その曲より前のNo（No.1〜No.4）の曲はキューに追加されません**。
  - **通常時（シャッフルOFF）**: 選択したトラック（No.5）およびそれ以降のトラック（No.5〜末尾）が元の曲順でキューにセットされ、No.5から末尾に向かって再生が進みます。
  - **シャッフルON時**: **選択したトラック（No.5）が先頭（現在再生曲）に固定され、後続のトラック（No.6〜末尾）のみがシャッフルされてキューに追加**されます。
- **アルバム単位の「次に再生」「キューに追加」**:
  - アルバムの右クリックメニューから「次に再生」を選択すると、アルバム収録曲（全曲または指定以降）が元の曲順を維持したまま、現在曲の直後にまとめて一括挿入されます。
  - 「キューに追加」を選択すると、アルバム収録曲がキューに追加されます。

### 2.3 シャッフル再生とキューの完全連動
- **シャッフルON時のキュー順序連動**:
  - プレイヤーのシャッフルボタンをONにすると、内部の再生順序だけでなく、**再生キュー画面のリスト自体の並び順がシャッフル再生順にリアルタイムで並び替えられます**。
  - これにより、「次にどの曲が流れるか」をキューの上から順に見るだけで正確に把握できます。
  - 現在再生中の楽曲はリストの現在位置（先頭）に保持され、再生が途切れることはありません。
- **シャッフルOFF時の元順序復元（穴あき復元仕様・複数アルバム対応）**:
  - アルバムなどの再生中にシャッフルボタンをOFFにした場合、元のアルバム収録順（または元の登録順）に再生キューの順番を戻します。
  - **現在再生中楽曲の配置**: 現在再生中の楽曲が復元後キューの先頭となり、音途切れなく再生を継続します。
  - **複数アルバム混在時のアルバム単位グループ復元**: 再生キューに複数アルバム（例: アルバムA, B, C）が含まれている場合でも、シャッフルOFF時には**キューに追加した順（A → B → C）でアルバムごとにまとまり**、各アルバム内は元のトラック順で整列復元されます。シャッフル再生によって楽曲がランダムに混ざり合っていた場合でも、シャッフルOFFによってアルバムごとの自然なリスニング順序に再整理されます。
  - **現在曲より前の曲（未再生）の除外**: 元の順序において現在再生中の曲より前の曲（先行するアルバムの未再生曲含む）は、未再生であれば「履歴」には入れず、再生キューから削除します。
  - **再生済み曲の穴あき（除外）処理**: シャッフル再生によって、現在再生中の曲より後の曲（同一アルバムの後続曲や後続アルバムの曲）が既に再生されて「履歴」に入っている場合、履歴はそのまま保持し、再生キュー側はその曲を穴あき（除外）としてスキップし、未再生の曲のみが元のアルバム順・トラック順でキューに並びます。
  - **再生済み履歴の保持**: 再生済みの楽曲は、シャッフル解除時もそのまま「履歴」タブに残ります。
- **シャッフル再生中の追加操作の振る舞い**:
  - **「次に再生」**: 
    - 単曲追加時: 現在再生中楽曲の直後に挿入されます。
    - **アルバム単位追加時**: **アルバム内の楽曲の順番がランダム（シャッフル）な状態で、まとめて現在再生中の楽曲の直後に追加**されます（アルバムの塊として現在曲直後に割り込み、他の既存キューの順序は崩さず維持）。
  - **「キューに追加」**: 追加された楽曲群（単曲またはアルバム）を含め、**現在再生中以外の全キューリストがランダムに再シャッフル**されてキュー内に均一に散りばめられます。

### 2.4 リピート再生（全曲リピート / OFF）
- **リピートOFF**:
  - キューの最後の楽曲が終了した時点で、自動的に再生が停止し、プレイヤーは待機状態になります。
- **全曲リピート**:
  - キューの最後の楽曲が終了した際、自動的にキュー先頭（1曲目）へ戻ってシームレスにループ再生を継続します。
  - シャッフル再生中も、現在のシャッフル順序を維持したまま先頭に戻ってループ再生されます。

### 2.5 再生キューの編集・並び替え
- **ドラッグ＆ドロップによる自由な並び替え**:
  - キュー内の任意の楽曲カードをドラッグ＆ドロップすることで、再生順を自由に上下へ入れ替えることができます。
  - シャッフル再生中であっても、ユーザーが手動で並び替えた順序が最優先され、即座に次の再生順に反映されます。
- **楽曲の個別削除**:
  - 各カードの右端にある「×」ボタン、または右クリックメニューの「キューから削除」をクリックすることで、特定の楽曲をキューから除外できます。
- **キューの全クリア**:
  - パネル右上のゴミ箱アイコンをクリックすることで、キュー内のすべての楽曲を一括消去できます。

### 2.6 再生キューが空（Empty）の際の振る舞い
- **キューが空の状態で「再生」ボタンを押下**:
  - 予期せぬ楽曲が突然鳴り出すのを防ぐため、音声再生は開始されず停止状態を維持します。
  - パネル中央に「再生キューは空です」「楽曲やアルバムを右クリックして『キューに追加』できます」という視覚的ガイドメッセージが表示されます。
- **再生中の楽曲をキューから削除した場合**:
  - キュー内に後続曲が存在する場合: 削除された曲の次の曲へ自動的に遷移して再生を継続します。
  - キュー内の最後の1曲（再生中だった曲）が削除された場合: **即座に音声を停止**し、プレイヤーの再生状態を停止、現在曲表示を未選択状態にクリアします。
- **再生中に「すべてクリア」を実行した場合**:
  - 音声再生を即座に停止し、キューおよび現在曲表示をクリアします。

## 3. 利用手順（想定ワークフロー）

### 3.1 楽曲・アルバムをキューに追加して楽しむ
1. ライブラリ画面でお気に入りのアルバムを右クリックし、「アルバムを再生」を選択します。
2. アルバムの全曲が再生キューにセットされ、1曲目から音楽が流れます。
3. 画面下部または右上の「Play Queue」ボタンをクリックし、再生キュースライドパネルを展開します。
4. ライブラリから別の楽曲を右クリックして「次に再生」を選択すると、現在曲のすぐ下にその曲が挿入され、次に再生されることを確認します。
5. 別のアルバムを右クリックして「キューに追加」を選択すると、キューの末尾にそのアルバムの楽曲群が追加されます。

### 3.2 アルバムの途中曲から聴き始め、シャッフル再生を活用する
1. アルバム詳細を開き、5曲目をダブルクリックまたは再生ボタンをクリックします。
2. 5曲目より前の1〜4曲目は除外され、5曲目からアルバム末尾までの曲がキューに追加されて再生が始まります。
3. プレイヤーの「シャッフル」ボタンをONにします。
4. 再生キューパネル内のリストが、現在再生中の5曲目を先頭に保ったまま、後続の曲がランダムな再生順に並び変わります。
5. シャッフルボタンを再度OFFにすると、元のトラック番号順にリストが復元されます（既にシャッフル中に再生済みの曲は「履歴」に残したままキューからは穴あき除外され、現在曲より前の未再生曲も除外された状態で、未再生の後続曲のみが元の収録順で並びます）。

### 3.3 曲順を手動で調整し、再生履歴を振り返る
1. 再生キューパネル内で、下の方にある楽曲を上の方へドラッグ＆ドロップして好みの位置へ移動します。
2. 楽曲の再生が完了すると、その楽曲は再生リストから消え、「履歴」タブへ自動的に追加されます。
3. パネル上部の「履歴」タブをクリックし、先ほど聴き終えた楽曲が表示されていることを確認します。
4. 履歴の中の曲を右クリックして「今すぐ再生」を選択すると、その楽曲が再びキューに追加されて再生されます。
