# 再生キュー機能仕様書

## 1. 機能概要
本機能は、ユーザーが次に聴きたい楽曲を柔軟に整理・管理し、自分だけのリスニングフローを直感的かつストレスフリーに組み立てるための「再生キュー（Play Queue）」機能です。

単曲やアルバム全体をキューに追加・挿入できるだけでなく、アルバムの途中の楽曲から聴き始めたり、シャッフル再生・リピート再生と連動させることができます。さらに、**「予約キュー」と「アルバムの残り曲」のセクション分離モデル**、現在再生中楽曲を除外した未再生キュー表示、再生が終了した楽曲を自動記録する「履歴」タブ、およびアルバム単位での連続再生を提供します。

---

## 2. ユーザー向け提供機能

### 2.1 セクション分離モデルとキュー一覧表示
- **セクション分離モデル（予約キュー／アルバムの残り曲）**:
  - 再生リスト（キュー）は、ユーザーの追加意図を尊重するため、以下の2つの独立したセクションで分離・整理されて表示されます。
    1. **予約キュー（ユーザーキュー）**: ユーザーが「次に再生」などで意図的に割り込ませた楽曲群。アルバムの残り曲よりも最優先で順次再生されます。
    2. **アルバムの残り曲（アルバムキュー）**: 現在再生中のアルバムまたは再生リストにおける未再生の後続曲群。予約キューが空になると自動的にこちらの曲へ再生が移行します。
  - 予約キューの見出しには `予約キュー (N)` のように件数が表示され、右端の「予約をクリア」ボタンによりアルバムの残り曲を維持したまま予約キューのみを消去できます。
  - アルバムの残り曲の見出しには `次のアルバムから: <リスト名>`（未選択時は `アルバムの残り曲`）と右端に `残り N 曲` が表示されます。
- **未再生リスト表示**:
  - 再生リスト内には**現在再生中の楽曲は表示せず、これから再生予定の未再生楽曲のみを表示**します。
  - 楽曲の再生が開始されるとキューから自動的に取り除かれ、次の曲へ再生予定が繰り上がります。
- **「再生リスト」と「履歴」のタブ切り替え**:
  - パネル上部のタブにより、「再生リスト」と「履歴」をワンクリックで切り替えることができます。
  - 各タブには現在の登録件数が `再生リスト (10)` `履歴 (12)` のように表示されます。
- **再生履歴タブの自動蓄積と活用**:
  - 楽曲の再生終了・次曲スキップ・別曲切替・停止時に、直前の楽曲が自動的に「履歴」タブへ格納・蓄積されます（インメモリ保持、最新順、重複曲は先頭へ再配置、最大100件）。
  - ※ サイドバーの「最近再生した曲」（JSON永続化・再生開始時記録）とは独立したセッション履歴として機能します。
  - **履歴からの即時再生と自動タブ遷移**:
    - 履歴内の楽曲をクリック、または右クリックメニューから「再生」を選択すると、**該当曲が即座に再生開始され、自動的に「再生リスト」タブへ切り替わります**。
  - 履歴内の楽曲を右クリックして「次に再生」「最後に再生」を選択することで、過去に聴いた曲を再生キューへ追加できます。
  - パネル右上のクリア（ゴミ箱）ボタンにより、選択中のタブに応じた全消去（再生リスト全クリアまたは履歴全クリア）を実行できます。

### 2.2 楽曲およびアルバムのキュー追加・再生
- **単曲の追加・挿入**:
  - 楽曲の右クリックメニューから「次に再生」を選択すると、**予約キューの先頭に挿入**され、最優先で次回再生されます。
  - 「最後に再生」を選択すると、既存の予約キューとアルバムの残り曲を統合してすべて予約キューとし、その末尾に追加されます。
- **アルバム全体の再生**:
  - アルバムの「再生」ボタンをクリックすると、既存のキューを置き換えてアルバム全曲がセットされます。
  - **通常時（シャッフルOFF）**: 先頭トラックから順に再生が開始され、2曲目以降が「アルバムの残り曲」セクションに展開されます。
  - **シャッフルON時**: アルバム内から最初の1曲目がランダムに選定されて即時再生を開始し、残りの曲もシャッフルされた順序で「アルバムの残り曲」セクションに展開されます。
- **キュー最終曲終了時の次アルバム自動遷移**:
  - アルバム再生中、全曲リピートがOFFの場合、当初セットされたキューの最終トラックの再生が終了した時点で、自動的に次のアルバムへ移行して再生が開始されます。
  - 次のアルバムへ遷移する際、シャッフル再生がONの場合は次アルバムの収録曲からランダムな1曲が最初に選定されて再生が開始され、残りの曲はシャッフルされてアルバムキューに追加されます。
- **アルバム収録曲の途中トラックからの再生**:
  - アルバム内から特定のトラック（例: No.5）をクリックして再生を開始した場合、**その曲より前のトラック（No.1〜No.4）はキューに追加されません**。
  - **通常時（シャッフルOFF）**: 選択したトラック（No.5）が即時再生され、後続トラック（No.6〜末尾）がアルバム順で「アルバムの残り曲」にセットされます。
  - **シャッフルON時**: 選択したトラック（No.5）が即時再生され、後続トラック（No.6〜末尾）がシャッフルされて「アルバムの残り曲」に追加されます。
- **アルバム単位の「次に再生」「最後に再生」**:
  - アルバムの右クリックメニューから「次に再生」を選択すると、アルバム収録曲が予約キューの先頭に一括挿入されます（シャッフルON時はアルバム収録曲内がシャッフルされて先頭追加）。
  - 「最後に再生」を選択すると、既存のアルバム残り曲と予約キューを統合した上で、アルバム収録曲が末尾に追加されます（シャッフルON時はアルバム収録曲内がシャッフルされて末尾追加）。

### 2.3 シャッフル再生と局所化制御
- **シャッフル適用範囲の限定（AlbumQueue限定）**:
  - プレイヤーのシャッフルボタンをONにした場合、**シャッフルの適用範囲は「アルバムの残り曲（AlbumQueue）」に限定**されます。
  - ユーザーが明示的に並べた「予約キュー（UserQueue）」はシャッフルの影響を受けず、指定順序が保護されます。
- **シャッフルOFF時の元順序復元**:
  - シャッフルボタンをOFFに戻した場合、「アルバムの残り曲」セクション内の未再生トラックが元のアルバムトラック番号昇順に復元されます。
- **シャッフル時の「最後に再生」**:
  - シャッフルON時に「最後に再生」を行った場合、キュー全体の再シャッフルではなく、**キューの末尾に追加**されます（アルバム単位の場合はアルバム収録曲のみをシャッフルして末尾追加）。

### 2.4 リピート再生（全曲リピート / OFF の2値トグル）
- **リピートOFF**:
  - キューの最終楽曲の再生が終了した際、ライブラリ内に次のアルバムが存在する場合は自動的に次のアルバムへ移行して再生を継続します。すべてのアルバムの再生が終了した時点で停止します。
- **全曲リピート（ON）**:
  - キューの最後の楽曲が終了した際、次のアルバムへは移行せず、現在のアルバム収録曲の先頭（シャッフルON時は再シャッフルされた先頭）へ戻ってループ再生を継続します。

### 2.5 再生キューの編集
- **楽曲の個別削除**:
  - 各カードの右端にある「✕」ボタン、または右クリックメニューの「キューから削除」をクリックすることで、特定の楽曲をキューから除外できます。
- **予約キューの一括クリア**:
  - 予約キュー見出しの「予約をクリア」ボタンをクリックすることで、予約キューのみを消去できます。
- **キューの全クリア**:
  - パネル右上のゴミ箱アイコンをクリック（「再生リスト」タブ選択時）することで、キュー全消去および再生停止が実行されます。
- **ドラッグ＆ドロップによる並び替え（拡張構想: Issue #216）**:
  - キュー内楽曲カードのドラッグ＆ドロップによる順序入れ替えは拡張機能（Issue #216）として計画されています。

### 2.6 再生キューが空（Empty）の際の振る舞い
- **キューが空の状態で「再生」ボタンを押下**:
  - 音声再生は開始されず停止状態を維持します。
  - パネル中央に「再生キューは空です」のガイドメッセージが表示されます。
- **最後の曲の再生が終了した場合**:
  - 音声を停止し、プレイヤーの再生状態を停止、現在曲表示を初期状態にクリアします。

## 3. 利用手順（想定ワークフロー）

### 3.1 楽曲・アルバムをキューに追加して楽しむ
1. ライブラリ画面でアルバムの再生ボタンをクリックするか、右クリックして「再生」を選択します。
2. アルバムの1曲目から音楽が再生され、2曲目以降が「アルバムの残り曲」セクションにセットされます。
3. 再生キュースライドパネルを展開し、これから再生される未再生曲のみが並んでいることを確認します。
4. 別の楽曲を右クリックして「次に再生」を選択すると、上部に「予約キュー」セクションが出現し、その曲が最優先で次回再生されます。
5. 別のアルバムを右クリックして「最後に再生」を選択すると、アルバム残り曲と予約曲が統合され、末尾に新しいアルバムの楽曲群が追加されます。

### 3.2 アルバムの途中曲から聴き始め、シャッフル再生を活用する
1. アルバム内の5曲目をクリックして再生を開始します。
2. 5曲目の再生が即時開始され、後続の6曲目以降が「アルバムの残り曲」に追加されます。
3. プレイヤーの「シャッフル」ボタンをONにすると、「アルバムの残り曲」セクション内の楽曲のみがランダムに並び変わります（予約キューの順序は保護されます）。
4. シャッフルボタンを再度OFFにすると、「アルバムの残り曲」が元のトラック番号順に復元されます。

### 3.3 予約の個別整理と再生履歴からの再再生
1. 予約キュー見出しの「予約をクリア」ボタンを押下し、アルバム残り曲を残したまま予約曲のみをクリアします。
2. 楽曲の再生が終了またはスキップされると、その楽曲は「履歴」タブへ自動蓄積されます。
3. 「履歴」タブを開き、曲をクリックまたは右クリックメニューから「再生」を選択すると、自動で「再生リスト」タブに切り替わり、即座に該当曲の再生が開始されます。
