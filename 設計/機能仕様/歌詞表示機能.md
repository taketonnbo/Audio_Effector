# 歌詞表示機能 仕様書

## 1. 機能概要
「歌詞表示機能」は、現在再生中の楽曲に対応する同期歌詞（`.lrc` ファイル）または非同期（プレーン）歌詞を自動的に読み込み、メイン画面右側タブの下部拡張領域へ表示する機能です。

ユーザーは右側タブの「歌詞表示ボタン」からワンクリックで歌詞パネルを展開でき、楽曲の進行に合わせた現在歌唱行のハイライト・自動スクロール、任意の歌詞行クリックによるシーク操作を通じて、音楽鑑賞体験をより深く楽しむことができます。

また、本機能の歌詞データ管理・再生同期・表示コンポーネントはメイン画面の右側タブに依存しない共通仕様として設計し、将来のミニプレイヤーでの歌詞表示や、テキストファイルから `.lrc` を自動生成する機能（関連 Epic #98）とのシームレスな連携を見据えています。

## 2. ユーザー向け提供機能

### 2.1. 歌詞表示の切り替えと右側タブ連動
- **歌詞表示ボタン（ワンクリック切替）**:
  - 右側タブに「歌詞表示ボタン」を配置し、クリックするたびに歌詞パネルの表示（ON）／非表示（OFF）を切り替えます。
  - 歌詞表示が ON の間は、ボタンがアクティブ状態として視覚的にハイライトされます。
- **右側タブ表示サイズモードとの自動連動**:
  - 右側タブが**最大化モード**（アルバムアートと収録トラックリストを大きく表示している状態）のときに歌詞表示ボタンを ON にした場合、右側タブは自動的に**コンパクトモード**へ切り替わり、下部の拡張領域に歌詞パネルが展開されます。
  - 歌詞表示ボタンを再度クリックして OFF にした場合、歌詞パネルは非表示になります。このとき、直前の歌詞表示 ON 操作によって最大化モードから自動的にコンパクトモードへ切り替わっていた場合は元の最大化モードへ自動復帰し、もともとコンパクトモードだった場合はコンパクトモードを維持したまま下部拡張領域を閉じます。
  - 歌詞パネル表示中に、ユーザーが右側タブ右上のサイズ切り替えボタンで手動で最大化モードへ切り替えた場合、歌詞表示は自動的に OFF となります。
  - 右側タブ自体を折りたたんで閉じた場合は、バックグラウンドでの同期更新を一時停止します。その後、右側タブを再度開いた際は歌詞表示 ON の状態を維持したまま、現在の再生位置に合わせて自動的に同期表示を再開します。
- **他拡張ウィジェットとの共存（関連 Epic #121 / #98）**:
  - 右側タブ下部拡張領域は、リスニング統計・タグクラウド（#121）や LRC 自動生成画面（#98）などと共有されます。
  - 下部拡張領域に表示するパネルは排他的に切り替えられ、他パネルへ切り替えた際は歌詞パネルの同期更新を一時停止します。

### 2.2. 歌詞ソースの探索優先順位とフォールバック
楽曲の再生開始時または楽曲切り替え時（および歌詞パネル表示時）に、以下の優先順位で対象楽曲の歌詞を自動的に探索・読み込みます。

1. **同階層・同名の外部 `.lrc` ファイル（最優先）**
   - 再生中の音声ファイルと同じフォルダ内にあり、拡張子のみを `.lrc` に置き換えたファイル（例: `01_Song.flac` に対して `01_Song.lrc`、ファイル名の大文字・小文字は OS 規約に従い区別しない）を探索します。
   - 文字コードは **UTF-8（BOM 有無の両方に対応）** を標準として読み込みます。UTF-8 として厳密に解釈できないファイルについては、環境互換のため Shift-JIS（CP932）等へ安全にフォールバックして文字化けを軽減します。
2. **音声ファイル内の埋め込み歌詞タグ（フォールバック）**
   - 外部 `.lrc` ファイルが存在しない場合、または外部 `.lrc` ファイルが空・メタデータのみで表示可能な歌詞行を含まない場合、もしくはアクセス権限不足やファイル破損等で読み取れなかった場合は、次の候補として音声ファイル自体に埋め込まれている歌詞メタデータ（MP3 の ID3v2 `USLT`、FLAC / Ogg の Vorbis Comments `LYRICS`・`UNSYNCEDLYRICS`、M4A / MP4 の歌詞タグ等）を読み込みます。
   - 埋め込み歌詞内に有効な LRC タイムタグが含まれている場合は同期歌詞として扱い、タイムタグを含まない場合は非同期（プレーン）歌詞として表示します。
3. **歌詞が見つからない場合（エンプティステート）**
   - 外部 `.lrc` ファイル・埋め込み歌詞のいずれも有効な歌詞を取得できなかった場合でも、エラーダイアログ等で音楽再生を中断しません。
   - 歌詞パネル内に「歌詞が見つかりません」等の案内メッセージと、LRC 自動生成機能（#98）を起動するための案内・導線を表示します。
   - 楽曲が未選択・未再生の場合は、「再生中の楽曲がありません」等の待機状態メッセージを表示します。

### 2.3. 対応 LRC フォーマット仕様
外部 `.lrc` ファイルおよびタイムタグ付き埋め込み歌詞は、以下の仕様に従って解釈します。

- **対応タイムタグ形式**:
  - 標準形式 `[mm:ss.xx]`（1/100 秒単位）および `[mm:ss.xxx]`（ミリ秒単位）に対応します。
  - 互換性のため、小数部を省略した `[mm:ss]`、区切り文字にコロンを用いた `[mm:ss:xx]`、および 100 分以上の 3 桁分表記（例: `[105:12.30]`）も解釈します。
- **複数タイムタグ行の展開**:
  - 1 行の先頭に複数のタイムタグが並記されている場合（例: `[00:12.00][01:05.50]サビの歌詞`）、すべてのタイムスタンプに対して同一テキストの歌詞行を展開し、全行をタイムスタンプ昇順に並び替えます。
  - 同一タイムスタンプを持つ複数行（訳詞の併記など）は、元の記載順序を維持して保持します。
- **メタデータタグとタイミング補正（`[offset:]`）**:
  - `[ti:]`（曲名）、`[ar:]`（アーティスト名）、`[al:]`（アルバム名）、`[by:]`（作成者）、`[offset:]`（ミリ秒単位の全体補正値）などのメタデータタグは、歌詞本文の行としては表示しません。
  - `[offset:±ms]` が指定されている場合、LRC 標準仕様に従い正の値で表示タイミングを早め、負の値で表示タイミングを遅らせます（補正後の時刻が 0 秒未満となる場合は 0 秒として扱います）。
- **空行・不正行・プレーンテキストの安全な処理**:
  - タイムタグのみでテキストが空の行（例: `[01:20.00]`）は、間奏や歌唱休止区間として保持します。再生位置がこの行に到達した場合は、直前の歌詞行のハイライトを解除して歌唱休止中であることを明確にします（視覚的な空白区切りとして表示し、クリックシークの対象外とします）。
  - 不正な書式の行や未対応タグが含まれていても読み込み全体は失敗させず、該当行のみ安全にスキップします。
  - 有効なタイムタグが 1 つも含まれない `.lrc` ファイルは、非同期（プレーン）歌詞として全文を上から順に表示します。

### 2.4. 同期表示・自動スクロール・行クリックシーク
- **再生位置に応じたアクティブ行ハイライト**:
  - 同期歌詞の再生中は、現在の再生位置に対応する歌詞行をリアルタイムにハイライト表示します。
  - 最初の歌詞行のタイムスタンプより前の区間（イントロ等）では、どの行もアクティブにせず待機します。
  - 訳詞の併記など同一タイムスタンプを持つ複数行が存在する場合は、そのタイムスタンプに到達した際に同一タイムスタンプの全行を同時にハイライト表示し、自動スクロールは該当グループの先頭行を基準に中央寄せします。
- **自動中央寄せスクロール**:
  - アクティブ行が切り替わるたびに、その行が歌詞パネルの表示領域中央付近に収まるよう自動的にスクロールします。
- **手動スクロール時の一時停止と追従復帰**:
  - ユーザーがマウスホイールやスクロールバーで歌詞を手動スクロールした場合、閲覧を妨げないよう自動スクロールを一時停止します。
  - 自動スクロールが一時停止している間は、パネル内に「現在の再生行へ戻る」ボタンを表示します。
  - 以下のいずれかのタイミングで自動スクロール追従を再開します。
    1. 「現在の再生行へ戻る」ボタンをクリックしたとき（即座に現在行へスクロールして復帰）
    2. タイムタグ付きの歌詞行をクリックしてシークしたとき（即座に追従復帰）
    3. 再生する楽曲が切り替わったとき（新楽曲の先頭から追従再開）
    4. 最後の手動スクロール操作から一定時間（既定 5 秒）経過したとき（追加のスクロール操作があれば待機時間をリセット）
- **歌詞行クリックによる任意位置シーク**:
  - 同期歌詞のうちテキストを含む各行をクリックすると、その行のタイムスタンプ位置へ楽曲の再生位置をシークします（`[offset:]` 補正がある場合は表示同期と一致する再生位置へ移動します）。
  - 再生中にクリックした場合は再生を継続したままシークし、一時停止中にクリックした場合は該当位置へシークしたうえで一時停止状態を維持します。
  - 間奏用の空行および非同期（プレーン）歌詞の各行はクリックシークの対象外とし、非同期歌詞では通常テキストとして自由にスクロール閲覧できます。
- **歌詞の再読み込み**:
  - ユーザーが外部エディタ等で `.lrc` ファイルを編集・配置した直後に最新内容を取り込めるよう、手動での再読み込み操作を提供します。

---

### 2.5. 高速な楽曲切り替え・省リソース動作
- **連続した楽曲切り替え時の表示整合**:
  - 「次の曲」「前の曲」を連続して素早く切り替えた場合でも、先に切り替えられた古い楽曲の歌詞読み込み結果が後から現在再生中の楽曲の歌詞を上書きすることなく、常に現在再生中の楽曲の歌詞のみを正確に表示します。
- **非表示時・停止時の負荷抑止**:
  - 歌詞パネルが非表示のとき（最大化モード・右側タブ閉鎖・他拡張パネル表示中）や楽曲の一時停止・停止中は、不要なバックグラウンド同期処理を停止し、PC への負荷を抑えます。

---

### 2.6. 将来拡張・外部機能との連携要件
- **ミニプレイヤーでの歌詞表示への展開**:
  - 歌詞の読み込み状態・現在再生行の同期状態・表示コンポーネントは、メイン画面の右側タブ固有の状態に依存させず共通化します。
  - これにより、ミニプレイヤー（コンパクトな常駐プレイヤー画面）へ同期歌詞表示を組み込む際も、同一の同期体験・ルール（探索優先順位・LRC 解釈・テーマ適用）を最小限の変更で提供できます。
- **LRC 自動生成機能（関連 Epic #98）との役割分担・連携**:
  - **役割分担**: 本機能は歌詞の探索・同期表示・閲覧／シーク操作を担当し、LRC 自動生成機能（#98）はプレーンテキストからの `.lrc` ファイル生成・タイミング微調整・保存を担当します。
  - **生成・再生成画面への導線**: 歌詞未検出時のエンプティステートだけでなく、既存の歌詞を表示している状態からもパネル内のアクションを通じて現在再生中の楽曲を対象に LRC 自動生成（作り直しを含む）を起動できる連携導線を備えます。LRC 自動生成機能が利用できない状態の場合は、操作ボタンを非活性とするか案内メッセージを表示して安全に動作します。
  - **保存後の即時反映**: LRC 自動生成（#98）で `.lrc` ファイルが新規保存または上書き保存された際は、保持している歌詞データを自動的に最新化し、歌詞パネルが表示中であれば即座に、他パネルへ切り替えていた場合は歌詞パネルへ戻った時点で最新の同期歌詞を反映します。

## 3. 利用手順（想定ワークフロー）

### 3.1. 同期歌詞を表示して聴く
1. 再生したい楽曲ファイルと同じフォルダに、同名の `.lrc` ファイル（例: `MySong.flac` と `MySong.lrc`）を配置します。
2. メイン画面で楽曲を再生し、右側タブを展開します。
3. 右側タブの「歌詞表示ボタン」をクリックします。
   - 右側タブが最大化モードだった場合は自動的にコンパクトモードへ切り替わり、下部拡張領域に同期歌詞が表示されます。
4. 楽曲の進行に合わせて現在の歌唱行がハイライトされ、中央へ自動スクロールされることを確認しながら鑑賞します。

### 3.2. 好きなフレーズから聴き直す・歌詞全体を読み返す
1. もう一度聴きたいフレーズの歌詞行をクリックします。楽曲がその行のタイムスタンプ位置へシークされます。
2. 曲の後半の歌詞を先読みしたい場合は、歌詞パネル上でマウスホイールを回して手動スクロールします。自動スクロールが一時停止し、「現在の再生行へ戻る」ボタンが表示されます。
3. 読み終えたら「現在の再生行へ戻る」ボタンをクリックする（または数秒間操作せずに待つ）と、現在の歌唱行へ戻って自動追従が再開されます。

### 3.3. 歌詞がない楽曲から LRC を用意する・表示を閉じる
1. `.lrc` ファイルも埋め込み歌詞もない楽曲を再生すると、歌詞パネルに「歌詞が見つかりません」の案内と LRC 自動生成（#98）への導線が表示されます。
2. 外部で `.lrc` を配置した場合は再読み込みボタンから、また LRC 自動生成（#98）で保存した場合は自動的に、同期歌詞がパネルへ反映されます。すでに歌詞がある場合も、パネルのアクションから LRC を再生成できます。
3. 歌詞表示を終了したい場合は、右側タブの「歌詞表示ボタン」を再度クリックします。歌詞パネルが閉じ、自動でコンパクトモードになっていた場合は元の最大化モードへ戻ります。
