# テキストループ表示機能 仕様書

## 1. 機能概要
「テキストループ表示機能」は、コンパクトプレイヤーやアルバム一覧（リスト表示・グリッド表示）、右側パネルなどにおいて、アルバム名や曲名、アーティスト名が画面の表示領域内に収まりきらず省略（`...`）される場合に、マウスオーバーすることでテキスト全体を右から左へ滑らかに連続スクロールさせ、名称の全貌を確認できるようにするための機能です。
常時アニメーションではなく、ユーザーが興味を持った項目にマウスを乗せた時のみ動作するため、画面の視覚的落ち着きと高いレスポンス・省リソース性能を維持したまま、長いタイトルの確認性を向上させます。

## 2. ユーザー向け提供機能

### 2.1. 省略テキストのマウスオーバー自動シームレスループ
- **静止時のすっきりとした表示**: 通常時は標準のテキストトリミング（`...` による省略）で表示され、画面全体の視覚的調和を維持します。
- **ホバー時の自動スクロール開始**: 表示枠を超えているテキスト（またはアルバムアート等の親カード・親行要素）にマウスカーソルを乗せると、約0.5秒のリードタイムの後、右から左へ一定速度（約40px/秒）で滑らかにスクロールが開始されます。
- **シームレス無限ループ**: 2つのテキスト要素間に適切な余白（最低60pxまたは表示幅の35%）を挟んで連結スクロールし、1周目の末尾が画面内に入った時点で約1.2秒間一時静止したあと、同速度のまま2周目の先頭が元の開始位置に重なるまで滑らかに連続スクロールし、初期位置で約1.2秒間静止してから次周へ移行します。
- **マウス離脱時の即時復元**: マウスカーソルが項目（親カード・行）から離れると直ちにアニメーションが停止し、元の省略表示状態にリセットされます。

### 2.2. 文字列が収まっている場合の静止維持
- 表示枠幅に対して十分に短い文字列（見切れが発生していないテキスト）の場合は、マウスオーバーしてもスクロールは発生せず、静止表示のままとなります。

### 2.3. 主要画面への横断的適用
以下の主要な楽曲・アルバム情報表示箇所に本機能（`MarqueeTextBlock`）が提供されます：
1. **上部バー（コンパクトプレイヤー）**: 現在再生中の楽曲タイトルおよびアーティスト名（アルバムアートへのホバー時にも連動）
2. **アルバム一覧（リスト表示）**: 各アルバムのタイトルおよびアーティスト名（アルバムアートへのホバー時にも連動）
3. **アルバム一覧（グリッド表示）**: 各アルバムカードのタイトルおよびアーティスト名（アルバムアートへのホバー時にも連動）、および展開トレイ内の収録トラックタイトル（トラック行ホバー時に連動）
4. **右側パネル（最大化表示）**: 選択中アルバム/リスト名（`PlaybackListName`）、サブタイトル/アーティスト名（`PlaybackListSubtitle`）、Player Pod内の現在再生中楽曲タイトル
5. **右側パネル（コンパクト表示）**: 再生中楽曲タイトルおよびアーティスト名（サムネイルアートへのホバー時にも連動）
6. **右側パネル（収録曲一覧）**: 各トラックの曲名タイトル（トラック行ホバー時に連動）
7. **ミニプレイヤー**: 現在再生中の楽曲タイトルおよびアーティスト名（情報エリアへのホバー時に連動）

## 3. 利用手順（想定ワークフロー）

1. アプリケーションを起動し、ライブラリやアルバム一覧を表示します。
2. 長い名称を持つアルバムや楽曲がある場合、通常は末尾が「`...`」として省略表示されています。
3. 全体の名称を確認したいテキスト（またはアルバム項目・トラック行）の上にマウスカーソルを合わせます。
4. 約0.5秒後にテキストが右から左へスクロールを始め、見切れていた後半部分やアーティスト名全体がシームレスにループ表示されます。
5. 確認できたらマウスを項目から外すと、テキストは直ちに元の省略表示に戻ります。
