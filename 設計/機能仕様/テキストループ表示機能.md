# テキストループ表示機能 仕様書

## 1. 機能概要
「テキストループ表示機能」は、コンパクトプレイヤーやアルバム一覧（リスト表示・グリッド表示）などにおいて、アルバム名や曲名、アーティスト名が画面の表示領域内に収まりきらず省略（`...`）される場合に、マウスオーバーすることでテキスト全体を右から左へ滑らかにスクロールさせ、名称の全貌を確認できるようにするための機能です。
常時アニメーションではなく、ユーザーが興味を持った項目にマウスを乗せた時のみ動作するため、画面の視覚的落ち着きと高いレスポンス・省リソース性能を維持したまま、長いタイトルの確認性を向上させます。

## 2. ユーザー向け提供機能

### 2.1. 省略テキストのマウスオーバー自動ループ
- **静止時のすっきりとした表示**: 通常時は標準のテキストトリミング（`...` による省略）で表示され、画面全体の視覚的調和を維持します。
- **ホバー時の自動スクロール開始**: 表示枠を超えているテキストにマウスカーソルを乗せると、約0.5秒の自然なリードタイムの後、右から左へ一定速度（約40px/秒）で滑らかにスクロールが開始されます。
- **末尾確認と再ループ**: テキストの末尾までスクロールしきった後、約1.2秒間末尾で一時静止し、その後先頭位置にリセットされて再度スクロールが行われます。
- **マウス離脱時の即時復元**: マウスカーソルが項目から離れると直ちにアニメーションが停止し、元の省略表示状態にリセットされます。

### 2.2. 文字列が収まっている場合の静止維持
- 表示枠幅に対して十分に短い文字列（見切れが発生していないテキスト）の場合は、マウスオーバーしてもスクロールは発生せず、静止表示のままとなります。不要な動きを排除し、必要な場合のみユーザーの視線誘導をサポートします。

### 2.3. 主要画面への横断的適用
以下の主要な楽曲・アルバム情報表示箇所に本機能が提供されます：
1. **上部バー（コンパクトプレイヤー）**: 現在再生中の楽曲タイトルおよびアーティスト名
2. **アルバム一覧（リスト表示）**: 各アルバムのタイトルおよびアーティスト名
3. **アルバム一覧（グリッド表示）**: 各アルバムカードのタイトルおよびアーティスト名
4. **右側パネル（フル表示）**: 選択中アルバム名、再生中楽曲タイトル
5. **右側パネル（ミニマイズ表示）**: 再生中楽曲タイトルおよびアーティスト名

## 3. 利用手順（想定ワークフロー）

1. アプリケーションを起動し、ライブラリやアルバム一覧を表示します。
2. 長い名称を持つアルバムや楽曲がある場合、通常は末尾が「`...`」として省略表示されています。
3. 全体の名称を確認したいテキスト（またはアルバム項目）の上にマウスカーソルを合わせます。
4. 約0.5秒後にテキストが右から左へスクロールを始め、見切れていた後半部分やアーティスト名全体が表示されます。
5. 末尾まで確認できたら、マウスを項目から外します。テキストは直ちに元のすっきりとした省略表示に戻ります。
