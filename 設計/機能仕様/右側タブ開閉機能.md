# 右側タブ開閉機能 仕様書

## 1. 機能概要
「右側タブ開閉機能」は、楽曲の詳細情報やタブメニューを表示している右側パネルを折りたたみ、画面のメイン領域（楽曲リストなど）を広く使えるようにするための機能です。
ユーザーは簡単なトグル操作でパネルの表示・非表示を切り替えることができ、パネルが非表示になっている間も、画面上部に展開される「コンパクトプレイヤー（トップバー）」から再生・一時停止・曲送りなどの基本的なプレイヤー操作を継続して行うことができます。

## 2. ユーザー向け提供機能

### 2.1. 画面の広域利用（右側パネルの折りたたみ）
- アプリケーション起動時のデフォルト状態では、右側パネルが折りたたまれており、ライブラリやプレイリストなどのメインコンテンツ領域が画面いっぱいに表示されます。
- これにより、長い曲名や多くのリスト項目をスクロールせずに一目で確認しやすくなります。

### 2.2. 動的な操作レイアウト切り替え
- **パネルを閉じている時**: 画面上部のバー領域に、再生ボタンやプログレスバー、小さなアルバムアートがコンパクトに表示されます。ユーザーはリストを見ながらでも、常に上部から直感的に音楽の操作を行えます。
- **パネルを開いている時**: 画面右側に大きくアルバムアートや詳細なタブ群（歌詞、プレイリストキューなど）が表示され、よりリッチな情報にアクセスできます。上部のコンパクトプレイヤーは非表示となり、操作系統が右側パネルに集約されます。

### 2.3. ワンクリックでの開閉操作
- メイン領域と右側パネルの間のスプリッター領域上に配置された「く」の字ボタン（＜ / ＞）をクリックするだけで、シームレスにパネルが開閉します。

## 3. 利用手順（想定ワークフロー）
1. アプリケーションを起動します。デフォルトでは右側パネルが閉じており、画面上部に「コンパクトプレイヤー」が表示されています。
2. ライブラリから好きな曲を選んで再生します。画面上部の再生ボタンで一時停止したり、プログレスバーでシークしたりできます。
3. 楽曲の歌詞や大きなアルバムアートが見たくなった場合は、画面中央のスプリッター領域にある「＜（開く）」ボタンをクリックします。
4. 右側パネルが展開し、詳細情報が表示されます。この時、上部のコンパクトプレイヤーは隠れ、右側パネル内のボタンから操作を行うようになります。
5. 再びリストを広く見たい場合は、画面中央のスプリッター領域にある「＞（閉じる）」ボタンをクリックします。右側パネルが非表示になり、元の広いレイアウトに戻ります。
