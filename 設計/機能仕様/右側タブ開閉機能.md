# 右側タブ開閉機能 仕様書

## 1. 機能概要
「右側タブ開閉機能」は、アルバムアート・Player Pod・収録曲リストを表示する右側パネルを折りたたみ、画面のメイン領域（ライブラリや楽曲リストなど）を広く使えるようにするための機能です。
ユーザーはワンクリックのトグル操作でパネルの表示・非表示を切り替えることができ、パネルが非表示になっている間も、画面上部に展開される「コンパクトプレイヤー（トップバー）」から再生・一時停止・曲送り・シークなどのプレイヤー操作を継続して行うことができます。

## 2. ユーザー向け提供機能

### 2.1. 画面の広域利用（右側パネルの折りたたみ）
- アプリケーション起動時の初期状態（`IsRightPanelOpen = false`）では、右側パネルが折りたたまれており、ライブラリやプレイリストなどのメインコンテンツ領域が画面全体に表示されます。
- これにより、長い曲名や多列のリスト項目をスクロールせずに一目で確認しやすくなります。

### 2.2. 動的な操作レイアウト切り替え
- **パネルを閉じている時**: 画面上部のバー領域に、再生ボタンやシークバー、小さなアルバムアートがコンパクトに表示されます。ユーザーはリストを見ながらでも、常に上部から直感的に音楽の操作を行えます。
- **パネルを開いている時**: 画面右側にアルバムアート、Player Pod、および収録曲リスト（またはコンパクトプレイヤーと下部拡張領域）が大きく展開されます。上部のコンパクトプレイヤーは自動的に非表示となり、操作系統が右側パネルに集約されます。

### 2.3. ワンクリックでの開閉操作
- メイン領域と右側パネルの境界（幅1pxの区切り線領域）に配置された開閉トグルボタン（`16×48px`）をクリックするだけで、シームレスにパネルが開閉します。
  - 閉状態（パネル格納時）: 左向き矢印（`<`）を表示（クリックで開く）。
  - 開状態（パネル展開時）: 右向き矢印（`>`）を表示（クリックで閉じる）。

## 3. 利用手順（想定ワークフロー）
1. アプリケーションを起動します。初期状態では右側パネルが閉じており、画面上部に「コンパクトプレイヤー」が表示されています。
2. ライブラリから好きな曲を選んで再生します。画面上部の再生ボタンで一時停止したり、シークバーで再生位置を変更できます。
3. 大きなアルバムアートや収録曲リストを見ながら操作したい場合は、画面右端の開閉ボタン（`<`）をクリックします。
4. 右側パネルが展開し、上部のコンパクトプレイヤーは隠れ、右側パネル内のPlayer Podから操作を行うようになります。
5. 再び左側のメインリストを広く見たい場合は、中央境界の開閉ボタン（`>`）をクリックします。右側パネルが非表示になり、元の広いレイアウトに戻ります。
