# ショートカット入力 UI仕様書

## 1. 概要 (Overview)

設定画面内で1つの機能にキーと修飾キーを割り当てる。対象はShortcutKeyConfig。

## 2. 実装イメージ（モックアップ）

### 2.1 ASCIIモックアップ

+-----------------------------------------------+

| +-------------------------------------------+ |
| | Space                                     | |
| +-------------------------------------------+ |
+-----------------------------------------------+

【キー入力フォーカス時 (待機中)】

## 3. 画面配置とペインレイアウト

設定画面のショートカット欄に縦積みするUserControl。Label、幅250の読み取り専用TextBox、警告文の順。下余白15、入力Padding=5、警告の上余白5。

## 4. デザイントークンの適用

| トークン名 | カラー見本 (Preview) | カラーコード | 用途 |
| :--- | :---: | :--- | :--- |
| `SecondaryTextForegroundBrush` | <span style="background-color:#A0AEC0;color:#161920;padding:2px 8px;border-radius:3px;">■ #A0AEC0</span> | `#A0AEC0` | 補足テキスト |
| `WindowBackgroundBrush` | <span style="background-color:#161920;color:#F0F4F8;padding:2px 8px;border-radius:3px;">■ #161920</span> | `#161920` | 画面背景 |

ラベルはSecondaryTextForegroundBrush、警告文は12 DIP。警告色はコードとXAMLのローカル指定。入力フォーカス色もコードビハインドで設定する。

## 5. 構成要素と共通コントロール

表示はLabelとShortcutの依存関係プロパティに連動。割当済みはCtrl／Shift／Alt／Win＋キー名、未割当は「割り当てなし」。フォーカス中は「キーを入力してください...」。警告文は通常Collapsed。リスト選択バー（幅3px）の適用対象なし。

## 6. アニメーションとインタラクション

クリックで入力へフォーカス。修飾キー単体は無視し、Delete／BackSpaceでクリア。WPFで使えない組合せ、同じ設定内の重複、OS／他アプリとの競合を検査し、MessageBoxを表示して割当を拒否する。競合時は警告文も表示。フォーカスを外すと割当文字列へ戻す。

## 7. パフォーマンス最適化要件

固定3要素で仮想化対象なし。警告は必要なときだけVisible。キー競合検査は入力時に行い、常時ポーリングしない。

共通要件は[パフォーマンス最適化](../../詳細設計/パフォーマンス最適化.md)に従う。多数の項目の標準指定は `IsVirtualizing=True / VirtualizationMode=Recycling / ScrollUnit=Pixel / CanContentScroll=True`。上記の個別構成と区別して適用範囲を判断する。
