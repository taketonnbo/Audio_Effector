# 設定 UI仕様書

## 1. 概要 (Overview)

テーマ、起動、オーディオ、再生、ショートカットの設定を変更する。対象はAppSettings。変更は各プロパティのSetterで保存する。

## 3. 画面配置とペインレイアウト

800×600、所有者中央に表示するダイアログ。ルートは見出し `Auto`、設定本文 `*`、閉じる `Auto`。本文はカテゴリ幅200、区切り20、詳細 `*`。カテゴリ選択で詳細のStackPanelを切り替える。

## 5. 構成要素と共通コントロール

| カテゴリ | 項目・表示 |
| :--- | :--- |
| 一般 | Dark／Light、OS起動時の自動起動、起動時最小化、最前面表示の3方式 |
| オーディオデバイス | サンプルレート44100/48000/88200/96000/192000 Hz、バッファ50/100/200/300/500 ms |
| エフェクト・再生 | マスター音量0～1、ピーク・ノーマライズと処理待ちの説明 |
| ショートカット | 再生・一時停止／停止／次／前／ミュート／音量上／音量下の7項目 |
| データ管理・その他 | データベースの最適化、アートワークキャッシュのクリア、設定バックアップ・エクスポート |

カテゴリListBoxの選択はローカルStyleで背景と文字を変更する。共通の左端3pxバーはこのStyleに含めない。保存・適用・キャンセルボタンを置かず、下端の「閉じる」で終了する。

## 6. アニメーションとインタラクション

各入力をTwoWayでViewModelへ反映し、変更時に設定を保存する。テーマの選択は表示テーマにも反映。閉じる操作は編集内容を取り消さない。ショートカットのキー検証は専用コントロールを使用する。

## 7. パフォーマンス最適化要件

カテゴリは5件の固定リスト。詳細はDataTriggerで選択カテゴリだけVisible、それ以外Collapsed。ショートカットだけScrollViewer（MaxHeight=450）内で7項目をスクロールする。DropShadowEffect/BlurEffectなし。

共通要件は[パフォーマンス最適化](../../詳細設計/パフォーマンス最適化.md)に従う。多数の項目の標準指定は `IsVirtualizing=True / VirtualizationMode=Recycling / ScrollUnit=Pixel / CanContentScroll=True`。上記の個別構成と区別して適用範囲を判断する。
