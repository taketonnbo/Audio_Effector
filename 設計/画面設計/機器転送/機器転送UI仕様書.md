# 機器転送 UI仕様書

## 1. 概要 (Overview)

接続機器の転送先を選び、PC側のAlbum／Trackをコピーする。対象はDevice、Album、Track。

## 3. 画面配置とペインレイアウト

`CurrentViewType = DeviceSync`、`DataContext` は `MainViewModel.DeviceBrowser`（`DeviceBrowserViewModel`）。行0が機器側エクスプローラー `1*`、行1が高さ `5px` の `GridSplitter` `Auto`、行2がPC側アルバム/楽曲選択一覧 `1*`、行3が下部進捗テキストおよび転送開始ボタン `Auto` の4行構成。上下の領域配分を `GridSplitter` のドラッグで調整できる。

## 5. 構成要素と共通コントロール

- **上部（機器側エクスプローラー）**: `"CONNECTED DEVICE"` 見出し、接続機器 `ComboBox`（リムーバブルドライブおよびMTPデバイス両対応）、`"↻ 機器を再検出"` ボタン（`RefreshDrivesCommand`）、`"⚙ Manage"` ボタン、接続機器詳細ヘッダーバー（接続種別バッジ `USB`/`MTP`・使用率プログレスバー `UsedSpaceRatio`・空き/総容量テキスト `StorageSummaryText`）、親フォルダへ移動 `".."`、現在パス `CurrentDevicePath`、既定転送先フォルダ登録／解除トグルボタン `"☆ 既定"` / `"★ 既定"`（`ToggleDefaultFolderCommand`・登録済みフォルダ表示中は `NeonCyanBrush` ハイライト）、再読込 `"↻"`、フォールバック通知テキスト（`DefaultFolderStatusMessage`）、および `DeviceDirectories`（サブフォルダ `📁` とファイル `📄` の一覧）を表示する。機器未接続時（`HasConnectedDevices == False`）はフォルダ一覧の代わりに未接続案内と再検出ボタンのエンプティ状態を表示する。
- **下部（PC側選択リスト）**: `"SELECT ALBUMS / TRACKS TO TRANSFER"` 見出し、右側の選択サマリ表示（`SelectedSizeSummaryText`: 選択アルバム数・曲数・合計サイズ・空き十分／容量不足の警告色表示）、`Albums` の `Expander` と `CheckBox`（展開時は配下 `Tracks` の `CheckBox`）。
- **重複防止とロック・詳細進捗と結果サマリ**: 選択中フォルダ（`CurrentDevicePath`）配下の既存音声ファイルを非同期で一括インデックス化し（ルート直下での全階層再帰走査は回避しつつ代表アーティスト新配置および曲別アーティスト旧配置・旧禁止文字除去配置・旧末尾ピリオド保持配置の既知転送先候補フォルダのみ照合）、フォルダ名のファイル名禁止文字（`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|` および制御文字）を `_`（アンダースコア）へ置換し末尾ピリオド・空白を除去する保存時と同一規則で正規化した相対パス（`<Artist>\<Album>\<拡張子除去ファイル名>`。`<Artist>` は PC ライブラリで解決したアルバムの代表アーティスト、旧配置の曲別アーティスト配下・旧禁止文字除去配置・旧末尾ピリオド保持配置・直下フラット配置含む）ベースで別アルバム間の同名衝突を防ぎつつ曲単位の `Track.IsOnDevice` を判定する。新配置・旧配置の既転送曲は曲単位で `CheckBox` が無効化・曲名が半透明（`Opacity="0.5"`）でグレーアウトされ、アルバム選択 ON 時も未転送曲のみ自動選択される。全曲転送済みのアルバムは `Album.IsOnDevice = True` に自動連動し、アルバムの `CheckBox`・タイトル表示も非活性・グレーアウトされる（デバイス未選択・切断時は自動リセット、転送実行時にも既転送曲は除外される）。転送中（`IsTransferring = True`）はナビゲーション・選択・転送ボタンをロックし、ボタン文言を `"TRANSFERRING..."` に切り替えるとともに、詳細進捗パネル（`ProgressBar` 0〜100% `Mode=OneWay`、件数・パーセント `TransferProgressCountText`、処理中ファイル名 `CurrentTransferFileName`、フェーズテキスト `TransferPhaseText`、および `✕ 転送を中止` ボタン `CancelTransferCommand`）を表示する。転送完了・キャンセル・中断時は再走査による選択状態・非活性状態の反映完了後にテーマ準拠の結果サマリダイアログ（`TransferResultDialog`：成功／スキップ／失敗件数および失敗曲一覧）を表示して操作ロックを解除する。

## 6. アニメーションとインタラクション

- 画面遷移時（`ViewType.DeviceSync`）に自動で `RefreshDrives()` を実行し、スペクトラムアナライザを非表示（`IsSpectrumVisible = false`）に格納する。
- 機器内フォルダ（`📁`）のダブルクリックで下位階層へ移動、`".."` ボタンは `NavigateUpCommand`、`"↻"` ボタンは `RefreshDirectoryCommand`、`"⚙ Manage"` ボタンは `OpenDeviceManagerCommand`（`DeviceManagerDialog` 表示）を実行する。
- アルバム/楽曲にチェックを入れて `"TRANSFER SELECTED"`（`TransferSelectedCommand`）を押下すると、転送開始前に空き容量不足および音声フォーマット自動変換対象の有無をチェックする。いずれかに該当する場合はテーマ準拠の確認・警告ダイアログ（`TransferConfirmationDialog`）を 1 回だけ表示し（両方該当時は 1 ダイアログへ統合表示、容量不足時は安全側としてキャンセルを既定ボタン）、ユーザーが「転送を開始」／「そのまま転送を開始」を選択した場合のみ転送を開始する（該当しない通常転送ではダイアログを省略して即座に開始する）。設定で変換オプションが有効な場合、`.mp4` は `.m4a` へ、`.flac` は `.mp3` へ自動変換して転送し一時ファイルを自動削除する。また、設定画面の「データ管理・その他」→「機器転送設定」で有効な種別の同階層・同名 `.lrc` が存在する場合は、変換後音声ファイルと同名ベースで同一フォルダへ同梱転送される [#442]。なお `.lrc` は曲単位重複判定の対象外とする。転送中にメインウィンドウを閉じようとした場合は中断確認 `MessageBox` を表示する。

## 7. パフォーマンス最適化要件

PC側アルバム一覧 `ListBox` には `VirtualizingStackPanel.IsVirtualizing="True"` および `VirtualizationMode="Recycling"` を指定する（機器ディレクトリ一覧および展開トラック `ItemsControl` は標準描画）。
