# プレゼンテーション層 詳細設計書

## 1. 概要

### 1.1 目的
本ドキュメントは、AudioEffector における **プレゼンテーション層（Presentation Layer / MVVM）** の設計仕様書です。
プレゼンテーション層はWPF（XAML）による画面表示、ユーザー入力の受付、データバインディング、および画面遷移を担当し、機能ごとのViewModel群とViewで構成されます。

### 1.2 設計原則
1. **MVVMパターンの徹底**: ViewのコードビハインドはUIコントロール固有のイベント（ドラッグシーク、ダブルクリック元の要素判定、スクロールバー幅同期、ウィンドウメッセージ処理等）のみに留め、状態管理と業務操作はViewModel経由でApplication層に委譲する。
2. **単一情報源（Single Source of Truth）とイベント連携**: 再生状態・再生キューは `IAudioService`（およびそれを購読する `PlayerControlViewModel`）、ライブラリ楽曲・アルバムは `LibraryViewModel` を単一情報源とし、イベント購読によって各画面ViewModelが自律的に表示を同期する。
3. **インフラ層具象への非依存**: View / ViewModel からNAudio等の外部デバイス制御を直接行わず、`IAudioService` や各 `ApplicationService` / `Repository` インターフェース経由で連携する。

## 3. 主要コンポーネントの責務と実装ルール

### 3.1 ViewModels (`AudioEffector.Presentation.ViewModels`)
- **基底とコマンド (`ViewModelBase.cs` / `RelayCommand.cs`)**:
  - **`ViewModelBase`**: `INotifyPropertyChanged` を実装し、`[CallerMemberName]` を利用した `OnPropertyChanged` および `EqualityComparer<T>.Default` による同値ガード付き `SetProperty<T>(ref T field, T value)` ヘルパーを提供する。
  - **`RelayCommand`**: `ICommand` の汎用実装。`Action<object?>` / `Predicate<object?>?` および引数なし `Action` / `Func<bool>?` オーバーロードを提供し、`CanExecuteChanged` イベントを WPF の `CommandManager.RequerySuggested` に委譲する。
- **主要ViewModelの責務境界**:
  - **`PlayerControlViewModel`**: `IAudioService` のイベント（`TrackChanged`, `PlaybackStateChanged`, `PlaylistChanged`, `TrackPlaybackEnded`, `FftCalculated`, `VolumeChanged`）を購読し、再生制御・シーク（`_isDraggingProgress` と `_isUpdatingProgressInternally` の二重ガード）・2層再生キュー（`UserQueue` / `AlbumQueue`）・インメモリ再生履歴タブ（`PlayHistory`, 上限100件）・スペクトラム描画（約30fpsスロットリング）・スライドパネル/ダイアログ開閉を一元管理する。
  - **`LibraryViewModel`**: アルバム一覧（`Albums`）、全トラック（`Tracks`）、表示切替（グリッド/リスト）、ソート順（`Artist` / `Album`、昇順/降順）、フォルダスキャン、および `FavoriteTrackMatcher` / `IFavoriteRepository` と連携したお気に入り状態管理の Single Source of Truth を担う。また `ShowAlbumInfo` による展開トレイクローズおよび `AlbumDetailRequested` イベント発行を担う。
  - **`AlbumDetailViewModel`**: アルバム情報詳細画面（`ViewType.AlbumDetail`）専用 ViewModel。選択アルバムのメタデータ集計（年・ジャンル・代表フォーマット・曲数・総時間・Hi-Res/Lossless 判定）、`CancellationTokenSource` と世代番号による高解像度カバーアート（`DecodePixelWidth = 400`、`Freeze()`）の非同期読み込み、アルバム／個別トラックの再生・キュー・お気に入り・削除コマンド、および `LibraryViewModel` の削除・差分同期イベントとの自動追従／一覧復帰（`BackRequested`）を担う。
  - **`AllSongsViewModel` / `ArtistsViewModel` / `RecentViewModel`**: `LibraryViewModel.Tracks` の変更（および既存ファイルのメタデータ更新を伴う `LibrarySynced` イベント）を `DispatcherPriority.Background` でコアレッシング同期し、大量トラックの一括追加時でも $O(N^2)$ のUI再構築が発生しないよう保護する。また、`RecentViewModel` は `ListeningStatsApplicationService.StatsReset` を購読して全リセット時に履歴一覧を即時クリアし、再生要求（`PlaybackRequested`）やキュー追加要求（`EnqueueRequested`）をイベント経由で `MainViewModel` / `PlayerControlViewModel` へ通知する。
  - **`PlaylistViewModel`**: プレイリスト一覧・詳細トラック・お気に入り一覧モードの切り替えを管理する。プレイリスト切替時の非同期読み込みは `CancellationTokenSource` と世代番号（`_trackLoadVersion`）を併用し、古い非同期結果による表示上書きを防止する。
  - **`LyricsViewModel` / `LyricLineItemViewModel`**: `MainWindow` に依存しない独立・再利用可能な歌詞表示 ViewModel。`IAudioService`・`IEventBus`（`TrackChangedEvent` / `PlaybackStateChangedEvent` / `LyricsUpdatedEvent`）・`LyricsApplicationService`・`IUiDispatcher` を DI で受け取り、再生中かつ `IsActiveView == true` の間のみ約 100ms 間隔の同期タイマーを稼働させて `LyricsDocument.FindActiveLineRange` による O(1) 差分ハイライト（同一タイムスタンプ複数行の同時強調・近接行 ±2 行・間奏空行でのハイライト解除）を行う。楽曲切替時の `CancellationTokenSource` キャンセル＋世代番号チェックでレースコンディションを防止し、手動スクロール一時停止＆既定 5 秒自動復帰、行クリックシーク（`[offset:]` 補正後比率の `0.0〜1.0` クランプ）、および LRC 自動生成連携（`GenerateLrcRequested`）を備える。
  - **`LrcGeneratorViewModel` / `LrcPreviewLineViewModel`**: 右側タブ下部拡張領域の LRC 自動生成パネルを統括する ViewModel。`LrcGenerationApplicationService`・`IAudioService`・`IUiDispatcher`・`ISettingsService`（`[ActivatorUtilitiesConstructor]` により DI 自動注入、`MainViewModel` フォールバック生成でも同一サービスを注入）を受け取り、6 排他視覚状態（モデル未配置／モデル DL 中／入力・待機／生成実行中／結果プレビュー・`.lrc` エディタ／エラー）と 2 インライン確認バー（非 UTF-8 承諾バー／既存 `.lrc` 上書き確認バー）、著作権・利用ガイドラインの初回確認・承諾状態管理と非同期永続化（`HasAcceptedCopyrightGuideline` / `NeedsCopyrightGuidelineAcceptance` / `IsCopyrightGuidelineExpanded` / `AcceptCopyrightGuidelineCommand` / `ToggleCopyrightGuidelineCommand`、`AppSettings.HasAcceptedLrcCopyrightGuideline` 連動、未承諾時の生成コマンド `CanExecute` および実行メソッド先頭防御ガード）、既存 `.lrc` の自動読込による手動編集画面優先表示（「`↺ 再生成`」クリック時のみ入力・生成画面へ遷移）、テキスト生成（`GenerateLrcCommand`）と音声直接文字起こし（`TranscribeAudioCommand`）の独立 2 ボタン、全体オフセット調整・個別行インライン編集・行クリックシーク・保存後即時反映連携・各非同期処理での NLog 詳細記録と生例外非露出の最終防御（`LrcGenerationErrorMessageResolver` 経由の安全な日本語エラー表示）および `IDisposable` によるキャンセルリソース解放を担う。
  - **`ListeningStatsViewModel` / `TopPlayedTrackItemViewModel`**: 右側タブ下部 3 タブの「ダッシュボード」を担当する ViewModel。`ListeningStatsApplicationService`・`IAudioService`・`IUiDispatcher`・`LibraryViewModel`（任意）を DI で受け取り、対象楽曲（再生中曲、または右側プレイリスト右クリック指定曲）の累計再生回数・累計再生時間・最終再生日時および所属アルバム内の「アルバム内でよく聴く曲 TOP 5」（`LibraryViewModel.Albums` からのファイルパス集合厳密解決＋メタデータフォールバック）を表示する。再生中以外の曲を表示時はピン留め状態と「再生中の曲に戻す」導線を提供し、非表示時（`IsActiveView == false`）はダーティフラグで更新を遅延する一方、`StatsReset` 受信時は非表示中を含め即座に空状態へ同期する（`IDisposable` 準拠）。
  - **`LibraryStatsViewModel` / `LibraryStatsTrackItemViewModel` / `LibraryStatsArtistItemViewModel` / `LibraryStatsAlbumItemViewModel` / `LibraryStatsChartBarViewModel`**: 左側メイン画面「リスニング統計」（`ViewType.ListeningStats`）を担当する ViewModel。`LibraryStatsApplicationService`・`ListeningStatsApplicationService`・`LibraryViewModel`・`IAudioService`・`IUiDispatcher`・`PlaylistViewModel` を連携し、期間フィルタ別 KPI サマリ・曲/アーティスト/アルバム TOP 10 ランキング・日別/月別推移・時間帯/曜日別傾向（ピークインサイト付き）・TOP 10 連続再生・プレイリスト化・アーティスト/アルバム詳細画面遷移を提供する。非表示時はダーティフラグで再集計を遅延し、連続更新をコアレッシングする一方、`StatsReset` 受信時は非表示中を含め即座に空状態へ同期する（`IDisposable` 準拠）。
  - **`SettingsViewModel`**: アプリ設定の即時保存・反映に加えて、データ保存先ディレクトリ変更・ログ出力構成動的反映、および再生履歴・リスニング統計データの全リセットコマンド（`ResetListeningStatsCommand`：警告確認ダイアログ［既定「いいえ」］→ `ListeningStatsApplicationService.ResetAllStats()` → 完了/失敗フィードバック通知・`ListeningStatsReset` イベント発火）を提供する。

### 3.2 Views & Controls (`AudioEffector.Presentation.Views` / `Controls`)
- **直接DataContextバインディング**:
  - `MainWindow.xaml` 内の各子ビュー（`LibraryView`, `AllSongsView`, `ArtistsView`, `RecentView`, `FolderView`, `PlaylistSelectorView`, `PlaylistTracksView`, `EqualizerView`, `DeviceSyncView`, `PlayQueueSidePanel`, `LyricsView`, `LrcGeneratorView`）は、それぞれ対応する専用ViewModel（`Library`, `AllSongs`, `Artists`, `Recent`, `Folder`, `Playlist`, `Equalizer`, `DeviceBrowser`, `PlayerControl`, `Lyrics`, `LrcGenerator`）を `DataContext` としてバインドする。
  - **`LyricsView`**: 依存関係プロパティ `IsCompactMode` により通常モード（右側タブ下部拡張領域）とコンパクトモード（将来の `MiniPlayerWindow` 組み込み）を切り替えられる再利用可能 `UserControl`。UI 仮想化 4 属性付き `ListBox`、プログラムスクロール誤検知防止ガード付き自動中央寄せスクロール、手動スクロール検知、およびクリックシーク後の `SelectedItem` 解除を実装する。
  - **`LrcGeneratorView`**: 右側タブ下部拡張領域へ `LyricsView` と排他配置する `UserControl`。初回未承諾時の著作権・利用ガイドライン警告・確認カードと承諾後の常設注意表示（詳細展開トグル付き）、`.txt` ドラッグ＆ドロップ、非 UTF-8 警告インラインバー、独立した 2 モード生成ボタン、UI 仮想化 4 属性付きプレビュー `ListBox`（`ItemsPresenter.Margin="0"`・選択行左端 3px `NeonCyanBrush` 縦バー・個別行インライン編集）、およびダーク／ライトテーマ両対応を実装する。
- **カスタムコントロール (`MarqueeTextBlock.cs` / `GridLengthAnimation.cs`)**:
  - **`MarqueeTextBlock`**: テキストが表示幅を超過する場合のみ、ホバー（または親要素の `IsTriggered`）連動で2つの `TextBlock` を用いたシームレスな無限ループスクロールを行う（詳細は [テキストループ表示機能](../../機能仕様/テキストループ表示機能.md) を参照）。
  - **`GridLengthAnimation`**: 右側パネル開閉等の `GridLength` プロパティ（スター比率 `GridUnitType.Star`）を補間アニメーションするカスタム `AnimationTimeline`。

### 3.3 添付プロパティ (`AudioEffector.Presentation.AttachedProperties`)
- **`AlbumArtLoader` (`AlbumArtLoader.cs`)**:
  - `Image` コントロール向けの添付プロパティ `AlbumArtLoader.SourcePath` を提供する。
  - パス設定時にまずインメモリ LRU キャッシュ（上限 `MaxCacheSize = 100`、`Dictionary<string, BitmapImage>` + `LinkedList<string>`）を参照し、未キャッシュ時はプレースホルダー画像（`pack://application:,,,/Assets/Images/default_now_playing_bg.png`）を表示した上で、`Task.Run` にて `TagLib.File` から埋め込み画像を非同期抽出する。
  - 抽出画像は `DecodePixelWidth = 150`（サムネイル縮小）・`BitmapCacheOption.OnLoad` でデコード後に `Freeze()` して UI スレッドへ返却し、非同期完了時に `GetSourcePath(image) == path` が一致する場合のみ `image.Source` を更新することで仮想化再利用時の画像取り違えを防止する。

### 3.4 ValueConverter群 (`AudioEffector.Presentation.Converters`)
XAML データバインディングにおける表示変換を担う全9種の `IValueConverter` 実装仕様は以下の通りです。

| クラス名 | 入力値 / パラメータ | 出力値・変換仕様 | 主な用途 |
| :--- | :--- | :--- | :--- |
| **`BoolToVisConverter`** | `bool` (`Parameter="Invert"` 可) | `true` → `Visibility.Visible`、`false`（または非 `bool`）→ `Visibility.Collapsed`。`"Invert"` 指定時は真偽を反転。 | パネル・アイコン・オーバーレイの表示/非表示切替 |
| **`InvertBoolConverter`** | `bool` | `!b`（非 `bool` 時は `false`）。`ConvertBack` による双方向反転にも対応。 | `IsEnabled` や排他トグル状態の反転バインディング |
| **`NullToVisConverter`** | `object?` / `string?` | `null` または空文字列（`string.IsNullOrEmpty`）→ `Visibility.Collapsed`、それ以外 → `Visibility.Visible`。 | 文字列やオブジェクトが存在する場合のみの要素表示 |
| **`EnumToBoolConverter`** | `Enum` + `Parameter` (文字列、カンマ区切り複数指定可) | 列挙値名とパラメータ文字列を大文字小文字無視で比較し一致時に `true`。`ConvertBack` では `true` の場合に先頭パラメータ名で `Enum.TryParse` して列挙値を返却（`false` 時は `Binding.DoNothing`）。 | `ViewType` 等に応じたサイドバー・ラジオボタンの選択判定 |
| **`IndexConverter`** | `int` (0始まり) | `index + 1`（1始まりの表示用行番号）。 | `AlternationIndex` 等からのトラック行番号（`#`）表示 |
| **`IndexIsOddConverter`** | `int` (0始まり) | `index % 2 == 1`（奇数行で `true`、偶数行で `false`）。 | `DataTrigger` による奇数行スタイル切替 |
| **`IndexToZebraBackgroundConverter`** | `int` (0始まり) | 偶数行は `Brushes.Transparent`、奇数行はテーマの `ZebraOddBackgroundBrush`（未解決時は `TextForegroundColor` の明度からダーク用 `#10FFFFFF` / ライト用 `#0C000000` の `Freeze()` 済みブラシ）を返却。 | 楽曲リスト・キュー一覧のゼブラストライプ行背景 |
| **`HeightToBorderThicknessConverter`** | `double` (高さ) | `(height / 600.0) * 3.0` を `0`〜`3.0` の範囲にクランプした `Thickness` を返却。 | スペクトラムバー等の高さに応じた動的ボーダー太さ算出 |
| **`ZeroToTransparentConverter`** | `double` | `0.01` 以下の場合は `0.0`（完全透明）、それ以外は `1.0`（不透明）を返却。 | スペクトラム無音・極小値時の要素非表示（Opacity制御） |

### 3.7 非Presentation層からのWPF依存分離に伴う責務整理（#298）
4 層プロジェクト分割（#295 / #298）に伴い、WPF 固有の画像デコード・キー型変換・UI スレッドマーシャリングの責務を Presentation 層へ完全集約します。

1. **アートワーク表示・キャッシュの完全集約**:
   - **一覧画面（仮想化リスト）**: `LibraryView`, `AllSongsView`, `ArtistsView`, `DeviceSyncView`, `PlaylistSelectorView`, `PlaylistTracksView`, `PlayQueueSidePanel`, `RecentView` は現行通り添付プロパティ `AlbumArtLoader.SourcePath`（LRU キャッシュ 100 件・`DecodePixelWidth = 150`・`Freeze()`・パス一致ガード）を継続使用し、XAML バインディングおよび仮想化パフォーマンスを変更しない。
   - **高解像度表示（詳細・再生中・ミニプレイヤー）**:
     - `AlbumDetailViewModel.CoverImage`（`DecodePixelWidth = 400`）および `MainViewModel.MiniPlayerAlbumArtImage` は現行通り ViewModel 側で `FilePath` から非同期デコード＋世代番号ガード＋`Freeze()` を継続する。
     - `PlayerControlViewModel.UpdateTrackDisplays(Track? track)` は `track.CoverImage != null` 分岐を削除し、`FilePath` からの非同期デコード（`DecodePixelWidth = 500`・`_trackArtworkGeneration` 競合ガード・`Freeze()`）へ統一する。
     - `MainViewModel.LoadTrack` 内の `track.CoverImage` 代入と未使用となる `_albumArtCache` フィールド、および `LibraryViewModel` の `Album.CoverImage = null` 代入を削除する。
2. **ショートカットキー型の相互変換マッパー（`ShortcutKeyHelper` 集約）**:
   - Domain 層の `ShortcutKeyConfig` が WPF 非依存型（`int Key`, `ShortcutModifiers Modifiers`）へ移行されることに伴い、`ShortcutKeyHelper` に以下の相互変換メソッドを集約する。
     - `Key ToWpfKey(int keyCode)`: `Enum.IsDefined(typeof(Key), keyCode)` を検証し、未定義値は `Key.None` へ安全フォールバックする。
     - `int FromWpfKey(Key key)`: `(int)key` へ変換する。
     - `ModifierKeys ToWpfModifiers(ShortcutModifiers modifiers)` / `ShortcutModifiers FromWpfModifiers(ModifierKeys modifiers)`: 同一ビットマスク（`Alt=1, Control=2, Shift=4, Windows=8`）で相互変換する。
     - `ShortcutKeyConfig CreateConfig(Key key, ModifierKeys modifiers)`: 新規設定生成ファクトリ。
   - `SettingsDialog.xaml`（`Shortcut="{Binding PlayPauseShortcut, Mode=TwoWay}"`）および `SettingsViewModel.cs` はプロパティ型が `ShortcutKeyConfig` のまま維持されるため変更不要。更新対象は `ShortcutKeyHelper.cs`, `ShortcutInputBox.xaml.cs`, `WindowShortcutHandler.cs` の 3 ファイルに局所化される。
3. **UI スレッドディスパッチャー具象実装（`WpfUiDispatcher`）**:
   - `Application.Common.IUiDispatcher` の WPF 向け具象クラス `WpfUiDispatcher` を Presentation 層へ配置する。
   - [パフォーマンス最適化 詳細設計書](../パフォーマンス最適化.md) の原則 4 に準拠し、`Application.Current?.Dispatcher` を取得して以下のライフサイクル保護を行う：
     - **`Invoke(Action action)`**: `dispatcher == null || dispatcher.HasShutdownStarted || dispatcher.HasShutdownFinished || dispatcher.CheckAccess()` の場合は直接 `action()` を実行。それ以外は `dispatcher.Invoke(action)` を呼び出し、`TaskCanceledException` 時は安全に無視する。
     - **`BeginInvoke(Action action)`**:
       - `dispatcher == null`（ヘッドレス・単体テスト環境）の場合は、オーディオ再生スレッドからの離脱を維持するため `Task.Run(action)` へフォールバックする。
       - `dispatcher.HasShutdownStarted || dispatcher.HasShutdownFinished`（WPF アプリケーション終了処理中・終了済み）の場合は、終了途中での次曲再生開始や破棄途中 ViewModel へのイベント発火を防止するため破棄（no-op）とする。
       - 通常時は `dispatcher.BeginInvoke(action)` で UI スレッドへ非ブロッキング投入する。

## 4. DI（依存性注入）登録仕様

プレゼンテーション層のクラスは、[`AudioEffector/Presentation/DependencyInjection.cs`](../../../AudioEffector/Presentation/DependencyInjection.cs) の `AddPresentationServices()` で一括して **Singleton** 登録します。

- **UI 基盤サービス**: `IUiDispatcher`（`WpfUiDispatcher` を Singleton 登録し、Infrastructure 層の既定 `ImmediateUiDispatcher` を上書き）
- **登録対象ViewModel**: `MainViewModel`, `PlayerControlViewModel`, `LibraryViewModel`, `AlbumDetailViewModel`, `AllSongsViewModel`, `ArtistsViewModel`, `RecentViewModel`, `PlaylistViewModel`, `EqualizerViewModel`, `DeviceSyncViewModel`, `NowPlayingViewModel`, `LyricsViewModel`, `LrcGeneratorViewModel`, `ListeningStatsViewModel`, `LibraryStatsViewModel`, `SettingsViewModel`
- **登録対象Window**: `MainWindow`
