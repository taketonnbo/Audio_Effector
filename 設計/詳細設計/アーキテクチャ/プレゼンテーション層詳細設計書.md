# プレゼンテーション層 詳細設計書

## 1. 概要

### 1.1 目的
本ドキュメントは、AudioEffector における **プレゼンテーション層（Presentation Layer / MVVM）** の設計仕様書です。
プレゼンテーション層はWPF（XAML）による画面表示、ユーザー入力の受付、データバインディング、および画面遷移を担当します。旧来の巨大な `MainViewModel.cs` から責務を分割し、機能ごとの軽量・高凝集なViewModel群とViewで構成されます。

### 1.2 設計原則
1. **MVVMパターンの徹底**: ViewのコードビハインドはUIコントロール固有のイベント（ドラッグシークやウィンドウ操作等）のみに留め、ビジネスロジックはViewModel経由でApplication層（ApplicationService）に委譲する。
2. **ドメインイベントの自律購読**: ViewModel同士が直接参照し合うことを避け、`IEventBus` を通じたイベント購読（`IHandle<TEvent>`）によって自律的に画面状態を更新する。
3. **インフラ層への非依存**: ViewModelからNAudioやTagLib、ファイルI/O等のインフラ層具象クラスを直接参照してはならない。

## 2. 名前空間とディレクトリ構造

プレゼンテーション層は `AudioEffector.Presentation` をルート名前空間とし、役割ごとに以下のディレクトリで管理します。

```
AudioEffector/
└── Presentation/                                # [名前空間: AudioEffector.Presentation]
    ├── ViewModels/                              # 各画面・コントロールに対応するViewModel
    │   ├── ViewModelBase.cs                     # INotifyPropertyChanged 基底クラス
    │   ├── RelayCommand.cs                      # ICommand 実装
    │   ├── MainViewModel.cs                     # 画面ルーティング・全体ダイアログ制御
    │   ├── PlayerControlViewModel.cs            # 再生/停止/シーク/ボリューム/スペクトラム
    │   ├── LibraryViewModel.cs                  # 楽曲一覧/アルバム一覧/検索/ソート
    │   ├── PlaylistViewModel.cs                 # プレイリスト選択・楽曲一覧
    │   ├── EqualizerViewModel.cs                # 10バンドEQ/プリセット選択
    │   ├── DeviceSyncViewModel.cs               # MTPデバイス同期・転送進捗
    │   ├── NowPlayingViewModel.cs               # 再生中ジャケット/トラック情報
    │   └── SettingsViewModel.cs                 # テーマ/ショートカットキー設定
    ├── Views/                                   # XAML ウィンドウおよびユーザーコントロール
    ├── Controls/                                # アプリ共通のカスタムUIコントロール
    │   └── GridLengthAnimation.cs               # Gridサイズ伸縮アニメーションコントロール
    ├── Converters/                              # XAMLデータバインディング用ValueConverter
    │   ├── BoolToVisConverter.cs                # bool -> Visibility 変換
    │   ├── EnumToBoolConverter.cs               # Enum一致判定 -> bool 変換
    │   ├── HeightToBorderThicknessConverter.cs  # 高さ -> 枠線太さ 変換
    │   ├── IndexConverter.cs                    # 0始まりインデックス -> 1始まり番号 変換
    │   ├── IndexIsOddConverter.cs               # インデックス奇数判定 変換
    │   ├── IndexToZebraBackgroundConverter.cs   # ゼブラストライプ行背景ブラシ 変換
    │   ├── InvertBoolConverter.cs               # bool反転 変換
    │   ├── NullToVisConverter.cs                # null/空文字列 -> Visibility 変換
    │   └── ZeroToTransparentConverter.cs        # 0/微小値 -> 透明度(0.0/1.0) 変換
    └── Themes/                                  # テーマリソースおよびテーマ管理
        ├── DarkTheme.xaml                       # ダークテーマリソース定義
        ├── LightTheme.xaml                      # ライトテーマリソース定義
        └── ThemeManager.cs                      # OS設定/ユーザー選択に応じたテーマ切り替え制御
```

## 3. 各コンポーネントの配置基準と実装ルール

### 3.1 ViewModels (`AudioEffector.Presentation.ViewModels`)
- **配置基準**: View（画面やユーザーコントロール）に対するデータバインディングとコマンド処理を提供するクラス。
- **実装ルール**:
  - `ViewModelBase` を継承し、プロパティ変更通知（`OnPropertyChanged`）を行う。
  - 操作トリガーは `ICommand`（`RelayCommand`）として公開し、Application層の `xxxApplicationService` のメソッドを呼び出す。
  - 再生状態や曲変更などの通知を受け取るため、必要なドメインイベントのハンドラーインターフェース（`IHandle<TrackChangedEvent>` 等）を実装する。

### 3.2 Views & Controls (`AudioEffector.Presentation.Views` / `Controls`)
- **配置基準**: XAMLファイルおよびそのコードビハインド。
- **実装ルール**:
  - 各Viewは自身に対応するViewModelを `DataContext` としてバインドする。
  - アニメーションやスタイルは `Themes/` 配下のリソースを参照する。

### 3.3 Converters (`AudioEffector.Presentation.Converters`)
- **配置基準**: XAMLデータバインディング時の型変換クラス（例: `BoolToVisConverter`, `IndexToZebraBackgroundConverter`）。
- **実装ルール**:
  - `IValueConverter` を実装し、純粋な値変換ロジックのみを記述する。

### 3.4 Themes (`AudioEffector.Presentation.Themes`)
- **配置基準**: アプリケーション全体のカラーパレット、ブラシ、ドロップシャドウ効果等のリソース定義XAML、およびテーマ切り替え制御マネージャー。
- **実装ルール**:
  - `DarkTheme.xaml` / `LightTheme.xaml`: 各テーマのカラー・ブラシ・エフェクトを統一されたキー名で定義する。
  - `ThemeManager.cs`: `ApplyTheme(ThemeType)` により `Application.Current.Resources.MergedDictionaries` 内のテーマリソースを動的に差し替える。

## 4. ViewModel 実装パターン（ApplicationService呼び出しとイベント購読）

```csharp
namespace AudioEffector.Presentation.ViewModels;

public class PlayerControlViewModel : ViewModelBase, IHandle<TrackChangedEvent>, IHandle<PlaybackStateChangedEvent>
{
    private readonly AudioApplicationService _audioApplicationService;

    public PlayerControlViewModel(AudioApplicationService audioApplicationService)
    {
        _audioApplicationService = audioApplicationService;

        TogglePlayPauseCommand = new RelayCommand(async () => await ExecuteTogglePlayPauseAsync());
    }

    public ICommand TogglePlayPauseCommand { get; }

    private async Task ExecuteTogglePlayPauseAsync()
    {
        if (IsPlaying)
        {
            await _audioApplicationService.PauseAsync();
        }
        else if (CurrentTrack != null)
        {
            await _audioApplicationService.PlayTrackAsync(CurrentTrack.Id);
        }
    }

    // イベント購読: ドメインイベント受信時に自律的にプロパティを更新
    public Task HandleAsync(TrackChangedEvent e, CancellationToken cancellationToken)
    {
        CurrentTrackTitle = e.Track.Title;
        TotalTime = e.Track.Duration.ToString(@"mm\:ss");
        return Task.CompletedTask;
    }

    public Task HandleAsync(PlaybackStateChangedEvent e, CancellationToken cancellationToken)
    {
        IsPlaying = e.State == PlaybackState.Playing;
        return Task.CompletedTask;
    }
}
```

## 5. DI（依存性注入）登録仕様

プレゼンテーション層のクラスは、レイヤー固有の拡張メソッド `AddPresentationServices()` で一括登録します。

```csharp
namespace AudioEffector.Presentation;

public static class DependencyInjection
{
    public static IServiceCollection AddPresentationServices(this IServiceCollection services)
    {
        // 画面状態を保持する主要ViewModelは Singleton
        services.AddSingleton<MainViewModel>();
        services.AddSingleton<PlayerControlViewModel>();
        services.AddSingleton<LibraryViewModel>();
        services.AddSingleton<PlaylistViewModel>();
        services.AddSingleton<EqualizerViewModel>();
        services.AddSingleton<DeviceSyncViewModel>();
        services.AddSingleton<NowPlayingViewModel>();
        services.AddSingleton<SettingsViewModel>();

        return services;
    }
}
```
