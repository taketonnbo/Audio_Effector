# プレゼンテーション層 詳細設計書

## 1. 概要

### 1.1 目的
本ドキュメントは、AudioEffector における **プレゼンテーション層（Presentation Layer / MVVM）** の設計仕様書です。
プレゼンテーション層はWPF（XAML）による画面表示、ユーザー入力の受付、データバインディング、および画面遷移を担当し、機能ごとのViewModel群とViewで構成されます。

### 1.2 設計原則
1. **MVVMパターンの徹底**: ViewのコードビハインドはUIコントロール固有のイベント（ドラッグシーク、ダブルクリック元の要素判定、スクロールバー幅同期、ウィンドウメッセージ処理等）のみに留め、状態管理と業務操作はViewModel経由でApplication層に委譲する。
2. **単一情報源（Single Source of Truth）とイベント連携**: 再生状態・再生キューは `IAudioService`（およびそれを購読する `PlayerControlViewModel`）、ライブラリ楽曲・アルバムは `LibraryViewModel` を単一情報源とし、イベント購読によって各画面ViewModelが自律的に表示を同期する。
3. **インフラ層具象への非依存**: View / ViewModel からNAudio等の外部デバイス制御を直接行わず、`IAudioService` や各 `ApplicationService` / `Repository` インターフェース経由で連携する。

## 2. 名前空間とディレクトリ構造

プレゼンテーション層は `AudioEffector.Presentation` をルート名前空間とし、役割ごとに以下のディレクトリで管理します（個別ファイルの正本は実ディレクトリを参照）。

    │   ├── ViewModelBase.cs / RelayCommand.cs / ViewType.cs

    │   ├── NowPlayingViewModel.cs               # 再生中トラック情報モデル
    │   ├── LibraryViewModel.cs                  # アルバム一覧(グリッド/リスト)・スキャン・お気に入り統括
    │   ├── AlbumDetailViewModel.cs              # アルバム情報詳細・メタデータ集計・高解像度アートワーク非同期読込・収録曲操作

    │   ├── PlaylistViewModel.cs                 # プレイリスト一覧・詳細・お気に入りビュー表示・追加ダイアログ制御
    │   ├── EqualizerViewModel.cs                # 10バンドEQ・プリセット管理 (+ BandViewModel)

    ├── Controls/                                # カスタムUIコントロール

    │   └── AlbumArtLoader.cs                    # アルバムアート非同期読み込み・キャッシュ添付プロパティ
    ├── Converters/                              # XAMLデータバインディング用ValueConverter群
    ├── Diagnostics/                             # 診断・検証基盤
    │   └── BindingErrorDebugListener.cs         # DEBUG実行時のXAMLバインディングエラー検知リスナー
    └── Themes/                                  # テーマリソースおよびテーマ管理
        ├── DarkTheme.xaml                       # ダークテーマリソース定義

        └── ThemeManager.cs                      # OS設定/ユーザー選択に応じたテーマ動的切り替え制御

## 3. 主要コンポーネントの責務と実装ルール

### 3.1 ViewModels (`AudioEffector.Presentation.ViewModels`)
- **基底とコマンド (`ViewModelBase.cs` / `RelayCommand.cs`)**:
  - **`ViewModelBase`**: `INotifyPropertyChanged` を実装し、`[CallerMemberName]` を利用した `OnPropertyChanged` および `EqualityComparer<T>.Default` による同値ガード付き `SetProperty<T>(ref T field, T value)` ヘルパーを提供する。
  - **`RelayCommand`**: `ICommand` の汎用実装。`Action<object?>` / `Predicate<object?>?` および引数なし `Action` / `Func<bool>?` オーバーロードを提供し、`CanExecuteChanged` イベントを WPF の `CommandManager.RequerySuggested` に委譲する。
- **主要ViewModelの責務境界**:
  - **`PlayerControlViewModel`**: `IAudioService` のイベント（`TrackChanged`, `PlaybackStateChanged`, `PlaylistChanged`, `TrackPlaybackEnded`, `FftCalculated`, `VolumeChanged`）を購読し、再生制御・シーク（`_isDraggingProgress` と `_isUpdatingProgressInternally` の二重ガード）・2層再生キュー（`UserQueue` / `AlbumQueue`）・インメモリ再生履歴タブ（`PlayHistory`, 上限100件）・スペクトラム描画（約30fpsスロットリング）・スライドパネル/ダイアログ開閉を一元管理する。
  - **`LibraryViewModel`**: アルバム一覧（`Albums`）、全トラック（`Tracks`）、表示切替（グリッド/リスト）、ソート順（`Artist` / `Album`、昇順/降順）、フォルダスキャン、および `FavoriteTrackMatcher` / `IFavoriteRepository` と連携したお気に入り状態管理の Single Source of Truth を担う。また `ShowAlbumInfo` による展開トレイクローズおよび `AlbumDetailRequested` イベント発行を担う。
  - **`AlbumDetailViewModel`**: アルバム情報詳細画面（`ViewType.AlbumDetail`）専用 ViewModel。選択アルバムのメタデータ集計（年・ジャンル・代表フォーマット・曲数・総時間・Hi-Res/Lossless 判定）、`CancellationTokenSource` と世代番号による高解像度カバーアート（`DecodePixelWidth = 400`、`Freeze()`）の非同期読み込み、アルバム／個別トラックの再生・キュー・お気に入り・削除コマンド、および `LibraryViewModel` の削除・差分同期イベントとの自動追従／一覧復帰（`BackRequested`）を担う。
  - **`AllSongsViewModel` / `ArtistsViewModel` / `RecentViewModel`**: `LibraryViewModel.Tracks` の変更（および既存ファイルのメタデータ更新を伴う `LibrarySynced` イベント）を `DispatcherPriority.Background` でコアレッシング同期し、大量トラックの一括追加時でも $O(N^2)$ のUI再構築が発生しないよう保護する。また、再生要求（`PlaybackRequested`）やキュー追加要求（`EnqueueRequested`）をイベント経由で `MainViewModel` / `PlayerControlViewModel` へ通知する。
  - **`PlaylistViewModel`**: プレイリスト一覧・詳細トラック・お気に入り一覧モードの切り替えを管理する。プレイリスト切替時の非同期読み込みは `CancellationTokenSource` と世代番号（`_trackLoadVersion`）を併用し、古い非同期結果による表示上書きを防止する。

### 3.2 Views & Controls (`AudioEffector.Presentation.Views` / `Controls`)
- **直接DataContextバインディング**:
  - `MainWindow.xaml` 内の各子ビュー（`LibraryView`, `AllSongsView`, `ArtistsView`, `RecentView`, `FolderView`, `PlaylistSelectorView`, `PlaylistTracksView`, `EqualizerView`, `DeviceSyncView`, `PlayQueueSidePanel`）は、それぞれ対応する専用ViewModel（`Library`, `AllSongs`, `Artists`, `Recent`, `Folder`, `Playlist`, `Equalizer`, `DeviceBrowser`, `PlayerControl`）を `DataContext` としてバインドする。
- **カスタムコントロール (`MarqueeTextBlock.cs` / `GridLengthAnimation.cs`)**:
  - **`MarqueeTextBlock`**: テキストが表示幅を超過する場合のみ、ホバー（または親要素の `IsTriggered`）連動で2つの `TextBlock` を用いたシームレスな無限ループスクロールを行う（詳細は [テキストループ表示機能](../../機能仕様/テキストループ表示機能.md) を参照）。
  - **`GridLengthAnimation`**: 右側パネル開閉等の `GridLength` プロパティ（スター比率 `GridUnitType.Star`）を補間アニメーションするカスタム `AnimationTimeline`。

### 3.3 添付プロパティ (`AudioEffector.Presentation.AttachedProperties`)
- **`AlbumArtLoader` (`AlbumArtLoader.cs`)**:
  - `Image` コントロール向けの添付プロパティ `AlbumArtLoader.SourcePath` を提供する。
  - パス設定時にまずインメモリ LRU キャッシュ（上限 `MaxCacheSize = 100`、`Dictionary<string, BitmapImage>` + `LinkedList<string>`）を参照し、未キャッシュ時はプレースホルダー画像（`pack://application:,,,/Assets/Images/default_now_playing_bg.png`）を表示した上で、`Task.Run` にて `TagLib.File` から埋め込み画像を非同期抽出する。
  - 抽出画像は `DecodePixelWidth = 150`（サムネイル縮小）・`BitmapCacheOption.OnLoad` でデコード後に `Freeze()` して UI スレッドへ返却し、非同期完了時に `GetSourcePath(image) == path` が一致する場合のみ `image.Source` を更新することで仮想化再利用時の画像取り違えを防止する。

### 3.4 ValueConverter群 (`AudioEffector.Presentation.Converters`)
XAML データバインディングにおける表示変換を担う全9種の `IValueConverter` 実装仕様は以下の通りです。

| クラス名 | 入力値 / パラメータ | 出力値・変換仕様 | 主な用途 |
| :--- | :--- | :--- | :--- |
| **`BoolToVisConverter`** | `bool` (`Parameter="Invert"` 可) | `true` → `Visibility.Visible`、`false`（または非 `bool`）→ `Visibility.Collapsed`。`"Invert"` 指定時は真偽を反転。 | パネル・アイコン・オーバーレイの表示/非表示切替 |
| **`InvertBoolConverter`** | `bool` | `!b`（非 `bool` 時は `false`）。`ConvertBack` による双方向反転にも対応。 | `IsEnabled` や排他トグル状態の反転バインディング |
| **`NullToVisConverter`** | `object?` / `string?` | `null` または空文字列（`string.IsNullOrEmpty`）→ `Visibility.Collapsed`、それ以外 → `Visibility.Visible`。 | 文字列やオブジェクトが存在する場合のみの要素表示 |
| **`EnumToBoolConverter`** | `Enum` + `Parameter` (文字列、カンマ区切り複数指定可) | 列挙値名とパラメータ文字列を大文字小文字無視で比較し一致時に `true`。`ConvertBack` では `true` の場合に先頭パラメータ名で `Enum.TryParse` して列挙値を返却（`false` 時は `Binding.DoNothing`）。 | `ViewType` 等に応じたサイドバー・ラジオボタンの選択判定 |
| **`IndexConverter`** | `int` (0始まり) | `index + 1`（1始まりの表示用行番号）。 | `AlternationIndex` 等からのトラック行番号（`#`）表示 |
| **`IndexIsOddConverter`** | `int` (0始まり) | `index % 2 == 1`（奇数行で `true`、偶数行で `false`）。 | `DataTrigger` による奇数行スタイル切替 |
| **`IndexToZebraBackgroundConverter`** | `int` (0始まり) | 偶数行は `Brushes.Transparent`、奇数行はテーマの `ZebraOddBackgroundBrush`（未解決時は `TextForegroundColor` の明度からダーク用 `#10FFFFFF` / ライト用 `#0C000000` の `Freeze()` 済みブラシ）を返却。 | 楽曲リスト・キュー一覧のゼブラストライプ行背景 |
| **`HeightToBorderThicknessConverter`** | `double` (高さ) | `(height / 600.0) * 3.0` を `0`〜`3.0` の範囲にクランプした `Thickness` を返却。 | スペクトラムバー等の高さに応じた動的ボーダー太さ算出 |
| **`ZeroToTransparentConverter`** | `double` | `0.01` 以下の場合は `0.0`（完全透明）、それ以外は `1.0`（不透明）を返却。 | スペクトラム無音・極小値時の要素非表示（Opacity制御） |

### 3.5 Diagnostics (`AudioEffector.Presentation.Diagnostics`)
- **`BindingErrorDebugListener`**: DEBUGビルド起動時に `PresentationTraceSources.DataBindingSource` を監視し、XAMLバインディングエラー発生時にトレース出力へ警告を記録する（詳細は [XAMLバインディング検証基盤](../XAMLバインディング検証基盤.md) を参照）。

### 3.6 Themes (`AudioEffector.Presentation.Themes`)
- **`DarkTheme.xaml` / `LightTheme.xaml` / `ScrollBarResources.xaml`**: カラートークン・ブラシ・ドロップシャドウ・共通スクロールバースタイルを定義する（詳細は [デザイントークン仕様書](../../デザインシステム/01_デザイントークン仕様書.md) を参照）。
- **`ThemeManager.cs`**: `ApplyTheme(ThemeType)` により `Dark` / `Light` / `System`（Windowsレジストリ `AppsUseLightTheme` 参照）に応じたリソースディクショナリを動的に適用する。

## 4. DI（依存性注入）登録仕様

プレゼンテーション層のクラスは、[`AudioEffector/Presentation/DependencyInjection.cs`](../../../AudioEffector/Presentation/DependencyInjection.cs) の `AddPresentationServices()` で一括して **Singleton** 登録します。

- **登録対象ViewModel**: `MainViewModel`, `PlayerControlViewModel`, `LibraryViewModel`, `AlbumDetailViewModel`, `AllSongsViewModel`, `ArtistsViewModel`, `RecentViewModel`, `PlaylistViewModel`, `EqualizerViewModel`, `DeviceSyncViewModel`, `NowPlayingViewModel`, `SettingsViewModel`
- **登録対象Window**: `MainWindow`
