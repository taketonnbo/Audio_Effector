# アプリケーション層 詳細設計書

## 1. 概要

### 1.1 目的
本ドキュメントは、AudioEffector における **アプリケーション層（Application Layer / ApplicationServices）** の設計仕様書です。
アプリケーション層はプレゼンテーション層（ViewModel）からの操作要求を受け付け、ドメインモデル・リポジトリ・外部エンジンを連携させて一連の業務処理を実行・調整する役割を担当します。

### 1.2 設計原則
1. **UIフレームワーク非依存**: WPF特有のコントロールやUIスレッド（Dispatcher）に直接依存せず、純粋なC#ロジックとして完結させる。
2. **直感的な業務メソッドの提供**: 1クラスに1メソッド（Execute）を強制するのではなく、関連する業務操作ごとにまとまったわかりやすいメソッド名（`PlayTrackAsync()`, `PauseAsync()`, `SeekAsync()` 等）を公開する。
3. **イベント発行の単一責任**: 処理が正常に完了した後の「ドメインイベントの発行（`IEventBus.PublishAsync`）」はアプリケーション層（ApplicationService）が一括して担当する。

## 2. 名前空間とディレクトリ構造

アプリケーション層は `AudioEffector.Application` をルート名前空間とし、以下の構成で管理します。

```
AudioEffector/
└── Application/                                 # [名前空間: AudioEffector.Application]
    ├── Common/                                  # 共通基盤 (EventBus, 共通インターフェース, 汎用型)
    │   ├── IEventBus.cs                         # イベント発行・購読インターフェース
    │   ├── IHandle.cs                           # イベントハンドラーインターフェース
    │   ├── IAudioEngine.cs                      # 音声再生エンジンの抽象I/F
    │   ├── FftEventArgs.cs                      # FFT計算結果通知イベント引数
    │   └── Result.cs                            # 処理成否・エラー返却用型
    └── ApplicationServices/                     # アプリケーションサービス群 (機能カテゴリごとに配置)
        ├── AudioApplicationService.cs           # 音声再生・一時停止・停止・シーク・音量制御
        ├── IAudioService.cs                     # オーディオ再生コアサービスインターフェース
        ├── LibraryApplicationService.cs         # フォルダスキャン・楽曲検索・ソート・お気に入り操作
        ├── PlaylistApplicationService.cs        # プレイリスト作成・削除・楽曲追加・並び替え
        ├── EqualizerApplicationService.cs       # EQプリセット適用・バンドゲイン調整・カスタム保存
        ├── DataTransferApplicationService.cs    # MTPデバイス検出・データ転送
        ├── SettingsApplicationService.cs        # 設定のロード・セーブ
        └── ISettingsService.cs                  # 設定サービスインターフェース
```

## 3. 各コンポーネントの配置基準と実装ルール

### 3.1 ApplicationServices (`AudioEffector.Application.ApplicationServices`)
- **配置基準**: 機能カテゴリごとにまとまった業務処理・操作シナリオを提供するクラス。
- **命名規則**: `<機能名>ApplicationService`（例: `AudioApplicationService`, `LibraryApplicationService`, `PlaylistApplicationService`, `DataTransferApplicationService`）。
- **実装ルール**:
  - クラス内には、呼び出し側（ViewModel等）から見て直感的で分かりやすい名前のメソッドを定義する。
  - 必要な依存オブジェクト（リポジトリ、ドメインサービス、外部エンジンI/F、EventBus）はコンストラクタ経由で受け取る（Constructor Injection）。
  - 状態変更を伴う操作が成功した場合、適切な `IDomainEvent` を `IEventBus` 経由で発行する。

### 3.2 Common (`AudioEffector.Application.Common`)
- **配置基準**: アプリケーションサービス間で横断的に利用される通信基盤や共通型。
- **主要インターフェース**:
  - `IEventBus`: `PublishAsync<TEvent>(TEvent domainEvent)`
  - `IHandle<TEvent>`: `HandleAsync(TEvent domainEvent, CancellationToken cancellationToken)`
  - `IAudioEngine`: 音声再生・シーク・ボリューム制御の抽象

## 4. ApplicationService 実装パターン

```csharp
namespace AudioEffector.Application.ApplicationServices;

public class AudioApplicationService
{
    private readonly IAudioEngine _audioEngine;
    private readonly ITrackRepository _trackRepository;
    private readonly IEventBus _eventBus;

    public AudioApplicationService(
        IAudioEngine audioEngine,
        ITrackRepository trackRepository,
        IEventBus eventBus)
    {
        _audioEngine = audioEngine;
        _trackRepository = trackRepository;
        _eventBus = eventBus;
    }

    /// <summary>
    /// 指定されたトラックを再生します。
    /// </summary>
    public async Task PlayTrackAsync(TrackId trackId, CancellationToken cancellationToken = default)
    {
        var track = await _trackRepository.GetByIdAsync(trackId, cancellationToken);
        if (track == null) return;

        await _audioEngine.PlayAsync(track, cancellationToken);
        await _eventBus.PublishAsync(new TrackChangedEvent(track, TimeSpan.Zero), cancellationToken);
    }

    /// <summary>
    /// 再生を一時停止します。
    /// </summary>
    public async Task PauseAsync(CancellationToken cancellationToken = default)
    {
        await _audioEngine.PauseAsync(cancellationToken);
        await _eventBus.PublishAsync(new PlaybackStateChangedEvent(PlaybackState.Paused), cancellationToken);
    }

    /// <summary>
    /// 指定位置にシークします。
    /// </summary>
    public async Task SeekAsync(TimeSpan position, CancellationToken cancellationToken = default)
    {
        await _audioEngine.SeekAsync(position, cancellationToken);
    }

    /// <summary>
    /// 音量を変更します。
    /// </summary>
    public async Task ChangeVolumeAsync(float volume, CancellationToken cancellationToken = default)
    {
        await _audioEngine.SetVolumeAsync(volume, cancellationToken);
        await _eventBus.PublishAsync(new VolumeChangedEvent(volume, false), cancellationToken);
    }
}
```

## 5. DI（依存性注入）登録仕様

アプリケーション層のクラスは、レイヤー固有の拡張メソッド `AddApplicationServices()` で一括登録します。

```csharp
namespace AudioEffector.Application;

public static class DependencyInjection
{
    public static IServiceCollection AddApplicationServices(this IServiceCollection services)
    {
        // EventBus はアプリケーション全体で共有するため Singleton
        services.AddSingleton<IEventBus, EventBus>();

        // ApplicationService は Transient (必要に応じて Scoped)
        services.AddTransient<AudioApplicationService>();
        services.AddTransient<LibraryApplicationService>();
        services.AddTransient<PlaylistApplicationService>();
        services.AddTransient<EqualizerApplicationService>();
        services.AddTransient<DataTransferApplicationService>();
        services.AddTransient<SettingsApplicationService>();

        return services;
    }
}
```
