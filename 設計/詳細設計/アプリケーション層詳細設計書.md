# アプリケーション層 詳細設計書

## 1. 概要

### 1.1 目的
本ドキュメントは、AudioEffector における **アプリケーション層（Application Layer / UseCases）** の設計仕様書です。
アプリケーション層はプレゼンテーション層（ViewModel）からのユーザー操作要求を受け付け、ドメインモデル・リポジトリ・外部エンジンを連携させて「1つの業務操作（ユースケース）」を完了させる調整役（オーケストレーター）を担当します。

### 1.2 設計原則
1. **UIフレームワーク非依存**: WPF特有のコントロールやUIスレッド（Dispatcher）に直接依存せず、純粋なC#ロジックとして完結させる。
2. **ステートレス（状態非保持）**: 各ユースケースクラスは操作の実行に必要なサービスやリポジトリのみを保持し、インスタンス自体に実行状態を抱え込まない。
3. **イベント発行の単一責任**: 処理が正常に完了した後の「ドメインイベントの発行（`IEventBus.Publish`）」はアプリケーション層（UseCase）が一括して担当する。

## 2. 名前空間とディレクトリ構造

アプリケーション層は `AudioEffector.Application` をルート名前空間とし、機能カテゴリごとのサブディレクトリで管理します。

```
AudioEffector/
└── Application/                                 # [名前空間: AudioEffector.Application]
    ├── Common/                                  # 共通基盤 (EventBus, 共通インターフェース, 汎用型)
    │   ├── IEventBus.cs                         # イベント発行・購読インターフェース
    │   ├── IHandle.cs                           # イベントハンドラーインターフェース
    │   ├── IAudioEngine.cs                      # 音声再生エンジンの抽象I/F
    │   └── Result.cs                            # 処理成否・エラー返却用型
    └── UseCases/                                # ユースケース群 (機能カテゴリごとにサブ名前空間を配置)
        ├── Audio/                               # 再生・停止・シーク・音量・次曲 UseCases
        ├── Library/                             # ライブラリスキャン・検索・お気に入り UseCases
        ├── Playlist/                            # プレイリスト作成・更新・並び替え UseCases
        ├── Equalizer/                           # イコライザー設定・プリセット適用 UseCases
        ├── Device/                              # デバイス検出・ファイル転送 UseCases
        └── Settings/                            # 設定読み込み・保存 UseCases
```

## 3. 各コンポーネントの配置基準と実装ルール

### 3.1 UseCases (`AudioEffector.Application.UseCases.*`)
- **配置基準**: ユーザーの1つの意図や操作シナリオ（例: 「曲を再生する」「プレイリストを作成する」「端末へ転送する」）。
- **命名規則**: `<動詞><対象>UseCase`（例: `PlayTrackUseCase`, `ScanLibraryFolderUseCase`, `AddTrackToPlaylistUseCase`）。
- **実装ルール**:
  - 原則として `ExecuteAsync()` または `Execute()` メソッドを1つだけ公開する。
  - 必要な依存オブジェクト（リポジトリ、ドメインサービス、外部エンジンI/F、EventBus）はコンストラクタ経由で受け取る（Constructor Injection）。
  - 処理が成功した場合にのみ、関係する `IDomainEvent` を `IEventBus` を介して発行する。

### 3.2 Common (`AudioEffector.Application.Common`)
- **配置基準**: ユースケース間で横断的に利用される通信基盤や共通型。
- **主要インターフェース**:
  - `IEventBus`: `PublishAsync<TEvent>(TEvent domainEvent)`
  - `IHandle<TEvent>`: `HandleAsync(TEvent domainEvent)`
  - `IAudioEngine`: 音声再生・シーク・ボリューム制御の抽象

## 4. ユースケース実装パターン

```csharp
namespace AudioEffector.Application.UseCases.Audio;

public class PlayTrackUseCase
{
    private readonly IAudioEngine _audioEngine;
    private readonly ITrackRepository _trackRepository;
    private readonly IEventBus _eventBus;

    public PlayTrackUseCase(
        IAudioEngine audioEngine,
        ITrackRepository trackRepository,
        IEventBus eventBus)
    {
        _audioEngine = audioEngine;
        _trackRepository = trackRepository;
        _eventBus = eventBus;
    }

    public async Task ExecuteAsync(TrackId trackId, CancellationToken cancellationToken = default)
    {
        // 1. ドメインデータの取得
        var track = await _trackRepository.GetByIdAsync(trackId, cancellationToken);
        if (track == null) return;

        // 2. 外部再生エンジンの操作
        await _audioEngine.PlayAsync(track, cancellationToken);

        // 3. 成功後にドメインイベントを発行 (Publish)
        await _eventBus.PublishAsync(new TrackChangedEvent(track, TimeSpan.Zero), cancellationToken);
    }
}
```

## 5. DI（依存性注入）登録仕様

アプリケーション層のクラスは、レイヤー固有の拡張メソッド `AddApplicationServices()` で一括登録します。

```csharp
namespace AudioEffector.Application;

public static class DependencyInjection
{
    public static IServiceCollection AddApplicationServices(this IServiceCollection services)
    {
        // EventBus はアプリケーション全体で共有するため Singleton
        services.AddSingleton<IEventBus, EventBus>();

        // UseCase はステートレスな操作単位のため Transient
        services.AddTransient<PlayTrackUseCase>();
        services.AddTransient<PausePlaybackUseCase>();
        services.AddTransient<ScanLibraryFolderUseCase>();
        services.AddTransient<CreatePlaylistUseCase>();
        // ... 他のUseCaseも同様に Transient 登録

        return services;
    }
}
```
