# ユースケース仕様書: 機器転送・同期機能

## 1. 概要
PCに接続された外部ポータブル機器（Walkman、USBストレージ等）を検出し、機器内部ストレージの探索や、ライブラリから選択したアルバムの一括転送を行うためのユースケース群です。

## 2. アクター
- 一般ユーザー

## 4. オブジェクト構成（コレクション / シングル）と課題
- **外部機器 (`Device`)**:
  - **コレクション表示**: `DeviceSyncView` 上部のコンボボックス、および `DeviceManagerDialog` 内の機器リスト。
  - **シングル表示**: `DeviceSyncView` 内の特定機器のフォルダ階層ブラウザ。
  - **課題**: 「デバイス同期画面」として上下2分割の専用画面を介して転送を行うタスク先行型（動詞先行）のUIになっており、日常的にライブラリを見ながら直接ドラッグ＆ドロップで転送するオブジェクト指向の操作になっていない。
