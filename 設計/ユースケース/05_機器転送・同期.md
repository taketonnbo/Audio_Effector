# ユースケース仕様書: 機器転送・同期機能

## 1. 概要
PCに接続された外部ポータブル機器（MTP対応オーディオプレーヤー、USBフラッシュメモリ等のリムーバブルドライブ）を検出し、機器内部ディレクトリの探索や、ライブラリから選択したアルバム・楽曲の一括転送、および機器内コンテンツの削除管理を行うためのユースケース群です。

## 2. アクター
- 一般ユーザー

## 4. オブジェクト構成（コレクション / シングル）と拡張指針
- **外部機器 (`Device`)**:
  - **コレクション表示**: `DeviceSyncView` 上部のデバイス選択コンボボックス（`ConnectedDevices`）。
  - **シングル表示**: `DeviceSyncView` 内のフォルダ階層ブラウザ（`DeviceDirectories`）、および `DeviceManagerDialog`（`DeviceAlbums` / `DeviceTrack` 一覧・削除）。
  - **拡張設計指針**: 全階層重複スキャン（Issue #169）、曲単位での重複非活性化（Issue #170）、転送時フォーマット変換（Issue #96, #97）、空き容量予測バーおよび既定フォルダ記憶（Issue #233）。
