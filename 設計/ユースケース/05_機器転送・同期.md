# ユースケース仕様書: 機器転送・同期機能

## 1. 概要
PCに接続された外部ポータブル機器（Walkman、USBストレージ等）を検出し、機器内部ストレージの探索や、ライブラリから選択したアルバムの一括転送を行うためのユースケース群です。

## 4. オブジェクト構成（コレクション / シングル）と課題
- **外部機器 (`Device`)**:
  - **コレクション表示**: `DeviceSyncView` 上部のコンボボックス、および `DeviceManagerDialog` 内の機器リスト。
  - **シングル表示**: `DeviceSyncView` 内の特定機器のフォルダ階層ブラウザ、および右側「端末転送パネル (`DeviceTransferSidePanel`)」。
  - **課題とTo-Be**:
    - 専用の「デバイス同期画面」へ遷移する方式から、端末接続時にトースト通知と右側転送パネルが自動起動し、通常のライブラリ画面（すべての曲・アルバム・アーティスト・プレイリスト等）から単選択・複数選択して即座に転送できるモードレスな導線へ移行する。
    - 機器接続のたびに毎回転送先フォルダ（MUSICフォルダ等）を探索・指定し直す手間を解消するため、端末ごとの固有IDを識別し、各端末に紐付いた既定フォルダを自動選択・記憶する管理機能を導入する。
    - 転送実行前のストレージ空き容量超過に対するリアルタイム警告と安全な転送抑止機構を提供する。
