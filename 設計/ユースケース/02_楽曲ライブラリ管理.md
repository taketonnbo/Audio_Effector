# ユースケース仕様書: 楽曲ライブラリ管理機能

## 1. 概要
ユーザーがPC内の音源ファイルを管理し、アルバム一覧表示（グリッド/リスト）、フォルダブラウズ、お気に入り楽曲、外部ファイル取り込み等を通じて楽曲を探索・ブラウズするためのユースケース群です。

## 2. アクター
- 一般ユーザー

## 4. オブジェクト構成（コレクション / シングル）と課題
- **アルバム (`Album`)**:
  - **コレクション表示**: `LibraryView`（グリッド表示とリスト表示を切り替え可能）、およびアーティストドリルダウン時の所属アルバム一覧。
  - **シングル表示**: アルバム詳細情報パネル/画面（`AlbumDetailView`）、およびカード・リスト行内のインライン展開（Expander / ソケット風オーバーレイトレイ）。
- **楽曲 (`Track`)**:
  - **コレクション表示**: 全曲データグリッド一覧（`AllSongsView.xaml`）、アルバム展開リスト、プレイリスト/お気に入り一覧、再生履歴一覧（`RecentView.xaml`）。
  - **シングル表示**: 右カラムの楽曲情報パネル、またはプロパティダイアログ。
- **課題とTo-Be**:
  - 複数選択時のモードレスな一括操作（ドラッグ＆ドロップ投入や一括タグ編集）、および大量楽曲表示時の仮想化とレスポンス維持が重要となる。
  - 階層が深くなるドリルダウン操作（アーティストやフォルダ）において、現在地を見失わないためのパンくずリストナビゲーションの常時提供。
