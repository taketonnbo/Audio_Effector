# ユースケース仕様書: 楽曲ライブラリ管理機能

## 1. 概要
ユーザーがPC内の音源ファイルを管理し、アルバム一覧表示（グリッド/リスト）、フォルダブラウズ、お気に入り楽曲、外部ファイル取り込み等を通じて楽曲を探索・ブラウズするためのユースケース群です。

## 2. アクター
- 一般ユーザー

## 4. 現状のオブジェクト構成（コレクション / シングル）と課題
- **アルバム (`Album`)**:
  - **現状のコレクション表示**: `LibraryView`（グリッド表示とリスト表示を切り替え可能）。
  - **現状のシングル表示**: 独立したシングルビュー（アルバム詳細画面）は存在せず、カード・リスト行内のExpanderまたはソケット風オーバーレイトレイでインプレース展開される。
- **楽曲 (`Track`)**:
  - **現状のコレクション表示**: 全曲一覧 (`AllSongsView.xaml`) は未実装。現状は各アルバムの展開内、またはプレイリスト/お気に入り内でのみ一覧表示される。
  - **現状のシングル表示**: なし（右カラムのアルバム情報タブに現在の曲/アルバムが表示されるのみ）。
