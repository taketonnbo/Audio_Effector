# ユースケース仕様書: 楽曲ライブラリ管理機能

## 1. 概要
ユーザーがPC内の音源ファイルを管理し、全曲一覧、アーティスト一覧、最近再生した曲、アルバム一覧（グリッド/リスト）、フォルダ選択、お気に入り楽曲（メタデータベース照合）等を通じて楽曲を探索・ブラウズするためのユースケース群です。

## 2. アクター
- 一般ユーザー

## 4. オブジェクト構成（コレクション / シングル）と拡張指針
- **アルバム (`Album`)**:
  - **コレクション表示**: `LibraryView`（グリッド/リスト切替）、`ArtistsView`（右ペイン所属アルバム横スクロール）。
  - **展開・詳細表示**: カード・リスト行内のインライン展開（ソケットトレイ / Expander）および右側パネル（独立シングルビュー `AlbumDetailView` は Issue #188 で計画）。
- **楽曲 (`Track`)**:
  - **コレクション表示**: `AllSongsView`, `ArtistsView`, `RecentView`, `LibraryView` 展開リスト, `PlaylistTracksView`。
  - **シングル表示**: 右側パネルの楽曲情報・Player Pod、およびプロパティダイアログ。
