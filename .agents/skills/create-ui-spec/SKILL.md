# UI仕様書作成スキル (create-ui-spec)

このスキルは、ユーザーから「UI仕様書を作成する」よう指示された場合に使用します。エージェントは以下の手順と規則に従って作業を進めてください。

## ワークフロー手順

### 1. ディレクトリとファイルの準備
- プロジェクトルートから `設計/画面設計/<機能名・画面名>/` というディレクトリを作成します。
- そのディレクトリ内に `<画面名>UI仕様書.md` というMarkdownファイルを作成します（ファイル名は必ず日本語にすること）。
- モックアップ画像を保存するため、同ディレクトリ内に `images/` サブディレクトリを作成します。

### 2. 仕様書のフォーマット
作成するMarkdownファイルには、必ず以下のセクションを含めてください。
- `## 1. 概要`: 画面の目的と全体像
- `## 2. 実装イメージ（モックアップ）`: 生成した画像をここに挿入します
- `## 3. レイアウトとデザイン`: サイズ、アイコン、配色、各セクションの構成
- `## 4. アニメーションとインタラクション`: ホバー時の挙動、クリック時のビュー切り替え、ドラッグ＆ドロップなどの詳細
- `## 5. 関連Issue`: 親Issueや関連Issueへのリンク

### 3. モックアップ画像の生成
- `generate_image` ツールを使用して、実装イメージとなるUIのモックアップ画像を生成します。
- プロンプトには、「Windows 11アプリケーション」「Fluent Design」「指定されたUI構成」など、プロジェクトに合致する具体的なデザイン要件を含めてください。
- 生成した画像を `<画面名>UI仕様書.md` と同じディレクトリの `images/` 配下にコピー（または移動）します。
- Markdownファイル内に `![実装イメージ](images/<画像ファイル名>)` として画像を挿入します。

### 4. ドキュメント参照の追加
- プロジェクトの `README.md` またはそれに準ずるドキュメント目次に、作成した仕様書へのリンク（相対パス）を追記します。

### 5. Git操作 (任意)
- ユーザーから「対応を進めて」「PRを作成して」などの指示がある場合は、`create-pr-from-issue` スキルや `.agents/rules/git_operation_rules.md` のコミットルールに従い、コミットとPR作成を行ってください。
